🎯 오늘 만드는 것
  • 깨끗해진 추세 그래프 — 믿기 어려운 해를 걸러 낸 뒤 다시 그리기
  • 전처리 판단 기록 — 무엇을 왜 뺐는지 근거와 함께

0. 왜 배우나

체육 시간에 반 평균 키를 재는데 두 명이 결석했다고 합시다. 그 두 칸에 0cm를 넣고 평균을 내면 반 평균이 뚝 떨어집니다. 누가 봐도 이상한 처리지만, 데이터 분석에서는 이런 일이 조용히 일어납니다. 빈 칸을 어떻게 다루느냐에 따라 같은 데이터에서 전혀 다른 답이 나오기 때문입니다. 지난 차시에 찾은 두 구멍 — 끊긴 선과 0.6℃의 점 — 도 바로 이 문제의 실제 사례입니다. 오늘은 그 구멍의 정체를 밝히고, 무엇을 남기고 무엇을 뺄지 근거를 들어 정하는 일, 곧 전처리를 배웁니다.

1. 개념 이해 — 빠진 값을 대하는 법

빠짐에도 종류가 있다

빈 칸을 다루는 판단은 언제나 "왜 빠졌는가"에서 출발합니다. 빠짐은 크게 세 갈래로 나눌 수 있습니다. 첫째, 우연히 빠짐. 동전 던지기처럼 아무 이유 없이 이날 저 날 빠진 경우입니다. 남은 데이터가 전체의 축소판이라, 빈 행을 빼고 분석해도 결론이 뒤틀리지 않습니다. 둘째, 다른 사정 때문에 빠짐. 예를 들어 어떤 시대에 장비가 자주 고장 나서 그 시기의 기록이 빠졌다면, "시기"라는 사정을 알고 있으므로 그것을 감안해 다룰 수 있습니다. 셋째, 값 그 자체 때문에 빠짐. 가장 까다로운 경우입니다. 몹시 추운 날마다 기계가 얼어 기록이 빠졌다면, 낮은 값만 골라 사라진 셈이라 남은 데이터가 실제보다 따뜻해 보입니다. 남은 데이터만 보아서는 이 왜곡을 알아챌 방법조차 마땅치 않습니다.

갈래예빼고 분석하면
우연히 빠짐아무 날이나 드문드문 기록 누락안전 — 남은 데이터가 전체의 축소판
사정 때문에 빠짐특정 시기에 장비가 자주 고장그 사정을 감안하면 다룰 수 있음
값 때문에 빠짐몹시 추운 날마다 기계가 얼어 누락위험 — 남은 데이터가 실제보다 따뜻해 보임

그렇다면 한국전쟁 결측은 어느 갈래일까요? 빠진 이유는 전쟁이고, 전쟁이 그해의 기온을 바꾸지는 않았습니다. 곧 기온이라는 값과 무관한 이유로 빠졌으므로, 우연히 빠진 경우와 같게 다룰 수 있습니다. 전쟁기 연도를 빼고 남은 해로 추세를 재도 결론이 뒤틀리지 않는다는 뜻이고, 이것이 오늘 전처리의 통계적 근거입니다.

반쪽 관측이 평균을 왜곡하는 원리

1953년의 0.6℃는 틀린 측정이 아닙니다. 그해 관측된 31일은 전부 겨울이었고, 그 겨울 기온의 평균으로는 정직한 값입니다. 문제는 이름입니다. 연평균이라면 봄·여름·가을·겨울이 골고루 들어간 평균이어야 하는데, 겨울만 잰 평균이 "연평균"이라는 같은 이름을 달고 다른 해들과 한 줄에 섰습니다. 겨울만 재면 낮게 나오는 것은 당연합니다. 2차시의 언어로 말하면 재료(표본)가 뒤바뀐 평균이고, 평균은 이런 오염에 무방비입니다. 그래서 처방도 값을 고치는 것이 아니라, 애초에 연평균이라는 이름을 달 자격이 없는 해를 걸러 내는 것이 됩니다.

빼기와 채우기 — 무엇이 더 정직한가

빈 칸을 다루는 길은 크게 둘입니다. 빼거나, 채우거나. 채우는 쪽이 얼핏 친절해 보입니다. 1951·1952년을 앞뒤 해의 평균으로 채우면 그래프의 선도 이어집니다. 그러나 그것은 있지도 않은 관측을 지어내는 일입니다. 채운 값은 새 정보가 아니라 이미 있는 값의 복사본이라, 데이터가 실제보다 확실한 척하게 만듭니다. 이 수업의 선택은 빼기입니다. 정직하게 비워 두고 비운 이유를 밝히는 쪽이 더 엄밀하기 때문입니다.

믿을 수 없는 값 제거와 불리한 값 제거

그럼 빼는 것은 늘 정당할까요? 아닙니다. 기준이 갈림길입니다. "관측일 300일 미만인 해 제외"는 기온 값을 보기 전에 정할 수 있고 누구에게나 같은 잣대라서, 믿을 수 없는 값을 거르는 정당한 전처리입니다. 반대로 결과 그래프를 본 뒤 추세를 약하게 만드는 해만 골라 뺀다면, 같은 삭제라도 불리한 값 제거, 곧 조작이 됩니다. 무엇을 뺐느냐가 아니라 어떤 기준으로 뺐느냐가 전처리와 조작을 가릅니다.

2. 지난 차시 구멍 2개

  • ① 1950년대 초 = 선이 끊김(1951·1952 값 없음) · ② 1953년 = 뚝 떨어진 점(0.6℃)
  • 오늘 → 이 구멍들의 정체를 밝히고, 어떻게 다룰지 정한다

3. 구멍의 정체 ① — 한국전쟁 결측

🕵️ 1950~1953년이 비어 있는 까닭
  • 1950년 9월~1953년 11월, 한국전쟁으로 서울 관측이 중단됐다
  • 1951·1952년은 유효한 관측이 0일 · 그래서 연평균이 아예 없다
  • 기온이 안 변한 게 아니라 기록하는 사람이 없었다 · "데이터에도 역사가 있다"

4. 구멍의 정체 ② — 1953년 반쪽 관측

🕵️ 1953년 연평균 0.6℃의 진짜 이유
  • 관측이 그해 12월 31일치 하루만 재개됨 · 1953년 관측일은 31일뿐(겨울만)
  • 여름 값이 통째로 빠지니 겨울 평균이 연평균으로 둔갑 → 0.6℃
  • 지구가 추워진 게 아니라 반쪽만 잰 데이터 · 평균이 왜곡된 것

5. 믿을 수 있는 해만 남기기 (①②③)

정체를 밝혔으니 이제 처방입니다. 1번에서 정한 원칙 — 값을 보기 전에, 누구에게나 같은 잣대로 — 을 그대로 실행합니다.

  • 해결책 = 관측일이 부족한 해를 뺀다 · 기준은 300일(1년의 대부분)
  • 진행 중인 올해도 아직 미완성이니 함께 뺀다
① 샘플 프롬프트
관측일이 300일보다 적은 해는 평균을 믿기 어려우니, 그런 해를 빼고
연평균 추세를 다시 그려 줘. 진행 중인 올해도 빼 줘.
데이터는 여기야: https://raw.githubusercontent.com/greatsong/modudata/main/data/seoul.csv
  • 여러분 화면이 이런 모습이면 성공 · 글자까지 같을 필요 없음
② AI가 준 코드 예시
import streamlit as st
import pandas as pd
import plotly.express as px

st.title("🧹 관측일로 거른 연평균 추세")

url = "https://raw.githubusercontent.com/greatsong/modudata/main/data/seoul.csv"
df = pd.read_csv(url)
df["연도"] = pd.to_datetime(df["날짜"]).dt.year

# 연도별 평균과 '관측일 수'를 함께 구하기
yearly = df.groupby("연도")["평균기온"].agg(["mean", "count"]).reset_index()

# 진행 중인 올해 제외 + 관측일 300일 미만인 해 제외
keep = (yearly["연도"] < df["연도"].max()) & (yearly["count"] >= 300)
clean = yearly[keep]

st.write(f"거르기 전 {len(yearly)}개 해 → 거른 뒤 {len(clean)}개 해")
fig = px.line(clean, x="연도", y="mean", title="관측일 300일 이상인 해만")
st.plotly_chart(fig, use_container_width=True)
  • 깨끗해진 그래프가 뜨면 → 세 박자대로 ③ 개선으로 전후를 비교
③ 프롬프트 개선 예시
좋아! 빼기 전과 뺀 후 그래프를 나란히 놓아서
어떻게 달라졌는지 한눈에 보이게 해 줘.
✔️ 발견 (★) — 무엇이 달라졌나
  • 거르기 전 118개 해 → 거른 뒤 114개 해(1908~2025)
  • 1953년의 0.6℃ 점이 사라지고 추세가 매끈해진다 · 이상치가 직선을 끌어내리던 게 빠짐
  • 데이터를 줄였는데 오히려 더 믿을 만해진다
💡 전처리는 조작이 아니다
  • 학생 질문 "데이터를 마음대로 빼도 되나요?"
  • 핵심 = "믿을 수 없는 값을 빼는 것"과 "불리한 값을 빼는 것"은 다르다
  • 300일 기준은 누구에게나 같은 잣대 · 결과가 마음에 안 든다고 빼는 게 아님 · 그래서 정당하다
📝 수행평가 예고 — 전처리 판단 서술
  • 결측(한국전쟁)과 이상치(1953년 반쪽 관측)를 구분해 원인을 적기
  • 관측일 300일 기준을 왜 정당하다고 보는지 내 말로 설명하기

6. 개념으로 다시 읽기 — 오늘 만난 숫자 세 개

오늘 확인한 숫자를 1번의 개념 언어로 다시 읽어 봅니다.

숫자개념으로 읽으면
0일1951·1952년의 유효 관측 — 기온이 변한 게 아니라 기록이 없었다. 빠진 이유(전쟁)가 기온과 무관하니 우연히 빠진 경우와 같게 다뤄, 빼고 분석해도 안전하다
31일1953년의 관측일, 전부 겨울 — 재료(표본)가 뒤바뀐 평균이 "연평균" 이름을 달고 0.6℃를 만들었다
118 → 114값을 보기 전에 정한 같은 잣대(300일)로 걸러 낸 결과 — 믿을 수 없는 값 제거이지 불리한 값 제거가 아니다

7. 해보기 — 개인 또는 팀

✏️ 개인 미션 — 기준을 바꿔도 결론이 버티나 (10분)
  • ③ 개선 프롬프트에 이어, 관측일 기준 300일을 250일과 350일로 바꿔 다시 걸러 달라고 주문한다
  • 남는 해의 개수를 기록한다: 250일 → ( ) · 300일 → 114 · 350일 → ( )
  • 마지막 한 줄: "기준을 바꿔도 우상향 추세는 버티는가?" 내 판단을 적는다
🗣️ 팀 미션 — 채울 것인가, 비울 것인가 (2~3인 토의, 7분)
  • 토의 질문: "1951·1952년 빈 자리를 앞뒤 해의 평균으로 채워 선을 잇자는 제안에 찬성하는가?"
  • 각자 입장을 근거와 함께 한 문장으로 적는다 (예: "채운 값은 지어낸 관측이라 반대한다" / "흐름을 보는 데는 도움이 되니 채우되 채웠다고 표시하자")
  • 입장이 갈리면 성공이다 — 1번의 기준, 채운 값은 새 정보가 아니라 복사본이라는 사실로 돌아가 정리한다
🧾 이 기록이 수행평가 재료가 된다
  • 오늘의 기록 — 결측(전쟁)과 이상치(반쪽 관측)의 구분, 300일 기준이 정당한 이유 — 는 수행평가 (b) 전처리 판단 서술에 그대로 쓰인다. 남의 문장이 아니라 내 말로 적어 둘 것.

8. 확인 문제

지필 문항과 같은 유형입니다. 먼저 스스로 답을 적고 나서 펼쳐 보세요.

문제 1 — "믿을 수 없는 값 제거"와 "불리한 값 제거"의 차이를 서술하시오.

예시 답안 — 믿을 수 없는 값 제거는 결과를 보기 전에 정한, 누구에게나 같은 기준(예: 관측일 300일 미만)으로 거르는 정당한 전처리다. 불리한 값 제거는 결과를 본 뒤 자기 결론에 불리한 값만 골라 빼는 조작이다. 무엇을 뺐느냐가 아니라 어떤 기준으로 뺐느냐가 둘을 가른다.

문제 2 — 1953년의 연평균이 0.6℃로 기록된 과정을 관측일 수를 근거로 서술하시오.

예시 답안 — 그해 관측일은 31일뿐이고 전부 겨울이었다. 사계절이 골고루 들어가야 할 연평균 자리에 겨울만의 평균이 들어가면서 낮은 값 0.6℃가 "연평균"이라는 이름을 달게 되었다. 틀린 측정이 아니라 재료(표본)가 뒤바뀐 평균이다.

문제 3 — 1951·1952년 결측을 빼고 추세를 분석해도 결론이 뒤틀리지 않는 이유를 "왜 빠졌는가"를 들어 서술하시오.

예시 답안 — 이 결측의 원인은 한국전쟁이고, 전쟁이 그해의 기온을 바꾸지는 않았다. 기온이라는 값과 무관한 이유로 빠졌으므로 우연히 빠진 경우와 같게 다룰 수 있고, 남은 해로 추세를 재도 결과가 한쪽으로 치우치지 않는다.

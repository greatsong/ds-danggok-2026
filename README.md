# 데이터 과학 웹 교재 (고등학교 2022 개정)

당곡고등학교 2026학년도 2학기 『데이터 과학』 수업에서 실제로 쓰는 학생용·교사용 웹 교재입니다. 코드는 AI에게 맡기고 학생은 **질문 설정·데이터 감식·결과 해석·한계 인식**을 배우는 바이브 코딩 수업으로 설계했습니다.

**교재 보기** → <https://greatsong.github.io/ds-danggok-2026/>
**다른 학교에서 쓰기** → [포크와 커스텀 안내서](https://greatsong.github.io/ds-danggok-2026/fork-guide.html)

빌드 도구가 없습니다. HTML·CSS·JavaScript 파일을 GitHub Pages가 그대로 서빙합니다. 파일을 고치고 커밋하면 1~3분 뒤 반영됩니다.

## 선생님을 위한 안내

### 무엇이 들어 있나

| 폴더·파일 | 내용 |
|---|---|
| `lesson01~14.html` | 학생용 14차시. 각 차시는 개념 → 실습(①샘플 프롬프트 → ②AI가 준 코드 → ③개선) → 발견 → 판단 → 정리 → 확인 문제 구조 |
| `lessonNN-deep.html` | 같은 차시의 자세한 판. 본문이 거의 같고 설명이 더 붙습니다 |
| `extra-*.html` | 심화·자유 실습 (영화 API, 모델 도감, 가설 검증) |
| `concepts·glossary·study-guide·eval-workbook.html` | 시험 대비 자료 4종 |
| `teacher/` | 차시별 진행안 14개, 이론 지도서, 수업용 슬라이드, 개강 전 안내 |
| `gallery/` | 학생 작품 갤러리 (수파베이스 연동, 안 쓰면 데모 모드) |
| `assets/` | 스타일과 스크립트. 차시 공개 잠금(`release.js`·`gate.js`) 포함 |

### 수업 데이터

기온·영화·야구 데이터는 [greatsong/modudata](https://github.com/greatsong/modudata)에 있고 교재가 주소로 직접 읽습니다. 급식은 나이스 API를 실시간으로 호출합니다. **급식만 학교마다 다르고 나머지는 전국 공개 자료**라 어느 학교에서든 그대로 쓸 수 있습니다.

### 차시 공개 잠금

진도보다 앞선 차시는 학생 화면에서 잠깁니다. `assets/release.js`의 숫자 한 줄이 공개 범위를 정합니다.

```js
window.RELEASED_LESSON = 6;   // 6차시까지 열림
```

교사는 주소 뒤에 `?teacher=열쇠`를 한 번 붙여 전체를 열 수 있습니다(해제는 `?teacher=off`). 이 잠금은 브라우저 안에서만 도는 장치라 **보안이 아니라 진도 조절용**입니다. 정말 감춰야 할 자료는 이 저장소에 올리지 마십시오.

### 다른 학교에서 쓰려면

[포크와 커스텀 안내서](https://greatsong.github.io/ds-danggok-2026/fork-guide.html)에 화면 그림과 함께 정리했습니다. 가장 급한 것만 적으면 이렇습니다.

1. **`gallery/config.js`를 먼저 확인하십시오.** 그대로 두면 학생 작품이 당곡고 데이터베이스로 갑니다.
2. `assets/release.js` — 우리 반 진도로
3. `assets/gate.js` — 교사 열쇠를 내 것으로
4. 급식 학교 코드(`B10`·`7010073`) — 우리 학교 나이스 코드로
5. 학교 이름 — 긴 것부터(당곡고등학교 → 당곡고 → 당곡)

### 라이선스와 인용

교재 본문에는 광주광역시교육감 인정 교과서 『데이터 과학』의 정의가 쪽수와 함께 인용되어 있습니다. 인용 부분의 권리는 원저작자에게 있습니다. 그 밖의 본문·코드·그림은 자유롭게 고쳐 쓰셔도 됩니다. 수업에 쓰셨다면 어떻게 쓰셨는지 알려 주시면 서로 도움이 됩니다.

## AI 에이전트를 위한 안내

이 저장소를 수정하는 에이전트는 아래를 지켜 주십시오. 실제 사고에서 나온 규칙입니다.

### 이 저장소의 성격

- **빌드 없는 정적 사이트.** 저장소 루트가 곧 사이트 루트입니다. `main`에 커밋하면 GitHub Pages가 1~3분 뒤 배포합니다.
- **학생이 읽는 교재입니다.** 문장 하나가 수업 중 학생 화면에 그대로 뜹니다. 임시 코드나 실험을 커밋하지 마십시오.
- `.nojekyll`은 지우면 안 됩니다. 0바이트 빈 파일이지만 없으면 배포가 깨집니다.

### 편집 규칙

1. **정규식·`sed`로 일괄 치환하지 마십시오.** 정확한 문자열을 하나씩 교체하십시오. 과거에 정규식 치환으로 본문 절과 확인 문제가 통째로 사라진 사고가 있었습니다.
2. **고치기 전후로 구조 개수를 세십시오.** 줄었으면 무언가를 잘못 지운 것입니다.
   ```bash
   grep -c '<h2>\|class="qn"\|codewrap' lesson06.html
   ```
3. **학생용과 자세한 판을 짝으로 고치십시오.** `lessonNN.html`과 `lessonNN-deep.html`은 본문이 거의 같습니다. 한쪽만 고치면 같은 차시가 두 가지를 말합니다. 저장소의 급식 수치 불일치(154일/184일)가 이렇게 생겼습니다.
4. **숫자를 일괄 치환하지 마십시오.** `216`은 영화 편수·표의 행 수·나눗셈 값으로, `114`는 화면 좌표로도 쓰입니다.
5. 교사용(`teacher/`)을 고치면 학생용도 어긋나지 않는지 확인하십시오. 시간표·프롬프트 번호·파일명이 서로 물려 있습니다.

### 문체 규칙

- 합쇼체(`~합니다`)로 통일합니다. 확인 문제 선택지와 체크리스트만 `~다`로 끝냅니다.
- **대시(—)로 문장을 잇지 않습니다.** 제목의 대시는 괜찮습니다.
- 은유·의인화·과장·구어체를 쓰지 않습니다. 명사구 종결과 슬로건투 문장도 쓰지 않습니다.
- 실습 프롬프트(`①`·`③` 블록)에는 **코드 문법과 계산 절차를 넣지 않습니다.** 함수명·파라미터·라이브러리 표기 금지입니다. 판별 기준은 "이 문장을 빼면 AI가 틀리는가, 아니면 다르게 만드는가"이며, 다르게 만들 뿐이면 뺍니다.
- 앞 차시에 만든 앱이나 파일을 이어 쓴다는 서술을 넣지 마십시오. **앱은 차시마다 독립**입니다. 배운 내용의 연계("8차시에 손계산합니다")는 괜찮습니다.

### 수치를 다룰 때

교재 본문·표·확인 문제 정답에는 실제로 계산해 얻은 값이 박혀 있습니다. 예를 들어 6차시의 `+2.60℃/100년`, `+8.14`, `114개 연도(1908~2025)`, 8차시의 `R² 0.70 ↔ 0.39`, 9차시의 기준선 `89%`입니다.

- **수치를 바꾸려면 실제로 계산해서 확인하십시오.** 추정하지 마십시오.
- 한 수치는 여러 파일에 흩어져 있습니다(학생용·자세한 판·교사용·시험 대비 자료·활동지). 한 곳만 고치면 어긋납니다.
- 데이터를 바꾸면 수치만이 아니라 **그 수치가 만드는 수업 장면**이 성립하는지 봐야 합니다. 예를 들어 8차시는 "전처리가 성능을 떠받친다"를 가르치는데, 새 데이터에서 필터를 껐는데도 점수가 안 떨어지면 숫자를 정확히 바꿔도 수업이 성립하지 않습니다.

### 커스텀 지점 (다른 학교용으로 고칠 때)

| 파일 | 값 | 비고 |
|---|---|---|
| `gallery/config.js` | `SUPABASE_URL`·`SUPABASE_KEY` | **가장 먼저.** 안 바꾸면 학생 데이터가 원본 학교 DB로 갑니다 |
| `gallery/app.js`, `gallery/*.sql` | 학교 메일 도메인 `danggok.hs.kr` | 화면 쪽과 SQL 쪽 **양쪽** 모두. 한쪽만 고치면 조용히 실패합니다 |
| `gallery/schema.sql` | 반 이름 `'B'`, `'E'` | DB 제약·필터·제출 화면 네 곳 |
| `assets/release.js` | `RELEASED_LESSON` | 공개 차시 |
| `assets/gate.js` | `KEY_HASH`, 잠금 화면 제목의 학교 이름 | 해시는 djb2 변형(`v = ((v*33) ^ c) >>> 0`, 초깃값 5381) |
| `lesson05·05-deep·12.html`, `data.html` | 나이스 코드 `B10`(교육청)·`7010073`(학교) | 급식 API |
| 전 파일 | 학교 이름 | **긴 것부터**: 당곡고등학교 → 당곡고 → 당곡 |
| `lesson12.html` 등 | 급식 실측 수치 | 학교 코드를 바꾸면 반드시 다시 계산 |

### 건드리면 안 되는 것

- **"서울 기온"의 "서울"** — 학교 지역이 아니라 기상청 전국 공개 데이터입니다. 1·6·7·8차시의 수치와 정답이 여기 묶여 있습니다. 바꿔야 할 "서울"은 급식 교육청 코드 설명뿐입니다.
- **저장소 이름을 `teacher`로 짓는 것** — 주소가 `/teacher/...`가 되어 `gate.js`가 사이트 전체를 잠급니다.
- **교과서 인용문** — `tbquote` 안의 `<p class="q">`는 원문 그대로입니다. 쪽수와 함께 손대지 마십시오.
- **`.nojekyll`**

### 확인 방법

```bash
# 문체 스캔 (금지 표현과 프롬프트 안 코드 문법)
python3 <문체 스캔 스크립트> .

# 잠긴 차시가 제대로 잠기는지, 링크가 살아 있는지는 브라우저에서 확인
python3 -m http.server 4098
```

수정 뒤에는 해당 페이지를 실제로 열어 **확인 문제 클릭 판정**과 **복사 버튼**이 동작하는지 보십시오. 외부 서비스에 붙는 5차시 급식 화면과 갤러리 제출은 화면만 보고는 알 수 없으므로 직접 눌러 확인해야 합니다.

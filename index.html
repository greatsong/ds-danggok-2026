코드는 AI가 짜고, 학생은 데이터를 의심하고 판단한다.
이 수업의 한 줄 정의

교과서의 흐름을 따라 데이터 과학의 개념을 배우고, 실습은 우리 곁의 데이터로 합니다. 100년 서울 기온, 오늘의 급식, 어제의 박스오피스가 API로 내 앱에 들어옵니다. 코드 문법은 외우지 않아도 됩니다. AI에게 자연어로 주문하고, 나온 결과가 정말 맞는지 스스로 확인하는 연습이 이 수업의 중심입니다.

🎯 이 수업에서 배우는 네 가지 판단
  • 질문 설정 — 데이터로 답할 수 있는 질문을 세운다
  • 데이터 감식 — 표의 구멍·이상치·편향을 알아챈다
  • 결과 해석 — 모델이 낸 값을 내 말로 설명한다
  • 한계 인식 — 어디까지 믿을 수 있는지 선을 긋는다

🗺️ 진행 지도

교과서 대단원 순서를 따라갑니다. 4차시에 배포한 앱 하나에 페이지를 계속 추가해, 학기말에는 각자의 데이터 포트폴리오 앱이 완성됩니다.

묶음차시배우는 것내 앱에 쌓이는 것
기초 (Ⅰ·Ⅱ)1~4분석 6단계 · 데이터의 종류와 수집 · 기온 데이터 탐색과 전처리 판단포트폴리오 앱 개설 + 기온 페이지 (4차시)
API (Ⅱ)5~6반정형 데이터 실전 · 우리 학교 급식과 박스오피스 · 데이터 통합급식 페이지 (5) · 영화 페이지 (6)
모델링·평가 (Ⅲ)7~11회귀와 다중회귀 · 분류 · 손계산 활동지 2회(오차·R² / 혼동행렬)기온 예측기 (7) · 흥행 분류기 (10)

✍️ 손계산 활동지

세 번의 평가 차시(9·11·13)에는 손계산 활동지가 있습니다. 첫 문제는 교과서의 해 보기 활동이고, 이어지는 문제는 수업 데이터로 만든 연습입니다. AI가 보여 주는 점수(R²·정확도·향상도)를 직접 계산해 검산할 수 있는 사람이 되는 것이 목표입니다. 활동지는 수업 시간에 배부됩니다.

🤝 팀 프로젝트 예고

공통 15차시와 중간고사가 끝나면 2~3인 팀 프로젝트가 별도로 시작됩니다. 15차시에서 팀을 구성하고 주제 후보를 정합니다. 자세한 안내는 그때 함께 열립니다.

📚 데이터 출처

분석은 데이터가 어디서 왔는지 밝히는 데서 시작합니다. 이 교재가 쓰는 데이터의 출처입니다.

🔎 이 교재가 쓰는 데이터
  • 공공데이터 수집 체험(2차시): 공공데이터포털
  • 서울 기온(3~4·7차시): 기상청 종관기상관측(ASOS) · 기상자료개방포털
  • 학교 급식(5·13차시): 나이스 급식식단정보 API · 나이스 교육정보 개방 포털
  • 영화 박스오피스(6·8·10~11차시): 영화진흥위원회 오픈API · KOBIS 영화관입장권통합전산망
  • 선수 기록(12차시): 데이터 확정 후 이 자리에서 안내합니다
  • 수업용으로 정리한 사본 일부는 modudata에 있습니다.
🔎 이 출처를 믿어도 될까 — 신뢰도를 가리는 4가지

출처 이름을 아는 것에서 한 걸음 더 나아가, 믿을 만한 출처인지 스스로 따져 보는 것이 데이터 감식의 시작입니다. 네 가지만 확인하면 됩니다.

  • 누가 만들었나 — 정부·공공기관·연구기관처럼 책임 소재가 분명한 곳인가
  • 어떻게 모았나 — 표준 장비·공식 절차로 측정·집계했나, 아니면 누군가의 어림짐작인가
  • 공개·검증되나 — 공식 포털에 누구나 확인할 수 있게 공개되고, 이용 조건(라이선스)이 밝혀져 있나
  • 계속 관리되나 — 한 번 올리고 방치된 자료가 아니라, 책임 기관이 정기적으로 갱신·관리하나

이 교재의 주요 데이터는 네 가지를 모두 충족합니다. 기상청·교육부(나이스)·영화진흥위원회는 각 데이터를 직접 관측·집계하는 국가·공공기관이고, 모두 공식 포털에 공개해 정기적으로 갱신합니다.

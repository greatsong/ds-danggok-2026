"질문이 데이터를 결정한다 — 데이터를 고르는 것부터가 분석이다."
1차시에서 질문을 던졌다면, 오늘은 그 질문에 맞는 데이터를 고릅니다

지난 시간에 만든 질문 카드를 다시 꺼냅니다. 그 질문에 답하려면 데이터가 필요합니다. 오늘은 데이터에 어떤 형태가 있는지 구분하는 눈을 갖추고, 누구에게나 열려 있는 공공데이터포털에서 관심 분야의 데이터를 직접 내려받아 첫인상을 기록합니다. 내려받은 파일은 AI에게 요약을 맡겨 봅니다.

🎯 오늘 하는 것
  • 형태 구분 — 정형·반정형·비정형을 교실 안 사례로 가려내기
  • 수집 실습 — data.go.kr에서 관심 분야 데이터 1개 내려받기
  • 첫 요약 — 내려받은 파일을 AI에게 표로 정리시키기 (①③)

0. 왜 배우나

데이터 분석의 두 번째 단계는 수집입니다. 그런데 수집은 "많이 모으기"가 아닙니다. 교과서 48쪽의 페트병 사례가 이것을 보여 줍니다 — 비닐이 있는 페트병과 없는 페트병을 구분하는 인공지능을 만들려면, 페트병에 남은 내용물의 양 같은 특성이 아니라 비닐 제거 유무를 담은 데이터가 필요합니다. 문제와 맞지 않는 데이터는 아무리 모아도 소용이 없습니다.

세상의 데이터는 생김새도 제각각이어서, 내 질문에 맞는 것을 골라내는 눈이 먼저 필요합니다. 다행히 정부와 공공 기관은 교통·환경·건강·문화 등 수많은 분야의 데이터를 무료로 공개하고 있습니다. 그 문을 오늘 처음 열어 봅니다. 진로가 어느 쪽이든, 그 분야의 공공 데이터가 이미 어딘가에 쌓여 있을 가능성이 큽니다.

1. 개념 이해 — 데이터의 세 가지 형태

📖 교과서의 정의 『데이터 과학』 19·20쪽

"정형 데이터(structured data)는 데이터의 속성이나 구조가 명확하고 체계화된 데이터를 말한다." (19쪽)

"비정형 데이터(unstructured data)는 구조를 명확하게 정의하기 어려운 데이터를 말한다." (20쪽)

"반정형 데이터는 일부분이 정형화된 데이터로, 구조가 존재하지만 구조를 바꿀 수도 있는 유연한 형태의 데이터를 말한다." (20쪽)

→ 행과 열이 반듯하면 정형, 구조가 아예 자유로우면 비정형, 구조는 있되 표는 아니면 반정형.

정형 데이터의 대표는 행과 열로 이루어진 표입니다. 각 열은 데이터의 특정 속성을 나타내고, 각 행은 구체적인 값 하나하나입니다. 교과서 19쪽의 일별 박스 오피스 표가 좋은 예입니다 — 영화명·개봉일·매출액이 열이고, 영화 한 편이 행 하나입니다(이 표의 친척을 6차시에 API로 직접 받게 됩니다). 속성이 명확해 수집·관리가 쉬워서 기업과 공공 기관에서 널리 쓰입니다.

비정형 데이터는 이미지·텍스트·음성·영상처럼 구조의 제약 없이 자유롭게 표현된 데이터입니다. 명확한 속성이 정의되어 있지 않지만 버려지는 것은 아닙니다 — 교과서 20쪽은 영화 댓글 리뷰를 숫자로 변환해 영화의 새로운 속성으로 쓰는 예를 듭니다. 가공하면 속성을 추출할 수 있습니다.

그 사이에 반정형 데이터가 있습니다. XML과 JSON이 대표적으로, 구조를 쉽게 바꿀 수 있고 필요하면 표 형태로 변환할 수 있어 데이터 공유에 많이 쓰입니다. 공공데이터포털에도 XML·JSON 형태의 파일이 많이 올라와 있습니다.

말보다 실물이 빠릅니다. 2025년 9월 2일의 당곡고 급식 하나가 세 가지 모습으로 기록된 것을 나란히 놓고 봅니다. 셋 다 같은 급식입니다.

정형 — 표 (CSV 파일)
날짜식사메뉴
20250901중식칼슘강화기장밥|쇠고기미역국|…
20250902중식친환경현미밥|근대된장국|제육볶음|…
20250903중식⋮
행과 열이 반듯한 표. 열이 속성, 행이 하루입니다. 표 그대로 분석에 들어갑니다.
반정형 — JSON (급식 API 응답)
{
  "MLSV_YMD": "20250902",
  "MMEAL_SC_NM": "중식",
  "DDISH_NM": "친환경현미밥
    <br/>근대된장국
    <br/>제육볶음 …",
  "CAL_INFO": "… Kcal"
}
표는 아니지만 "라벨": 값의 구조가 있음. 표로 변환해 씁니다 — 5차시에 직접 받습니다.
비정형 — 사진 (급식 사진)
행도 라벨도 없는 이미지. 그대로는 분석할 수 없고, 가공해야 속성(메뉴·양)을 꺼낼 수 있습니다.

같은 하루인데 담긴 그릇이 다릅니다. 수업에서 만나는 때와 함께 정리하면 이렇습니다.

형태위의 실물다루는 법우리 수업에서 만나는 때
정형CSV 식단표표 그대로 분석오늘부터 — 내려받는 파일 대부분
반정형JSON 응답표로 변환해 분석5·6차시 — API로 데이터를 받을 때
비정형급식 사진가공해 속성 추출팀 프로젝트에서 만날 수 있음

속성 — 데이터의 가치를 정하는 열

정형 데이터에서 표의 각 열이 가지는 특성과 성질을 속성이라고 부릅니다. 교과서 21쪽의 도서관 표가 보여 주듯, 같은 데이터라도 "가장 가까운 도서관은 어디인가"를 물으면 위도·경도 속성이 중요해지고, "언제 가면 열려 있나"를 물으면 휴관일·시작 시각 속성이 중요해집니다. 어떤 속성이 가치 있는지는 데이터가 아니라 질문이 정합니다. 문제 해결에 필요한 새로운 속성이 더해지면 데이터의 가치가 높아질 수도 있습니다 — 1차시의 결론("질문이 뒤 단계의 모양을 정한다")이 여기서 한 번 더 확인됩니다.

질문 ① 가장 가까운 도서관은 어디인가
도서관명 위도 경도 휴관일 운영 시작 시각
……………
……………
거리를 재려면 위도·경도 열이 가치 있는 속성이 됩니다.
질문 ② 언제 가면 열려 있나
도서관명 위도 경도 휴관일 운영 시작 시각
……………
……………
같은 표인데 질문이 바뀌자 가치 있는 열이 바뀌었습니다.

속성의 가치는 데이터가 아니라 질문이 정한다 (『데이터 과학』 21쪽).

2. 수집 실습 — 공공데이터포털에서 내 데이터 찾기

📖 교과서의 기준 『데이터 과학』 48쪽

"데이터를 수집할 때는 문제를 해결하기 위한 목적과 일치해야 한다." (48쪽)

→ 검색창에 넣을 말은 유행어가 아니라 내 질문이다. 목적에 맞지 않는 데이터는 아무리 커도 재료가 되지 못한다.

목적과의 일치 말고도, 교과서 48~49쪽은 좋은 데이터의 조건을 몇 가지 더 제시합니다. 데이터를 고를 때의 점검표로 요약해 둡니다.

조건점검하는 물음
목적에 알맞은가내 문제(질문)와 직접 관련된 데이터인가
양이 충분한가판단의 근거가 될 만큼 많은가, 한쪽으로 치우치지 않았는가
골고루 수집되었는가특정 출처·집단에만 쏠려 편향되지 않았는가
시기가 알맞은가지금의 상황을 반영하는 시기의 데이터인가
형태가 알맞은가분석에 쓸 수 있는 형태로 되어 있는가(또는 가공할 수 있는가)

공공데이터포털(data.go.kr)은 공공 기관의 데이터를 누구나 쓸 수 있게 정부에서 운영하는 사이트입니다. 정형·반정형·비정형 데이터가 모두 제공됩니다. 서울 지역 데이터는 서울열린데이터광장에서도 찾을 수 있습니다.

  1. 검색 — 질문 카드의 핵심 단어로
    지난 시간 질문 카드에서 핵심 단어를 뽑아 검색합니다. 결과 목록에서 파일 형식(CSV·JSON·XML 등)과 제공 기관을 확인합니다. 회원가입 없이 바로 받을 수 있는 파일부터 시작합니다 — 선생님이 예시 목록을 안내합니다.
  2. 내려받기 — CSV 1개
    정형 데이터(CSV) 1개를 내려받아 엽니다. 행이 몇 개인지, 열(속성)에는 무엇이 있는지, 어느 기간의 데이터인지 훑어봅니다.
  3. 기록 — 첫인상과 질문
    "이 데이터로 답할 수 있는 질문 1개"를 기록합니다. 처음 질문 그대로일 수도, 데이터를 보고 나서 더 좋은 질문으로 바뀔 수도 있습니다. 이 기록이 폼 Ⅱ-01c의 재료가 됩니다.
⚠️ 오늘의 발견 — 같은 주제, 다른 생김새

같은 "미세먼지"를 검색해도 기관마다 파일 형식이 다르고, 다루는 기간이 다르고, 담긴 속성이 다릅니다. "정답 파일"이 준비되어 있는 것이 아니라, 내 질문에 맞는 데이터를 고르는 일부터가 분석입니다. 어떤 파일을 고를지 판단한 이유를 기록에 남겨 두세요.

🔭 수집 방법은 내려받기만이 아니다

파일을 내려받는 것 말고도 데이터를 모으는 길은 여럿입니다 — 설문으로 직접 묻기, 휴대폰 카메라로 직접 찍기, 그리고 5차시에 만날 API로 받기. 방법마다 걸리는 시간과 얻는 형태가 다릅니다. 이 비교는 폼 Ⅱ-04b에서 정리합니다.

💡 한글이 깨져 보인다면

공공데이터 파일 중에는 열었을 때 한글이 깨져 나타나는 것이 있습니다. 파일이 잘못된 것이 아니라 글자를 저장한 방식(인코딩)이 다른 것으로, 이것도 데이터의 상태입니다. 다음 절에서 AI에게 파일을 맡길 때 "한글이 깨지면 인코딩을 바꿔서 읽어 줘"라고 덧붙이면 해결됩니다.

3. 실습 — 내려받은 파일을 AI에게 요약시키기 (①③)

내려받은 파일이 무엇을 담고 있는지, 오늘은 AI에게 물어봅니다. 지난 시간 선생님 시연으로만 본 리듬을 처음으로 직접 밟는 순간입니다. 배포도 코딩도 없습니다 — 파일을 주고, 우리말로 요청하고, 결과를 읽습니다.

  1. ① 샘플 프롬프트 — 그대로 붙여 넣기
    ① 프롬프트
    방금 내려받은 파일을 읽어서 행이 몇 개인지, 어떤 열이 있는지,
각 열이 무엇을 뜻하는 것 같은지 표로 정리해 줘.
  2. ② AI의 답 — 표를 읽고 검증한다
    AI가 정리한 표가 나타나면, 아까 직접 훑어본 내용과 맞는지 확인합니다. 행 수가 일치하는지, 열 설명이 그럴듯한지 — AI의 답을 그대로 믿지 않고 견주어 보는 것이 우리의 일입니다.
  3. ③ 개선 프롬프트 — 빠진 값을 물어본다
    ③ 개선
    빠진 값이 있는 열과 그 개수도 함께 알려 줘.
    빠진 값(결측)이 있다는 답이 나와도 놀랄 일이 아닙니다. 실제 데이터에는 빠진 값이 있는 것이 보통이고, 그것을 다루는 법이 3차시의 주제입니다.
✅ 오늘 익힌 습관 — AI의 답은 견주어 본다

②에서 한 일을 기억해 두세요. AI가 정리한 행 수·열 설명을 그대로 받아 적지 않고, 내가 직접 훑어본 내용과 견주었습니다. 앞으로 모든 실습에서 반복되는 순서입니다 — 먼저 내 눈으로 보고, 그다음 AI의 답과 대조합니다.

4. 정리 — 진로 분야의 데이터 씨앗

오늘 포털에서 스친 데이터 중 진로와 닿는 것이 있었다면 폼 Ⅰ-04c에 기록해 둡니다. 학기말 팀 프로젝트 주제를 정할 때 다시 꺼내게 됩니다.

5. 개념 정리 — 질문에서 데이터로

오늘 배운 것을 한 줄로 줄이면 이렇습니다. 데이터에는 정형·반정형·비정형의 형태가 있고, 그중 무엇을 고를지는 내 질문이 정한다. 같은 주제라도 기관마다 형식·기간·속성이 다르다는 것을 직접 확인했고, 내려받은 파일의 정체를 AI에게 요약시키는 첫 ①③을 밟았습니다. 다음 시간에는 100년 치 서울 기온 데이터(정형)를 그래프로 펼칩니다 — 그래프 한가운데에서 이상한 지점 하나를 만나게 됩니다.

문제 2 같은 도서관 데이터인데, 어떤 사람에게는 위도·경도 속성이 중요하고 어떤 사람에게는 휴관일 속성이 중요합니다. 이런 일이 생기는 이유는 무엇일까요? 자기 말로 답해 본 뒤 펼쳐 보세요.

속성의 중요성은 문제 상황(질문)에 따라 달라지기 때문입니다. 가까운 도서관을 찾는 질문에는 위도·경도가, 언제 갈지 정하는 질문에는 휴관일·운영 시각이 가치 있는 속성이 됩니다. 속성의 가치는 데이터가 아니라 질문이 정합니다.

문제 3 공공데이터포털에서 같은 주제를 검색했더니 서로 다른 기관의 파일 여러 개가 나왔습니다. 무엇을 기준으로 하나를 골라야 할까요?
수집은 문제 해결의 목적과 일치해야 합니다. 질문이 요구하는 기간을 담았는지, 필요한 속성이 있는지, 다룰 수 있는 형식인지를 견주어 고릅니다. 크기나 인기만으로 고르지 않습니다.

🎒 오늘의 체크

  • 정형·반정형·비정형을 각각 예를 들어 구분할 수 있다.
  • 공공데이터포털에서 관심 분야 데이터 1개를 내려받았다.
  • 내려받은 파일의 행 수·열(속성)·기간을 말할 수 있고, AI의 요약과 견주어 보았다.
  • "이 데이터로 답할 수 있는 질문 1개"를 기록했다.

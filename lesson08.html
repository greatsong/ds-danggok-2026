6차시의 기온 직선, 7차시의 영화 점수 0.24와 0.90. 화면에 떠 있던 그 점수의 정체를 오늘 밝힙니다. 도구는 화려하지 않습니다. 활동지 한 장과 사칙연산 — AI가 보여 주는 R² 점수를 직접 계산해 보면 별것 아닙니다. 그리고 별것 아니라는 것을 아는 사람만 그 숫자를 의심할 수 있습니다.

0. 왜 배우나

지금까지 우리는 모델의 점수를 AI가 계산해 주는 대로 받아 읽었습니다. 그런데 점수의 계산법을 모르면, 점수가 이상할 때 알아챌 방법이 없습니다. 자동차 계기판을 믿더라도 연비 계산법은 알아야 "이 수치가 말이 되나"를 판단할 수 있는 것과 같습니다. 오늘 배우는 세 계산 — 오차, 평균제곱오차, 결정계수 — 은 앞으로 이 수업의 모든 모델(분류·군집까지)을 판정하는 감각의 뿌리가 됩니다.

1. 개념 이해 — 오차에서 R²까지

📖 교과서의 정의 『데이터 과학』 120·131·132쪽

"실젯값과 예측값의 차이를 오차라고 하는데, 두 직선을 비교하여 오차가 더 작은 것을 선택해야 한다." (120쪽)

"평균제곱오차(MSE: Mean Squared Error)는 실젯값과 예측값의 차이를 모두 제곱하여 평균한 값으로, 이 값이 작을수록 예측 성능이 좋다." (131쪽)

"결정 계수(R² score: R-squared score)는 회귀 모델이 실제 데이터와 얼마나 유사하게 예측하고 구체적으로 설명하는지를 나타낸다." (132쪽)

→ 오차는 빗나간 거리, MSE는 그 거리를 제곱해 평균낸 값, R²는 그것을 기준 모델과 비교한 값이다.

🔬 그림으로 예열 — 오차와 제곱

왜 오차를 그냥 더하지 않고 절댓값이나 제곱을 쓰는지, 왜 하필 제곱인지 — 이 물음들은 설명으로 듣는 것보다 계산하다가 직접 부딪히는 편이 훨씬 오래 남습니다. 그래서 오늘은 개념 설명을 여기서 멈추고, 바로 활동지로 갑니다.

2. 손 활동지 — 교과서 해 보기에서 자작 문제까지

✍️ 활동지 문제 1 (교과서 120쪽 해 보기 ①)

교과서 120쪽을 펴고 활동지 문제 1부터 시작합니다. 소설책 쪽수로 독서 시간을 예측하는 두 회귀선이 놓여 있습니다. 그래프만 보면 한쪽이 좋아 보입니다. 그런데 다섯 점의 오차를 전부 계산해 절대오차 합계로 판정하면 — 눈으로 고른 답과 계산으로 고른 답이 갈리는 학생이 적지 않습니다. 눈이 아니라 오차로 판정한다, 이것이 첫 문제의 결론입니다.

이어지는 문제들은 한 계단씩 올라갑니다. 전부 사칙연산만으로 풀리도록 만들어져 있어, 수학 진도와 무관하게 누구나 끝까지 갈 수 있습니다.

💡 활동지 규칙
  • 계산 과정을 지우지 않는다. 과정이 곧 점수다 — 답만 적힌 활동지는 검산할 수 없다.
  • 막히면 표의 빈칸부터 채운다. 오차 계산은 언제나 "실젯값 − 예측값" 한 칸에서 시작한다.
  • 지필평가의 계산 문항은 이 활동지의 흐름 그대로 출제된다.

3. R²의 정체 — 게으른 모델과 비교하기

활동지 문제 4에서 만나는 핵심 장치는 게으른 모델입니다. 데이터를 들여다보지도 않고 매번 평균값만 찍는 모델 — 이것이 R²의 기준선입니다. R²는 내 모델의 제곱오차 합을 이 게으른 모델의 제곱오차 합과 비교합니다. 이해를 위해 가상의 예를 하나만 들면, 평균만 찍었을 때 제곱오차 합이 20인 데이터에서 내 직선의 제곱오차 합이 5라면, R² = 1 − (5 ÷ 20) = 0.75. "내 직선은 평균만 찍는 모델이 내는 오차의 75%를 없앴다"라고 읽습니다.

💡 R² 눈금 읽기
  • 1에 가까움 → 평균 모델의 오차를 대부분 없앴다
  • 0 → 평균만 찍는 것과 다를 바 없다 — 교과서도 "결정 계수가 0에 가깝다면 회귀 모델이 데이터의 평균을 맞추는 정도로 예측했고, 회귀 모델의 유의미성이 떨어진다는 뜻이다"라고 적는다(132쪽)
  • 음수 → 평균만 찍는 게으른 모델보다도 못하다 (활동지 문제 5에서 직접 만들어 본다)

이제 7차시의 0.24가 다르게 읽힙니다. "개봉 전 변수 3종은 처음 보는 영화에서, 평균만 찍기보다 오차를 4분의 1 정도 줄였을 뿐"이라는 뜻이었습니다. R²는 좋다/나쁘다의 절대 점수가 아니라 "무엇 대비 얼마나"의 비교값입니다.

# 관측일 필터를 켜고 끄며 R²가 어떻게 달라지는지 본다
import streamlit as st
import pandas as pd
import numpy as np

DATA_URL = "https://raw.githubusercontent.com/greatsong/modudata/main/data/seoul.csv"


@st.cache_data
def load_all():
    df = pd.read_csv(DATA_URL)
    df["연도"] = pd.to_datetime(df["날짜"]).dt.year
    return df.groupby("연도")["평균기온"].agg(["mean", "count"]).reset_index()


def score(yearly):
    a, b = np.polyfit(yearly["연도"], yearly["mean"], 1)
    pred = a * yearly["연도"] + b
    ss_res = ((yearly["mean"] - pred) ** 2).sum()
    ss_tot = ((yearly["mean"] - yearly["mean"].mean()) ** 2).sum()
    return 1 - ss_res / ss_tot


all_years = load_all().dropna(subset=["mean"])
# 아직 진행 중인 올해는 어느 경우에도 뺀다
all_years = all_years[all_years["연도"] < all_years["연도"].max()]
on = st.toggle("관측일 300일 미만인 해를 뺀다", value=True)
used = all_years[all_years["count"] >= 300] if on else all_years

c1, c2 = st.columns(2)
c1.metric("필터를 켠 경우 R²", f"{score(all_years[all_years['count'] >= 300]):.2f}")
c2.metric("필터를 끈 경우 R²", f"{score(all_years):.2f}")
st.caption(f"지금 쓰는 해: {len(used)}개 · 뺀 해: {len(all_years) - len(used)}개")
⚠️ 발견 — 필터를 끄면 0.70이 0.39로 떨어진다

관측일 필터를 켠 우리 예측기의 R²는 0.70. 필터를 끄는 순간 0.39로 떨어집니다. 범인은 6차시에 필터로 걸러 냈던 1953년 — 겨울 한 달만 관측되어 연평균이 반쪽 값으로 둔갑한 해입니다. 직선에서 멀리 떨어진 이 점의 오차가 제곱되면서(활동지 문제 3에서 확인한 "제곱은 큰 실수에 민감하다") 점수를 끌어내립니다. 모델의 성능은 알고리즘이 아니라 전처리가 지탱하고 있었던 것입니다.

남은 시간에는 교과서 134쪽 해 보기 ③(폼 Ⅲ-02c)으로 단순 회귀와 다중 회귀의 성능을 MSE와 결정계수, 두 지표로 나란히 비교합니다. 데이터 몇 행만으로 학습한 모델이 훈련 데이터에서만 높은 점수를 받는 현상 — 교과서가 과대적합이라 부르는 것 — 도 여기서 관찰합니다.

✔️ R²가 높아도 남는 물음

R²는 가진 데이터 안에서의 성적입니다. 6차시에 슬라이더를 2100년까지 밀었을 때를 떠올려 보세요. 직선은 학습 범위(1908~2025) 밖(외삽)에서도 주저 없이 숫자를 내놓지만, 그 구간의 성적표는 어디에도 없습니다. "R²가 높은 모델 = 미래를 잘 맞히는 모델"이 아닌 이유 — 활동지 문제 7에서 글로 정리합니다.

5. 개념 정리 — 점수를 의심할 자격

오늘 우리는 회귀 모델의 성적표가 만들어지는 전 과정을 손으로 통과했습니다. 오차를 재고, 부호를 없애 공정하게 더하고, 제곱해서 평균 내고, 게으른 모델과 비교한다 — 이 네 단계가 전부입니다. 그러자 이번 주 화면에 떠 있던 숫자들이 전부 다시 읽히기 시작합니다.

6. 확인 문제

문제 1 어느 예측기의 3일간 오차가 +3, −3, 0이었습니다. 두 소문항에 답해 보세요.
(가) 오차를 그냥 더해 "합계 0이니 완벽한 예측기"라고 주장한다면, 이 주장의 문제는?
+3과 −3이 상쇄되어 합이 0일 뿐입니다. "완벽하다"는 주장은 상쇄를 놓친 판단으로, +3과 −3은 둘 다 3만큼의 빗나감입니다. 표본 수의 문제도 아닙니다 — 표본이 아무리 많아도, 부호 있는 오차를 그냥 더하는 방식 자체가 잘못입니다.
(나) 이 예측기의 MSE는?
제곱오차는 9, 9, 0이고 MSE는 그 평균 = 18 ÷ 3 = 6입니다. 오차 합이 0이어도 제곱오차는 0이 아니므로 0은 답이 될 수 없고, 18은 제곱오차의 합 — MSE는 평균이므로 3으로 나눠야 합니다.
문제 2 어느 데이터에서 평균만 찍는 모델의 제곱오차 합이 40, 내 회귀 직선의 제곱오차 합이 10입니다.
(가) R²는?
R² = 1 − (10 ÷ 40) = 0.75. 게으른 모델 오차의 75%를 없앴다는 뜻입니다. 0.25는 10÷40까지만 계산하고 1에서 빼는 단계를 빠뜨린 값 — "남아 있는 오차의 비율"입니다. 4.0은 분자·분모를 뒤집은 40÷10 — R²의 분모는 평균 모델의 제곱오차 합입니다.
(나) 내 직선의 제곱오차 합이 60이라면?
R² = 1 − (60 ÷ 40) = −0.5. R²는 음수가 될 수 있습니다(활동지 문제 5). 0.5는 부호 처리를 놓친 값으로, 60÷40 = 1.5이므로 1 − 1.5 = −0.5입니다.
문제 3 기온 예측기의 R²는 관측일 필터를 켜면 0.70, 끄면 0.39입니다. 필터를 껐을 때 점수가 떨어지는 이유를 1953년과 "제곱"의 성질을 근거로 설명해 보세요.
예시 답 펼쳐 보기

1953년은 겨울 한 달 치만 관측되어 연평균이 실제보다 훨씬 낮은 반쪽 값이 된 해다. 필터를 끄면 이 점이 데이터에 들어오는데, 직선에서 멀리 떨어진 점의 오차는 제곱되면서 매우 커져 제곱오차 합을 크게 키운다. 그 결과 R²가 0.70에서 0.39로 떨어진다. 모델의 점수를 지탱한 것은 알고리즘이 아니라 전처리였다.

🎒 오늘의 체크

  • 오차 → 절대오차·제곱오차 → MSE → R²의 계산 순서를 손으로 밟았다.
  • 교과서 120쪽 해 보기 ①의 두 회귀선을 오차 계산으로 판정했다.
  • R²가 "평균 모델 대비 개선율"임을 계산으로 설명할 수 있다.
  • 필터에 따라 0.70이 0.39가 되는 이유를 1953년으로 설명할 수 있다.

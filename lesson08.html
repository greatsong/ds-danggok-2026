0. 왜 배우나

평가 지표의 계산법을 알면 점수가 무엇을 나타내는지 설명할 수 있습니다. 오늘은 예측이 빗나간 크기를 계산하고, 항상 평균값을 예측하는 기준과 비교합니다. 회귀의 평가 지표를 모든 모델에 그대로 적용할 수는 없지만, 평가 기준을 확인하는 습관은 분류와 군집 분석에서도 필요합니다.

1. 개념 이해 — 오차에서 R²까지

📖 교과서의 정의 『데이터 과학』 120·131·132쪽

"실젯값과 예측값의 차이를 오차라고 하는데, 두 직선을 비교하여 오차가 더 작은 것을 선택해야 한다." (120쪽)

"평균제곱오차(MSE: Mean Squared Error)는 실젯값과 예측값의 차이를 모두 제곱하여 평균한 값으로, 이 값이 작을수록 예측 성능이 좋다." (131쪽)

"결정 계수(R² score: R-squared score)는 회귀 모델이 실제 데이터와 얼마나 유사하게 예측하고 구체적으로 설명하는지를 나타낸다." (132쪽)

→ 오차는 실젯값과 예측값의 차이입니다. MSE는 제곱오차의 평균이며, R²는 제곱오차 합을 평균값 기준과 비교한 비율입니다.

계산구하는 법묻는 말
오차실젯값 − 예측값이 예측은 얼마나, 어느 쪽으로 빗나갔나
절대오차 / 제곱오차오차의 절댓값 / 오차의 제곱부호가 상쇄되지 않도록 크기를 나타내면?
MAE절대오차의 평균원래 단위로 평균적으로 얼마나 빗나갔나?
MSE제곱오차의 평균이 모델은 평균적으로 얼마나 빗나가나
R²1 − (내 모델의 제곱오차 합 ÷ 평균 모델의 제곱오차 합)평균만 찍는 모델보다 얼마나 나은가
🔬 그림으로 살펴보기 — 오차와 제곱

양수와 음수인 오차를 그대로 더하면 서로 상쇄될 수 있습니다. 절댓값과 제곱을 사용하면 어떤 차이가 생기는지 활동지에서 계산해 봅니다.

2. 손 활동지 — 교과서 해 보기에서 자작 문제까지

✍️ 활동지 문제 1 (교과서 120쪽 해 보기 ①)

교과서 120쪽의 두 회귀선을 활동지 문제 1에서 비교합니다. 먼저 어느 직선이 더 잘 맞아 보이는지 예상해 봅니다. 그다음 다섯 점의 오차를 계산하고 절댓값을 더해 두 직선을 비교합니다. 예상과 계산 결과가 다르다면 어느 점에서 차이가 생겼는지 확인합니다.

활동지는 오차 계산에서 시작해 MAE, MSE, R²의 순서로 진행합니다. 앞에서 채운 표를 활용해 다음 계산으로 넘어갑니다. 필요한 경우 짝과 계산 과정을 비교해도 좋습니다.

💡 활동지 규칙
  • 계산 과정을 지우지 않는다. 과정이 곧 점수다 — 답만 적힌 활동지는 검산할 수 없다.
  • 막히면 표의 빈칸부터 채운다. 오차 계산은 언제나 "실젯값 − 예측값" 한 칸에서 시작한다.
  • 지필평가의 계산 문항은 이 활동지의 흐름 그대로 출제된다.

3. R²의 의미 — 평균값을 예측하는 기준과 비교하기

R²는 모델의 제곱오차 합을, 평가 대상 실젯값들의 평균을 항상 예측했을 때의 제곱오차 합과 비교합니다. 기준의 제곱오차 합이 20이고 내 모델의 제곱오차 합이 5라면, R² = 1 − (5 ÷ 20) = 0.75입니다. 이는 기준보다 제곱오차 합이 75% 작다는 뜻이며, 예측의 75%가 정답이라는 뜻은 아닙니다. 이 식의 평균은 평가 대상 자료의 평균입니다. 학습 자료의 평균을 사용한 별도의 기준 예측기와 구분합니다.

💡 R² 눈금 읽기
  • 1에 가까움 → 평균값 기준보다 제곱오차 합이 매우 작습니다.
  • 0 → 평균만 찍는 것과 다를 바 없다 — 교과서도 "결정 계수가 0에 가깝다면 회귀 모델이 데이터의 평균을 맞추는 정도로 예측했고, 회귀 모델의 유의미성이 떨어진다는 뜻이다"라고 적는다(132쪽)
  • 음수 → 평균만 찍는 평균값 기준보다도 못하다 (활동지 문제 5에서 직접 만들어 본다)

7차시의 R²가 0.24였다는 것은, 해당 테스트 자료에서 모델의 제곱오차 합이 평균값 기준보다 24% 작았다는 뜻입니다. 어떤 자료에서 어떤 변수로 평가했는지를 함께 확인합니다. 실젯값이 모두 같으면 분모가 0이 되므로 이 식을 그대로 계산할 수 없습니다.

4. 기온 모델 다시 보기 — 자료 선택에 따른 R² 비교

기온 예측기를 새로 만들어 자료 선택에 따른 R²의 변화를 확인합니다. 여기서는 직선을 학습한 자료에 다시 예측한 학습 자료의 R²를 계산합니다. 별도로 떼어 둔 자료에서 평가한 7차시의 테스트 R²와는 평가 조건이 다릅니다.

"기온 예측기" 스트림릿 앱을 만들어 줘. 파일 하나로.
서울 기온 데이터(https://raw.githubusercontent.com/greatsong/modudata/bb860932644270ad1199f10d3e7670e30231bce4/data/seoul.csv)로
수업 기준 기간인 2025년까지의 자료로 연도별 평균기온을 구해 줘.

각 경우를 따로 학습한 R²를 나란히 보여 주고, 학습 자료에서 계산한 점수라고 표시해 줘.
스위치에 따라 산점도와 회귀선이 바뀌게 하고, 제외 후보인 연도와 관측일 수도 보여 줘.
선생님이 실행해 확인한 예시 코드

파일 하나로 저장합니다

app.py
# app.py — 관측일 필터를 켜고 끄며 R²가 어떻게 달라지는지 본다
import streamlit as st
import pandas as pd
import numpy as np
import plotly.express as px

DATA_URL = "https://raw.githubusercontent.com/greatsong/modudata/bb860932644270ad1199f10d3e7670e30231bce4/data/seoul.csv"


@st.cache_data
def load_all():
    df = pd.read_csv(DATA_URL)
    df["연도"] = pd.to_datetime(df["날짜"]).dt.year
    return df.groupby("연도")["평균기온"].agg(["mean", "count"]).reset_index()


def score(yearly):
    a, b = np.polyfit(yearly["연도"], yearly["mean"], 1)
    pred = a * yearly["연도"] + b
    ss_res = ((yearly["mean"] - pred) ** 2).sum()
    ss_tot = ((yearly["mean"] - yearly["mean"].mean()) ** 2).sum()
    return 1 - ss_res / ss_tot


all_years = load_all().dropna(subset=["mean"])
# 2026년 수업의 기준 기간은 2025년까지이다. 마지막 연도를 무조건 빼지 않는다.
all_years = all_years[all_years["연도"] <= 2025]
on = st.toggle("관측일 300일 미만인 해를 뺀다", value=True)
used = all_years[all_years["count"] >= 300] if on else all_years

c1, c2 = st.columns(2)
c1.metric("필터 적용 · 학습 R²", f"{score(all_years[all_years['count'] >= 300]):.2f}")
c2.metric("필터 해제 · 학습 R²", f"{score(all_years):.2f}")
st.caption(f"지금 쓰는 해: {len(used)}개 · 뺀 해: {len(all_years) - len(used)}개")
a, b = np.polyfit(used["연도"], used["mean"], 1)
fig = px.scatter(used, x="연도", y="mean", labels={"mean": "연평균기온(℃)"})
fig.add_scatter(x=used["연도"], y=a * used["연도"] + b, mode="lines", name="회귀선")
st.plotly_chart(fig, width="stretch")
st.write("관측일이 300일 미만인 해")
st.dataframe(all_years[all_years["count"] < 300].rename(columns={"mean": "평균기온", "count": "관측일 수"}), hide_index=True)
⚠️ 필터를 바꾸면 학습·평가 자료도 바뀝니다

관측일 필터를 적용한 114개 연도의 학습 R²는 0.70, 적용하지 않은 117개 연도에서는 0.39입니다. 필터를 해제하면 1907년(92일), 1950년(243일), 1953년(31일)이 포함됩니다. 특히 1953년의 겨울 한 달 평균은 다른 해의 연평균과 비교하기 어렵고, 큰 잔차가 제곱오차 합에 영향을 줍니다. 자료가 달라지면 회귀선과 R²의 분모도 함께 바뀝니다. 따라서 이 비교만으로 새로운 자료에 대한 예측 성능이 향상되었다고 결론지을 수는 없습니다.

자료를 제외하는 기준

연간 기온을 충분히 대표하는지 확인한 뒤 제외 기준을 정합니다. 점수가 높아졌다는 이유만으로 자료 제외를 정당화해서는 안 됩니다. 전처리 방법의 예측 성능을 비교하려면 같은 평가 자료를 사용해야 합니다.

남은 시간에는 교과서 134쪽 해 보기 ③(폼 Ⅲ-02c)으로 단순 회귀와 다중 회귀의 성능을 MSE와 결정계수, 두 지표로 나란히 비교합니다. 데이터 몇 행만으로 학습한 모델이 훈련 데이터에서만 높은 점수를 받는 현상 — 교과서가 과대적합이라 부르는 것 — 도 여기서 관찰합니다.

✔️ R²가 높아도 남는 물음

높은 학습 R²는 학습 자료를 잘 설명한다는 뜻입니다. 새로운 자료에서도 잘 예측하는지는 따로 평가해야 합니다. 특히 2045년이나 2100년처럼 학습 범위 밖을 예측할 때는 이 점수만으로 정확도를 보장할 수 없습니다.

5. 도전 — 직선 대신 곡선을 쓰면

곡선이 직선보다 항상 더 잘 예측할까요? 2005년 이전 자료로 1차·3차·9차 모델을 각각 학습하고, 2005~2025년 자료는 평가용으로 남겨 둡니다. 같은 평가 자료에서 평균절대오차(MAE)를 비교합니다. 차수가 높을수록 곡선의 형태를 더 복잡하게 조정할 수 있습니다.

도전 프롬프트
좋아, 이번엔 직선 대신 곡선을 시험해 보자.
- 연평균기온을 2005년 이전은 공부용, 2005년부터는 시험용으로 나눠 줘.
- 1차(직선), 3차, 9차 곡선을 각각 공부용으로만 맞추고,
  시험용에서 평균 몇 도나 빗나가는지와 2050년 예측값을 한 표로 보여 줘.
- 반드시 학습에 안 쓴 시험용으로 채점해 줘.
  연도 숫자가 커서 고차 곡선이 불안하면 연도를 작은 수로 바꿔서 계산해 줘.

# 도전 — 직선 대신 곡선을 쓰면 (app.py 끝에 이어 붙일 부분)
import numpy as np

st.subheader("도전 — 직선 대신 곡선을 쓰면")
연평균 = all_years[all_years["count"] >= 300].rename(columns={"mean": "기온"})   # 앞에서 만든 연평균 표
공부 = 연평균[연평균["연도"] < 2005]                             # 2005년 이전은 공부용
시험 = 연평균[연평균["연도"] >= 2005]                            # 그 뒤는 한 번도 안 본 시험용
x = lambda y: (y - 1950) / 100                                   # 연도를 작은 수로 바꿔야 고차 곡선이 안정된다

rows = []
for 차수 in [1, 3, 9]:
    계수 = np.polyfit(x(공부["연도"]), 공부["기온"], 차수)
    시험오차 = np.abs(np.polyval(계수, x(시험["연도"])) - 시험["기온"]).mean()
    rows.append({"곡선": f"{차수}차", "시험 오차(℃)": round(시험오차, 2),
                 "2050년 예측(℃)": round(np.polyval(계수, x(2050)), 1)})
st.dataframe(pd.DataFrame(rows), hide_index=True)
st.caption(f"학습 {len(공부)}개 연도 · 평가 {len(시험)}개 연도 · 평가 오차는 평균절대오차(MAE)입니다.")

3차1.01℃19.1℃

이 평가 자료에서 MAE는 1차 0.54℃, 3차 1.01℃, 9차 12.44℃입니다. 2050년 예측값은 각각 13.8℃, 19.1℃, 2,445℃였습니다. 이번 비교에서는 1차 모델의 평가 오차가 가장 작았지만, 모든 자료에서 직선이 가장 좋다는 뜻은 아닙니다. 학습 자료에 지나치게 맞추어 새로운 자료의 예측 성능이 떨어지는 현상을 과대적합이라고 합니다. 고차 다항식은 외삽에서 특히 불안정한 값을 낼 수 있습니다.

⚠️ 2050년도 2200년도 외삽입니다

도전 활동의 모델은 2005년 이전 자료로 학습했습니다. 따라서 2050년과 2200년의 예측은 모두 학습 범위 밖의 외삽입니다. 미래 시점이 비교적 가깝다는 이유만으로 정확하다고 볼 수 없습니다. 여기서 계산한 값은 회귀 모델을 범위 밖에 적용한 예시이며, 기후 예보를 뜻하지 않습니다.

6. 개념 정리 — 평가 점수의 의미와 한계

오차의 부호가 상쇄되는 문제를 확인하고, 절대오차와 제곱오차를 계산했습니다. MAE와 MSE는 오차의 크기를 요약하고, R²는 제곱오차 합을 평균값 기준과 비교합니다. 앞선 실습의 점수도 평가 조건과 함께 읽어 봅니다.

7. 확인 문제

문제 1 어느 예측기의 3일간 오차가 +3, −3, 0이었습니다. 두 소문항에 답해 보세요.
(가) 오차를 그냥 더해 "합계 0이니 완벽한 예측기"라고 주장한다면, 이 주장의 문제는?
+3과 −3이 상쇄되어 합이 0일 뿐입니다. "완벽하다"는 주장은 상쇄를 놓친 판단으로, +3과 −3은 둘 다 3만큼의 빗나감입니다. 표본 수의 문제도 아닙니다 — 표본이 아무리 많아도, 부호 있는 오차를 그냥 더하는 방식 자체가 잘못입니다.
(나) 이 예측기의 MSE는?
제곱오차는 9, 9, 0이고 MSE는 그 평균 = 18 ÷ 3 = 6입니다. 오차 합이 0이어도 제곱오차는 0이 아니므로 0은 답이 될 수 없고, 18은 제곱오차의 합 — MSE는 평균이므로 3으로 나눠야 합니다.
문제 2 어느 데이터에서 평균만 찍는 모델의 제곱오차 합이 40, 내 회귀 직선의 제곱오차 합이 10입니다.
(가) R²는?
R² = 1 − (10 ÷ 40) = 0.75. 평균값 기준보다 제곱오차 합이 75% 작다는 뜻입니다. 0.25는 10÷40까지만 계산하고 1에서 빼는 단계를 빠뜨린 값 — "남아 있는 오차의 비율"입니다. 4.0은 분자·분모를 뒤집은 40÷10 — R²의 분모는 평균 모델의 제곱오차 합입니다.
(나) 내 직선의 제곱오차 합이 60이라면?
R² = 1 − (60 ÷ 40) = −0.5. R²는 음수가 될 수 있습니다(활동지 문제 5). 0.5는 부호 처리를 놓친 값으로, 60÷40 = 1.5이므로 1 − 1.5 = −0.5입니다.
문제 3 기온 예측기의 R²는 관측일 필터를 켜면 0.70, 끄면 0.39입니다. 1953년 자료와 제곱오차를 이용해 차이를 설명하고, 높은 점수만으로 자료 제외를 정당화할 수 있는지도 써 보세요.
예시 답 펼쳐 보기

1953년의 31일 평균은 한 해 전체의 기온을 충분히 대표하기 어렵다. 필터를 해제하면 1907년·1950년·1953년이 함께 들어오고, 큰 오차는 제곱오차 합에 영향을 준다. 동시에 회귀선과 기준 평균, R²의 분모도 달라진다. 두 점수는 같은 평가 자료에서 얻은 값이 아니므로 성능 개선으로 단정할 수 없다. 자료 제외는 점수보다 관측 기간과 대표성을 근거로 판단한다.

문제 4 9차 곡선은 공부용 점들에 가장 가깝게 붙었는데, 시험용 오차는 12.44℃로 가장 크고 2050년 예측은 2,445℃였습니다. 이유로 알맞은 것은?
공부한 자료에서 잘 맞는 것과 처음 보는 자료에서 잘 맞는 것은 다릅니다. 1차 직선은 공부용 점들에서 가장 멀었지만 시험용에서는 가장 잘 맞았습니다. 점수는 반드시 학습에 쓰지 않은 자료로 따로 봐야 합니다.

  • 오차 → 절대오차·제곱오차 → MSE → R²의 계산 순서를 손으로 밟았다.
  • 교과서 120쪽 해 보기 ①의 두 회귀선을 오차 계산으로 판정했다.

  • 필터에 따라 학습·평가 자료가 바뀐다는 점과 자료 제외의 근거를 설명할 수 있다.

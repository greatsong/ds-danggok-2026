영화 API 프로젝트 — 가설을 세우고 데이터로 확인한다

오늘은 그래프를 더 늘리지 않고 질문 하나에 답합니다. 먼저 가설을 세우고 데이터로 확인하는 순서로 진행합니다. 지금까지 교사가 주는 조건대로 API 호출을 따라 했지만, 오늘은 필요한 데이터를 여러분이 직접 모아 확인합니다.

🎯 오늘 하는 것
  • 가설 — 12월 24일에는 로맨틱 코미디가 인기일 것이다
  • 데이터 모으기 — 연도를 바꿔 가며 그날의 박스오피스를 스물두 번 부르기
  • 장르 붙이기 — 영화코드를 열쇠로 장르 표와 이어 붙이기
  • 판정 — 대조가 되는 날짜와 비교해 가설을 가리기

1. 오늘의 가설

오늘의 가설은 12월 24일에는 로맨틱 코미디가 인기일 것이라는 짐작입니다. 이 짐작은 그럴듯하지만 아직 확인되지 않은 상태입니다. 가설은 맞는지 틀리는지를 데이터로 가릴 수 있는 형태여야 합니다.

2. 왜 API인가

3차시에서 다룬 축적 표는 365일치로, 작년 12월 24일 하루만 들어 있습니다. 여러 해의 12월 24일을 비교하려면 해마다 그날을 따로 불러야 합니다. KOBIS 일별 박스오피스는 2003년 11월부터 어제까지 날짜를 지정해 부를 수 있습니다.

3. 만들기

  1. 1단계 — 날짜 하나 불러 보기
    먼저 날짜 하나를 불러 응답의 모양을 확인합니다. 2차시에서 쓴 것과 같은 주소에 조건만 바꾸어 요청합니다.
    ① 프롬프트
    스트림릿 앱에 새 페이지를 추가해 줘. 제목은 '영화 가설 검증'.
- KOBIS 일별 박스오피스 API를 부르는데, 날짜를 내가 정할 수 있게 해 줘.
  월과 일을 숫자로 입력받아서 그 날짜의 10위권을 표로 보여 줘.
- 인증키는 2차시처럼 비밀 금고에 둔 KOBIS_KEY를 써 줘.
- 받아 온 관객수는 글자가 아니라 숫자로 바꿔서 써 줘.
  2. 2단계 — 여러 해를 모으기
    연도를 바꿔 가며 같은 요청을 반복해 표로 쌓습니다. 2004년부터 2025년까지 스물두 해, 하루 열 편씩 모읍니다. 선생님이 365일 표를 만든 방식과 같습니다.
    ② 추가 프롬프트
    좋아, 이어서 고쳐 줘.
- 연도 하나가 아니라 시작 연도부터 끝 연도까지 같은 날짜를 해마다 불러서
  한 표로 쌓아 줘. 연도 범위는 슬라이더로 고르게 해 줘.
- 같은 조건을 다시 물으면 또 부르지 말고 저장해 둔 것을 쓰게 해 줘.
- 응답에 목록이 없는 해가 있으면 멈추지 말고 그 해만 건너뛰어 줘.
  3. 3단계 — 장르 붙이기
    박스오피스 응답에는 장르가 없습니다. 영화코드별 장르를 담은 표를 따로 준비해 두었습니다. 영화코드를 열쇠로 두 표를 이어 붙입니다. 3차시에서 배운 데이터 통합의 또 다른 형태입니다. 그때는 같은 모양의 표를 아래로 쌓았고, 이번에는 영화코드가 같은 행끼리 옆으로 잇습니다.

    장르 표 주소

    ③ 추가 프롬프트
    좋아, 장르를 붙여 줘.
- 이 주소의 표에는 영화코드마다 장르가 적혀 있어:
  https://raw.githubusercontent.com/greatsong/modudata/main/data/kobis_genres.csv
- 박스오피스에서 받은 표와 이 표를 영화코드로 이어 붙여 줘.
- 장르를 못 찾은 영화는 '미상'으로 채워 줘.
  4. 4단계 — 두 저울로 세기
    한 영화에는 장르가 여럿 붙습니다. 액션이면서 드라마인 영화도 있습니다. 그래서 장르별 비율을 모두 더하면 100%를 넘습니다. 이것을 어떻게 셀지는 분석의 판단입니다.
    ④ 추가 프롬프트
    좋아, 마지막으로 두 그래프를 나란히 그려 줘.
- 한 영화에 장르가 여러 개면 낱개로 나눠서 세 줘.
- 왼쪽에는 장르별 관객 합계를 가로 막대로, 비율도 함께 보여 줘.
- 오른쪽에는 장르별로 몇 편이 10위권에 들었는지를 가로 막대로 보여 줘.
- 아래에는 장르를 골라 그 장르들이 차지한 관객 비율을 보여 주는 칸을 만들어 줘.

    # pages/91_영화_가설검증.py — 날짜를 정해 여러 해의 박스오피스를 모으고 장르로 확인한다
import streamlit as st
import pandas as pd
import requests
import time
import plotly.express as px

st.set_page_config(page_title="영화 가설 검증", layout="wide")
st.title("영화 가설 검증 — 날짜와 장르")

KEY = st.secrets["KOBIS_KEY"]
BOX_URL = "https://www.kobis.or.kr/kobisopenapi/webservice/rest/boxoffice/searchDailyBoxOfficeList.json"
GENRE_URL = "https://raw.githubusercontent.com/greatsong/modudata/main/data/kobis_genres.csv"

# ── 조건 고르기 ─────────────────────────────────────────────
c1, c2, c3 = st.columns(3)
month = c1.number_input("월", min_value=1, max_value=12, value=12)
day = c2.number_input("일", min_value=1, max_value=31, value=24)
y1, y2 = c3.slider("연도 범위", min_value=2004, max_value=2025, value=(2004, 2025))


@st.cache_data
def load_genres():
    # 영화코드별 장르 표 (선생님이 미리 만들어 둔 것)
    return pd.read_csv(GENRE_URL, dtype={"영화코드": str})


@st.cache_data(show_spinner="해마다 그 날짜를 부르는 중입니다")
def fetch_days(month, day, y1, y2):
    # 연도를 바꿔 가며 같은 날짜를 하나씩 부른다
    rows = []
    for year in range(y1, y2 + 1):
        target = f"{year}{month:02d}{day:02d}"
        res = requests.get(BOX_URL, params={"key": KEY, "targetDt": target}, timeout=20)
        answer = res.json().get("boxOfficeResult")
        if not answer:                      # 목록 대신 안내문이 오면 그 해는 건너뛴다
            continue
        time.sleep(0.2)                     # 잇달아 부를 때는 사이를 조금 둔다
        for m in answer["dailyBoxOfficeList"]:
            rows.append({
                "연도": year,
                "순위": int(m["rank"]),
                "영화코드": m["movieCd"],
                "영화명": m["movieNm"],
                "관객": int(m["audiCnt"]),
            })
    return pd.DataFrame(rows)


df = fetch_days(month, day, y1, y2)
if df.empty:
    st.warning("그 날짜에는 기록이 없습니다. 다른 날짜를 골라 보세요.")
    st.stop()

# ── 장르 붙이기 — 영화코드가 열쇠 ────────────────────────────
df = df.merge(load_genres()[["영화코드", "장르"]], on="영화코드", how="left")
df["장르"] = df["장르"].fillna("미상")

st.caption(f"{month}월 {day}일 · {y1}~{y2}년 · {len(df)}행 · 영화 {df['영화코드'].nunique()}편")

# 한 영화에 장르가 여럿이므로 낱개로 나눈다 (그래서 비율의 합은 100%를 넘는다)
one = df.assign(장르=df["장르"].str.split(",")).explode("장르")
one["장르"] = one["장르"].str.strip()

total = df["관객"].sum()
st.metric("기간 전체 관객 수", f"{total:,}명")

# ── 두 저울: 관객과 편수 ────────────────────────────────────
left, right = st.columns(2)

by_audi = (one.groupby("장르")["관객"].sum()
             .sort_values(ascending=False).head(10).reset_index())
by_audi["비율(%)"] = (by_audi["관객"] / total * 100).round(1)
fig1 = px.bar(by_audi.sort_values("관객"), x="관객", y="장르", orientation="h",
              text="비율(%)", title="관객으로 잰 장르")
left.plotly_chart(fig1, width="stretch")
left.caption("이 그래프로 알 수 있는 것: (한 문장으로 적어 보세요)")

by_count = (one.drop_duplicates(["연도", "영화코드", "장르"])["장르"]
              .value_counts().head(10).reset_index())
by_count.columns = ["장르", "편수"]
fig2 = px.bar(by_count.sort_values("편수"), x="편수", y="장르", orientation="h",
              title="편수로 잰 장르")
right.plotly_chart(fig2, width="stretch")
right.caption("이 그래프로 알 수 있는 것: (한 문장으로 적어 보세요)")

# ── 가설 판정 ──────────────────────────────────────────────
st.subheader("가설 확인")
picked = st.multiselect("확인할 장르", sorted(one["장르"].unique()),
                        default=[g for g in ["멜로/로맨스", "코미디"] if g in set(one["장르"])])
if picked:
    share = one[one["장르"].isin(picked)]["관객"].sum() / total * 100
    st.write(f"고른 장르가 차지한 관객 비율: **{share:.1f}%**")
    st.info("이 숫자만으로는 높은지 낮은지 알 수 없습니다. 다른 날짜로 한 번 더 재어 비교해 보세요.")

with st.expander("모은 데이터 보기"):
    st.dataframe(df, hide_index=True)

4. 발견 — 크리스마스이브의 주인은 누구인가

12월 24일 스물두 해의 관객 합계는 21,554,320명입니다. 멜로/로맨스와 코미디를 합한 몫은 21.2%입니다. 가장 큰 몫은 드라마 41.5%와 액션 40.1%입니다. 이는 가설과 다른 결과입니다.

한 영화에 장르가 여럿 붙으므로 비율의 합은 100%를 넘습니다.

5. 대조군 — 21.2%는 높은가 낮은가

21.2%가 높은지 낮은지는 그 숫자만으로 알 수 없습니다. 평범한 날과 비교해야 합니다. 6월 24일 같은 스물두 해의 몫은 25.9%입니다. 크리스마스이브가 오히려 더 낮습니다.

날짜관객 합계멜로/로맨스+코미디가장 큰 장르
12월 24일21,554,320명21.2%드라마 41.5% · 액션 40.1%
6월 24일8,232,656명25.9%액션 53.4% · 어드벤처 30.2%
⚠️ 대조가 없으면 판정도 없다

12월 24일만 보고 "21.2%나 된다"고 말할 수도, "21.2%밖에 안 된다"고 말할 수도 있습니다. 어느 쪽인지는 비교할 상대를 세워야 정해집니다. 비교 상대를 먼저 세우는 이 습관은 뒤의 평가 차시(8·10차시)에서 기준선이라는 이름으로 다시 만납니다.

6. 두 번째 발견 — 편수와 관객은 다른 말을 한다

편수로 세면 코미디 43편, 멜로/로맨스 32편으로 적지 않습니다. 관객으로 재면 몫이 크게 내려갑니다. 자주 걸리지만 크게 모으지는 못했다는 뜻입니다. 이는 4차시에서 도넛과 트리맵이 다른 말을 한 것과 같은 구조입니다.

# 연도별 장르 추세 — 22년을 두 저울로 잰다 (앞 코드 끝에 이어 붙입니다)
WEEKLY_URL = "https://raw.githubusercontent.com/greatsong/modudata/main/data/kobis_weekly.csv"

st.header("연도별 장르 추세")


@st.cache_data
def load_trend():
    weekly = pd.read_csv(WEEKLY_URL, dtype={"영화코드": str})
    weekly["연도"] = weekly["주시작일"].astype(str).str[:4].astype(int)
    weekly = weekly[weekly["연도"] <= 2025]                 # 진행 중인 해는 뺀다
    merged = weekly.merge(load_genres()[["영화코드", "장르"]], on="영화코드", how="left")
    merged = merged.dropna(subset=["장르"])
    낱개 = merged.assign(장르=merged["장르"].str.split(",")).explode("장르")
    낱개["장르"] = 낱개["장르"].str.strip()
    return 낱개


t = load_trend()
고른장르 = st.multiselect("견줘 볼 장르", sorted(t["장르"].unique()),
                     default=["액션", "코미디", "드라마"])
if 고른장르:
    관객 = t.groupby(["연도", "장르"])["주간관객"].sum().unstack(fill_value=0)
    관객몫 = (관객.T / 관객.sum(axis=1)).T * 100
    편수 = t.drop_duplicates(["연도", "영화코드", "장르"]).groupby(["연도", "장르"]).size().unstack(fill_value=0)
    편수몫 = (편수.T / 편수.sum(axis=1)).T * 100

    c1, c2 = st.columns(2)
    c1.plotly_chart(px.line(관객몫[고른장르], labels={"value": "관객 몫(%)"},
                            title="관객으로 잰 몫"), width="stretch")
    c2.plotly_chart(px.line(편수몫[고른장르], labels={"value": "편수 몫(%)"},
                            title="편수로 잰 몫"), width="stretch")

    요약 = pd.DataFrame({
        "관객 몫 04~08": 관객몫.loc[2004:2008, 고른장르].mean().round(1),
        "관객 몫 21~25": 관객몫.loc[2021:2025, 고른장르].mean().round(1),
        "편수 몫 04~08": 편수몫.loc[2004:2008, 고른장르].mean().round(1),
        "편수 몫 21~25": 편수몫.loc[2021:2025, 고른장르].mean().round(1),
    })
    st.dataframe(요약)
    st.caption("두 표가 같은 방향으로 움직이는 장르와 한쪽만 움직이는 장르를 찾아보세요.")

액션의 편수 몫은 처음 다섯 해 평균 13.1%에서 최근 다섯 해 평균 13.2%로 거의 변하지 않습니다. 같은 기간 관객 몫은 15.9%에서 26.0%로 커집니다. 편수는 그대로인데 관객만 늘어나므로, 한 편이 끌어모으는 관객이 커졌다는 뜻입니다.

장르편수 몫
2004~08 → 2021~25		관객 몫
2004~08 → 2021~25		모양

코미디는 편수 몫이 16.3%에서 7.2%로, 관객 몫이 14.0%에서 7.4%로 줄어듭니다. 두 몫이 함께 줄어드는 모양입니다. 액션은 한쪽만 늘었지만 코미디는 양쪽 다 줄어듭니다.

💡 한 해만 순서가 다르다

2020년만 드라마가 관객 몫 29.4%로 가장 큽니다. 다른 해에는 액션이 가장 큽니다. 그해에 무슨 일이 있었는지는 데이터 밖에서 찾아야 합니다.

편수 몫과 관객 몫은 서로 다른 질문에 답합니다. 편수는 얼마나 자주 만들어지는가를, 관객은 얼마나 크게 모으는가를 보여 줍니다. 하나만 보면 절반만 보는 것입니다.

주간 기록에 등장한 영화 3,800편 가운데 3,813편의 장르를 확인해 붙였습니다. 장르가 붙지 않은 행은 0.1%이고, 관객으로 보면 거의 전부가 포함됩니다.

8. 내 가설 만들기

날짜와 장르를 바꾸어 자기 가설을 세웁니다. 예를 들어 광복절에는 한국 영화가 강할 것이다, 여름에는 공포 영화가 많을 것이다와 같이 정할 수 있습니다. 대조가 될 날짜를 함께 정해야 합니다.

💡 가설을 적는 자리

가설 한 줄, 확인할 날짜, 대조로 삼을 날짜, 그리고 결과를 어떻게 판정할지를 먼저 적고 나서 앱을 돌립니다. 돌린 뒤에 기준을 정하면 보고 싶은 답이 나오도록 기준을 맞추게 됩니다.

9. 마무리

가설이 기각되어도 분석은 실패가 아닙니다. 확인되지 않았다는 것도 알아낸 것입니다. 기각된 자리에서 다음 질문이 나옵니다. 왜 크리스마스이브에는 대작이 걸리는가와 같은 질문입니다.

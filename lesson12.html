연관 분석 · 우리 학교 급식에서 규칙 찾기

"바늘 가는 데 실 간다."
속담 — 함께 등장하는 메뉴를 찾고, 규칙의 방향과 등장 빈도를 비교합니다

“제육볶음이 나오는 날 배추김치도 나올까?” 지지도·신뢰도·향상도를 손으로 계산한 뒤 당곡고 급식 데이터에서 메뉴의 동시 등장 패턴을 찾습니다. 세 지표의 차이를 이해하고, 표본에서 찾은 규칙을 어디까지 해석할 수 있는지 판단합니다.

이 수업에서 사용하는 급식 데이터는 어제까지 모인 데이터입니다. 조회하는 날에 따라 급식 일수와 메뉴 종류가 달라지므로, 화면에 나오는 숫자는 사람마다 조금씩 다릅니다. 숫자가 다른 것은 잘못이 아니며, 그 숫자를 어떻게 읽을지가 오늘의 과제입니다. 아래 손계산과 검산의 기준은 3절에 연결한 184일 저장본입니다.

🎯 오늘 하는 것
  • 교과서로 손계산 — 158·160쪽 〈개나리 마트〉의 세 지표 (활동지 기본 문제·연습 문제)
  • 바이브 코딩 — 급식 184일에서 규칙을 찾는 앱을 만든다
  • 판정 — 신뢰도가 높아도 기본 등장률과 차이가 작을 수 있음을 확인한다

0. 오늘의 목표

연관 분석은 함께 나타나는 항목의 패턴을 찾습니다. 자주 나오는 메뉴는 다른 여러 메뉴와도 자주 겹칩니다. 따라서 동시 등장 횟수뿐 아니라 각 메뉴의 기본 등장률도 함께 살펴야 합니다. 하루 중식 식단을 한 건으로 보고, 두 메뉴의 관계를 비교합니다.

  • 지지도·신뢰도·향상도의 분모가 각각 무엇인지 말할 수 있다.
  • 같은 두 메뉴라도 규칙의 방향이 바뀌면 신뢰도가 달라진다는 것을 설명할 수 있다.
  • 향상도를 결과 메뉴의 기본 등장률과 비교해 규칙을 판정할 수 있다.

1. 개념 이해 — 교과서의 세 숫자

📖 교과서의 정의 『데이터 과학』 159·160쪽

"지지도는 두 개의 사건이 동시에 발생하는 비율이며 …" (159쪽)

"신뢰도는 규칙의 결과 부분이 발생할 가능성을 측정한다." (159쪽)

"두 사건 A와 B가 서로 영향을 주지 않고 독립적으로 발생한다면, 향상도는 1에 가까워진다." (160쪽)

→ 지지도는 전체에서 함께 나온 비율, 신뢰도는 A가 나온 경우 중 B도 나온 비율, 향상도는 그 신뢰도를 B의 전체 등장률로 나눈 값입니다. 향상도 1은 표본에서 두 비율이 같다는 뜻이며, 그것만으로 우연이나 독립을 증명하지는 않습니다.

숫자계산식 (N: 전체 일수)묻는 말
지지도A·B 동시 일수 ÷ N이 조합, 다룰 만큼 자주 나오는가
신뢰도A·B 동시 일수 ÷ A 등장 일수A가 나오면 B도 나오는가
향상도신뢰도 ÷ (B 등장 일수 ÷ N)A가 있을 때 B의 등장률은 전체 등장률의 몇 배인가
🧩 세 지표는 분모가 서로 다릅니다

"지지도는 두 개의 사건이 동시에 발생하는 비율이며 …" (교과서 159쪽)

세 숫자는 모두 동시 등장 일수에서 출발하지만 무엇으로 나누는지가 다릅니다. 지지도는 전체 일수로, 신뢰도는 조건 메뉴 A가 나온 일수로 나눕니다. 향상도는 그 신뢰도를 다시 결과 메뉴 B의 전체 등장률로 나눕니다. 분모가 다르므로 세 숫자는 서로 대신할 수 없습니다.

향상도가 1이면 A가 나온 날의 B 비율과 B의 전체 등장률이 같다는 뜻입니다. 1보다 크면 A가 나온 날에 B가 더 자주 나왔고, 1보다 작으면 덜 나왔습니다. 향상도 1은 표본에서 두 비율이 같았다는 관찰이며, 두 메뉴가 서로 무관하다는 증명이 아닙니다.

신뢰도가 높다고 향상도가 높지는 않습니다. B가 원래 거의 날마다 나오는 메뉴라면 신뢰도는 저절로 높아지지만 향상도는 1 언저리에 머뭅니다. 그래서 두 숫자를 함께 읽습니다.

교과서의 {삼겹살} → {쌈채소} 규칙은 향상도가 1.67입니다. 삼겹살을 산 거래에서 쌈채소를 산 비율이 전체 거래의 쌈채소 구매 비율의 약 1.67배라는 뜻입니다. 구매 원인이나 미래의 구매를 보장하는 값은 아닙니다.

2. 손계산 활동지 — 기본 문제와 연습 문제

오늘의 계산은 활동지에 손으로 적습니다. 활동지에는 문제가 둘 있습니다. 기본 문제는 선생님과 함께 한 단계씩 풀고, 연습 문제는 같은 순서로 혼자 풉니다. 두 문제 모두 규칙이 둘씩 나옵니다. 같은 기록을 두 규칙으로 재 보고, 세 지표가 어느 규칙을 더 나은 규칙이라고 말하는지 비교합니다. 활동지의 수는 계산이 떨어지도록 고른 값이며 실제 관측값이 아닙니다. 나눗셈이 모두 두 자리 소수에서 끝나 계산기 없이 풀 수 있습니다.

🖥️ 위젯은 선생님 화면으로 함께 봅니다

이 차시의 위젯은 선생님이 앞에서 보여 주는 시연용입니다. 화면이 답을 대신 계산해 주면 계산 순서가 손에 남지 않습니다. 학생은 활동지에 손으로 적고, 다 푼 뒤에 화면의 값과 대조합니다.

단계활동지에 적는 것확인할 점
① 횟수앞 항목·뒤 항목·함께 나온 횟수세 수를 먼저 적어야 나머지가 나옵니다.
② 지지도함께 나온 횟수 ÷ 전체이 조합이 얼마나 자주 있는 일인지를 봅니다.
③ 신뢰도함께 나온 횟수 ÷ 앞 항목의 횟수분모가 앞 항목입니다. 지지도와 분모가 다릅니다.
④ 등장률뒤 항목의 횟수 ÷ 전체비교의 기준이 되는 값입니다.
⑤ 향상도신뢰도 ÷ 등장률1이면 우연과 같습니다. 분모는 뒤 항목의 등장률입니다.
⑥ 판단어느 규칙을 고를지와 그 까닭지표가 갈릴 때는 하려는 일이 무엇인지를 먼저 정합니다.
✍️ 기본 문제 · 급식 안내 화면에 무엇을 띄울까

지지도만 보면 이기는 규칙과 향상도로 보면 이기는 규칙이 서로 다릅니다. 순서를 지켜 지지도부터 구하고, 신뢰도에서 순위가 뒤집히는 것을 확인한 뒤 향상도로 넘어갑니다. 향상도를 먼저 구해 버리면 이 차시가 보여 주려는 것이 사라집니다.

⚠️ 계산이 끝나면 판단이 달라진다

두 규칙 모두 그럴듯해 보이지만, 향상도를 구하면 판단이 달라집니다. 교과서의 표는 이 판정 기준을 미리 준비해 둡니다. 이 기준을 가지고 우리 학교 급식으로 넘어갑니다.

    main.py
    # main.py — 함께 자주 나오는 메뉴 쌍을 찾는다
import re
from collections import Counter
from itertools import combinations

import pandas as pd
import plotly.express as px
import requests
import streamlit as st


@st.cache_data(ttl=3600)
def load_baskets(api_key):
    rows, page = [], 1
    params = {"Type": "json", "KEY": api_key,
              "pSize": 1000, "ATPT_OFCDC_SC_CODE": "B10",
              "SD_SCHUL_CODE": "7010073", "MMEAL_SC_CODE": "2",
              "MLSV_FROM_YMD": "20250901", "MLSV_TO_YMD": "20260930"}
    while True:
        response = requests.get("https://open.neis.go.kr/hub/mealServiceDietInfo",
                                params={**params, "pIndex": page}, timeout=20)
        response.raise_for_status()
        data = response.json()
        if "mealServiceDietInfo" not in data:
            result = data.get("RESULT", {})
            if result.get("CODE") == "INFO-200" and page == 1:
                return []
            raise ValueError("급식 조회 실패: " + result.get("MESSAGE", "응답 확인 필요"))
        blocks = data["mealServiceDietInfo"]
        head = next(block["head"] for block in blocks if "head" in block)
        total = next(item["list_total_count"] for item in head if "list_total_count" in item)
        chunk = next((block["row"] for block in blocks if "row" in block), [])
        if not chunk:
            raise ValueError("전체 데이터를 받기 전에 빈 페이지가 반환되었습니다.")
        rows.extend(chunk)
        if len(rows) >= total:
            break
        if len(chunk) < params["pSize"]:
            raise ValueError("전체 건수보다 적게 받았습니다. 인증키를 확인하세요.")
        page += 1
    days = {}
    for row in rows:
        basket = days.setdefault(row["MLSV_YMD"], set())
        for dish in re.split(r"<br\s*/?>", row["DDISH_NM"], flags=re.I):
            name = re.sub(r"\([^)]*\)", "", dish).strip()
            if name:
                basket.add(name)
    return [sorted(basket) for basket in days.values() if basket]

try:
    api_key = st.secrets["NEIS_API_KEY"]
except Exception:
    st.error("비밀 금고에 NEIS_API_KEY를 설정하세요. 5차시 안내를 확인합니다.")
    st.stop()
if not api_key.strip():
    st.error("인증키가 비어 있습니다.")
    st.stop()
try:
    baskets = load_baskets(api_key)
except (requests.RequestException, ValueError, KeyError, StopIteration):
    st.error("급식을 모두 조회하지 못했습니다. 인증키·조회 조건·연결 상태를 확인하세요.")
    st.stop()
if not baskets:
    st.info("조회 기간에 분석할 중식 데이터가 없습니다.")
    st.stop()
n = len(baskets)
single = Counter(item for b in baskets for item in b)
pair = Counter(c for b in baskets for c in combinations(b, 2))

rows = []
for (a, b), together in pair.items():
    if together < 5:                       # 동시에 나온 횟수가 5회 미만이면 뺀다
        continue
    for x, y in [(a, b), (b, a)]:
        rows.append({"조건": x, "결과": y, "동시": together,
                     "지지도": round(together / n, 3),
                     "신뢰도": round(together / single[x], 3),
                     "향상도": round((together / single[x]) / (single[y] / n), 2)})
rules = pd.DataFrame(rows, columns=["조건", "결과", "동시", "지지도", "신뢰도", "향상도"])
rules = rules.sort_values("향상도", ascending=False)
if rules.empty:

4. 결과 해석 — 기본 등장률과 비교하기

아래 세 규칙을 화면에서 찾아 직접 채웁니다. 등장 칸에는 앞 메뉴와 뒤 메뉴가 각각 나온 일수를, 판정 칸에는 향상도를 기본 등장률과 비교한 결과를 적습니다. 세 번째 규칙은 동시 등장이 드물어 결과 표에 나오지 않을 수 있습니다. 그때는 메뉴로 좁혀 보기 기능이나 원데이터에서 두 메뉴를 따로 세어 비교합니다. 세 규칙의 판정이 어떻게 갈리는지가 오늘의 발견입니다.

제육볶음 → 배추김치
순대국 → 석박지
배추김치 → 깍두기
🧩 규칙에는 방향이 있습니다

A → B와 B → A는 다른 규칙입니다. 신뢰도의 분모가 앞에 오는 메뉴가 나온 일수이기 때문입니다. 184일 저장본으로 확인합니다. 순대국 5일, 석박지 20일, 함께 나온 날 5일이므로 순대국 → 석박지의 신뢰도는 5÷5 = 1.00이고, 석박지 → 순대국의 신뢰도는 5÷20 = 0.25입니다.

반면 지지도와 향상도는 방향을 바꾸어도 같습니다. 지지도의 분모는 전체 일수 하나뿐이고, 향상도는 정리하면 동시 등장 비율을 두 메뉴 각각의 등장 비율의 곱으로 나눈 값이 되어 앞뒤 구분이 사라집니다. 위 예에서 두 방향의 향상도는 모두 9.20입니다.

그러므로 "B가 나오는 날은 A가 나온다"라고 말하려면 그 문장의 방향에 해당하는 신뢰도를 확인해야 합니다. 아래 위젯의 [방향 바꾸기] 단추로 두 값이 어떻게 갈리는지 확인합니다.

⚠️ 세 장면이 말하는 것
  • 신뢰도는 혼자 읽지 않습니다. 결과 메뉴가 원래 얼마나 자주 나오는지를 함께 보고, 그 차이를 향상도로 확인합니다.
  • 정렬 기준을 바꾸면 순위가 갈립니다. 신뢰도가 가장 높은 규칙과 향상도가 가장 높은 규칙이 다를 수 있습니다. 어느 숫자를 근거로 삼을지는 무엇을 묻고 있는지에 따라 정합니다.
  • 동시 0회도 관찰 결과입니다. 두 메뉴가 이 기간에 함께 나오지 않았다는 뜻이며, 급식실의 실제 운영 원칙인지는 별도로 확인해야 합니다.

분석 전에 적은 메뉴 쌍과 결과를 대조합니다. 동시 등장 횟수, 신뢰도, 기본 등장률, 향상도를 함께 적고 해석합니다. 결과 표에 없다고 반드시 관련이 없는 것은 아닙니다. 최소 횟수 기준 때문에 제외되었는지도 확인합니다. 이 기록을 Ⅲ-04d 과제에 활용합니다.

🧩 최소 지지도 — 규칙 후보를 걸러 내는 기준

교과서 162쪽은 규칙 후보를 추리기 전에 최소 지지도를 먼저 정하는 절차를 다룹니다.

최소 지지도는 규칙 후보로 남길 최소 등장 비율입니다. 이 실습은 동시 등장 5회 이상을 기준으로 삼습니다. 기준이 필요한 까닭은 향상도의 성질에 있습니다. 드물게 등장하는 메뉴는 분모가 작아 향상도가 쉽게 커지므로, 단 하루 겹친 조합이 표의 맨 위를 차지할 수 있습니다.

기준을 낮추면 규칙이 늘어나는 대신 우연한 조합이 섞여 들어오고, 높이면 규칙이 줄어드는 대신 드물지만 의미 있는 조합까지 사라집니다. 결과 표에 없다는 것과 관련이 없다는 것은 다릅니다. 이 기준은 실습을 위한 선택이며 통계적 유의성을 보장하지 않습니다.

6. 개념 정리 — 교과서와 급식이 만나는 대목

지지도는 조합의 빈도를, 신뢰도는 조건부 비율을, 향상도는 기본 등장률과의 비율을 나타냅니다. 세 지표를 함께 보고 관측 기간과 등장 횟수도 기록합니다. 동시 5회 이상이라는 기준은 드문 조합을 제외하는 실습 기준이며, 통계적으로 유의하거나 미래에도 유지되는 규칙을 보장하지 않습니다.

향상도가 크게 나온 규칙도 앞 메뉴가 뒤 메뉴의 등장을 일으켰다는 인과관계의 증명은 아닙니다. 식단 구성 방침 등 다른 요인이 두 메뉴에 함께 작용했을 수 있습니다. 신뢰도가 1.00인 규칙도 그 조건 메뉴가 나온 며칠에서 관찰된 값일 뿐이며, 다음 식단을 보장하지 않습니다.

7. 확인 문제

문제 1 당곡고 184일 저장본에서 제육볶음 10일, 배추김치 102일, 동시 6일이다. 활동지 기본 문제도 같은 두 메뉴를 다루지만 그쪽은 계산이 떨어지도록 고른 스무 날짜리 설계값이므로 수가 다르다. "제육볶음 → 배추김치"의 신뢰도와 향상도를 손으로 계산한 뒤, 판정을 고릅니다.
신뢰도 = 6÷10 = 0.60, 향상도 = 0.60÷(102÷184) ≈ 1.08. 이 표본에서는 기본 등장률보다 약 8% 높은 비율입니다. 강한 연관이나 독립을 확정하려면 이 값만으로는 부족합니다.
계산 펼쳐 보기

신뢰도는 6÷10 = 0.60, 향상도는 0.60÷(102÷184) ≈ 1.08입니다. 중간 값을 반올림하지 않고 마지막에 반올림합니다. 향상도가 1에 가까워 기본 등장률과 차이가 작지만, 이를 우연의 증명으로 해석하지는 않습니다.

문제 2 "순대국 → 석박지"의 신뢰도는 1.00, "석박지 → 순대국"의 신뢰도는 0.25다. 급식실 게시판에 "석박지가 나오는 날은 순대국이 나온다"라고 써 붙여도 될까요?
규칙에는 방향이 있습니다. 석박지가 나온 20일 중 순대국은 5일뿐이므로, 그 기간의 식단 중 15일은 게시판 문장과 맞지 않습니다. 미래 식단도 보장하지 않습니다.
문제 3 어느 쌍의 향상도가 184로 나왔다(분석 기간 전체에서 동시 등장 1회, 각자 등장도 1회씩). 향상도 9.2인 순대국·석박지보다 20배 강한 규칙이라 말할 수 있을까요?
동시 1회만으로 안정적인 패턴이라고 판단하기 어렵습니다. 동시 5회 이상은 이 실습의 최소 횟수 기준이며, 184일에서 최소 지지도 5÷184 ≈ 0.027에 해당합니다. 이 기준도 우연을 완전히 배제하지는 못합니다.

🎒 오늘의 체크

  • 지지도·신뢰도·향상도의 분모가 각각 무엇인지 말할 수 있다.
  • 교과서 해 보기 ①의 두 규칙을 손으로 계산하고 판정했다.
  • 급식 데이터에서 향상도가 높은 규칙과 기본 등장률에 가까운 규칙을 비교했다.
  • 향상도만으로 인과관계나 미래의 식단을 보장할 수 없는 이유를 설명할 수 있다.

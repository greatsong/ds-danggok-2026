정답표 없이 비슷한 것끼리 묶기

🎯 오늘 만드는 것
  • 지하철역 군집 초안 — 서울 지하철역을 시간대 승차 리듬이 비슷한 묶음으로 나누는 앱

0. 왜 배우나

새 학기 첫날, 서로를 아직 모르는 반에서 모둠을 짜야 한다고 해 봅시다. 시험이라면 정답표를 놓고 채점하면 되지만, 자리 배치에는 채점표가 없습니다. 누구와 누구를 묶는 게 좋은지, 몇 모둠으로 나누는 게 좋은지 미리 정해진 답이 없습니다. 오늘 배우는 군집이 바로 이런 일입니다. 서울 지하철 500여 개 역을 정답표 없이, 하루 리듬이 닮은 것끼리 묶습니다. 정답이 없는데도 컴퓨터는 잘만 묶어 냅니다. 그 묶음을 어떻게 읽고 어디까지 믿을지가 오늘부터 세 시간의 주제입니다.

1. 개념 이해 — 정답표가 없는 학습

📖 교과서의 정의 『데이터 과학』 145쪽

"유사한 데이터끼리 그룹으로 묶는 작업을 군집화(clustering)라고 하며, 이때 구성된 그룹을 군집(cluster)이라고 한다."

→ 정답표(라벨) 없이, 역들을 시간대 승하차 패턴만으로 묶는다 — 오늘이 비지도학습의 첫날이다.

채점할 수 있는 시험, 채점표가 없는 자리 배치

회귀 트랙에서는 연도마다 실제 기온이라는 정답이 있었고, 분류 트랙에서는 시간대마다 실제 혼잡 단계라는 정답이 있었습니다. 모델이 내놓은 답을 정답과 맞춰 보면 몇 점짜리인지 바로 알 수 있었습니다. 이렇게 정답을 보고 규칙을 배우는 방식을 지도학습이라 부릅니다. 오늘은 사정이 다릅니다. "이 역은 무슨 형"이라는 정답 열이 데이터 어디에도 없습니다. 컴퓨터는 정답 없이 비슷한 것끼리 스스로 묶어야 합니다. 이것이 비지도학습입니다. 채점 가능한 시험과 채점표 없는 자리 배치의 차이라고 생각하면 됩니다.

k-means가 하는 일 — 말로 풀면

오늘 쓰는 도구 k-means는 이름은 낯설지만 하는 일은 두 동작의 반복입니다. 먼저 묶음의 중심 k개를 잡고, 각 역을 가장 가까운 중심의 모둠에 넣습니다. 그다음 각 모둠의 중심을 소속 역들의 한가운데로 다시 잡습니다. 배정이 바뀌면 중심이 옮겨 가고, 중심이 옮겨 가면 배정이 또 바뀝니다. 이 두 동작을 더 바뀔 것이 없을 때까지 되풀이하면 "가까운 것끼리 k개 모둠"이 완성됩니다. 여기서 '가깝다'는 오늘 데이터에서는 하루 승차 리듬이 닮았다는 뜻입니다. 미리 알아 둘 것이 하나 있습니다. 몇 모둠으로 나눌지, 즉 k는 컴퓨터가 찾아내는 값이 아니라 사람이 먼저 정해 주는 값입니다.

실루엣 — 제 모둠에 얼마나 붙어 있나

정답표가 없으면 잘 묶였는지 무엇으로 잴까요? 실루엣 점수는 역 하나하나가 제 모둠 동료들과는 얼마나 가깝고, 가장 가까운 이웃 모둠과는 얼마나 떨어져 있는지를 함께 재서 요약한 값입니다. 1에 가까울수록 제 모둠에 바싹 붙어 있으면서 이웃 모둠과는 멀다는 뜻이고, 0에 가까우면 두 모둠의 경계에 어중간하게 걸쳐 있다는 뜻입니다. 다만 이 점수는 채점표가 아니라 참고 자료입니다. 오늘 이 점수를 처음 만나고, 다음 시간에는 이 점수만 믿어도 되는지 따져 봅니다.

자리 배치 비유오늘의 군집
학생 한 명지하철역 하나
서로 친한 정도하루 승차 리듬이 닮은 정도

모둠의 한가운데 자리묶음의 중심 (반복하며 다시 잡음)
"이 배치 괜찮은가"의 감실루엣 점수 (0~1, 참고 자료)

2. 회귀·분류엔 정답이 있었다

  • 회귀: 연도 → 기온이라는 정답이 있었다. 분류: 시간·요일 → 혼잡 단계라는 정답이 있었다.
  • 오늘은 정답표가 없다. 컴퓨터가 스스로 비슷한 것끼리 묶는다. 이것이 비지도학습이다.
종류정답표하는 일예
지도학습있음정답을 보고 규칙을 배움기온 회귀 · 혼잡 분류
비지도학습없음스스로 비슷한 것끼리 묶음오늘: 역 군집

3. 오늘의 데이터 — 지하철역의 하루 리듬

  • 파일: subway_time.csv (2015년부터 매월, 역마다 24개 시간대 승하차 인원 · 약 8만 3천 줄)
  • 역마다 하루 리듬이 다르다. 아침에 사람이 몰려 타는 역이 있고, 저녁에 몰려 타는 역이 있다.
  • 승차 = 지하철을 타는 것. 주거지는 아침에 집을 나서며 타고, 업무·번화가는 저녁에 집으로 가며 탄다.
🔎 데이터 출처 — 서울교통공사
  • 지하철 시간대별 승하차는 서울교통공사가 제공하고 서울특별시가 배포한 자료입니다 · 서울 열린데이터광장 data.seoul.go.kr
  • 믿을 수 있는 이유 — 지하철을 직접 운영하는 서울교통공사가 실제 개찰 기록으로 집계한 1차 당사자 데이터라, 추정이 아니라 실측입니다.
  • 공공누리(출처표시) 계열 공개 데이터입니다. 수업용 사본은 modudata에 있습니다.
💡 왜 '비율'로 바꿀까
  • 큰 역은 어느 시간대든 사람이 많다. 승객 수 그대로 재면 리듬이 아니라 크기로 묶인다.
  • 그래서 역마다 하루 총승차를 100%로 놓고 시간대별 비율(정규화)로 바꾼다. 이래야 크기를 지우고 리듬만 남는다.
  • 비율로 바꾸는 이 판단이 오늘의 핵심이다. 다음 시간에 안 바꾸면 어떻게 되는지 직접 본다.

4. 첫 군집 만들기 (①②③)

  • 도구 = k-means(케이민즈): 미리 정한 묶음 수 k개로 비슷한 것끼리 나누는 방법.
  • 잘 나뉜 정도는 실루엣 점수로 잰다. 1에 가까울수록 안이 촘촘하고 묶음끼리 멀다.
  • requirements.txt에는 scikit-learn·plotly만 (스트림릿·판다스·넘파이는 기본 설치 · 버전 없이).
① 샘플 프롬프트
스트림릿 '지하철역 군집' 앱 하나(main.py)를 만들어줘. 스트림릿 클라우드에 올릴 거야. 조건:

- 데이터는 이 주소에서 불러와. 역마다 24개 시간대의 승차·하차
  인원이 매월 들어 있어. 31MB라 한 번 읽고 캐시에 저장해:
  https://raw.githubusercontent.com/greatsong/modudata/main/data/subway_time.csv
- 가장 최근 달만 남겨. 같은 역이 여러 호선에 나오면 승차 인원을 합쳐 줘.
- 시간대별 '승차 인원'만 골라서, 역마다 하루 총승차를 100%로 놓고
  시간대별 비율로 바꿔 줘(크기 말고 리듬으로 묶기 위해).
- k-means로 비슷한 리듬의 역끼리 3묶음으로 나눠 줘.
- 얼마나 잘 나뉘었는지 실루엣 점수를 카드로 크게 보여주고,
  이 점수가 뭔지 한 줄로 설명해 줘.
- 묶음마다 역이 몇 개씩 들어갔는지도 보여 줘.
- 필요한 라이브러리 목록(requirements.txt)도 같이 줘.
  버전 숫자 없이 이름만, 스트림릿·판다스·넘파이는 기본 설치라 빼고.
- 한국어 라벨, 따뜻한 톤, 초보자용 한국어 주석. main.py 전체 코드를 한 번에 줘.
  • AI가 아래 모습의 코드를 준다 (똑같지 않아도 된다).
② AI가 준 코드 예시
import streamlit as st
import pandas as pd
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score

st.title("🚇 지하철역 군집 나누기")

# 31MB 파일이라 한 번만 읽고 캐시에 저장
@st.cache_data
def load():
    url = "https://raw.githubusercontent.com/greatsong/modudata/main/data/subway_time.csv"
    return pd.read_csv(url)

df = load()

# 전처리 — 가장 최근 달만, 역별로 승차 합치고, 시간대 '비율'로
latest = df[df["사용월"] == df["사용월"].max()]
ride_cols = [c for c in df.columns if "승차" in c]
station = latest.groupby("지하철역")[ride_cols].sum()
ratio = station.div(station.sum(axis=1), axis=0).fillna(0)

# k-means로 3묶음
model = KMeans(n_clusters=3, random_state=42, n_init=10)
labels = model.fit_predict(ratio)

# 얼마나 잘 나뉘었나 — 실루엣 점수(1에 가까울수록 좋음)
score = silhouette_score(ratio, labels)
st.metric("실루엣 점수 (1에 가까울수록 잘 나뉨)", f"{score:.3f}")

# 묶음별 역 수
st.subheader("묶음별 역 수")
st.write(pd.Series(labels, index=ratio.index).value_counts().sort_index())
✔️ 실행하면 이렇게 나온다 (이 달 기준)
  • 최신월 529개 역, 실루엣 점수 0.46 안팎
  • 묶음 크기: 한 묶음 172역(저녁에 몰려 타는 역), 한 묶음 356역(아침에 몰려 타는 역), 그리고 역이 딱 1개뿐인 이상한 묶음
  • 데이터가 매월 갱신돼 숫자는 조금씩 달라진다. 점수가 0.46 근처면 성공.
③ 프롬프트 개선 예시
좋아! 이어서 고쳐줘.
- 묶음마다 대표 역 몇 개(그 묶음에서 승객이 많은 역)를 함께 보여줘.
- 아침(7~9시)에 몰려 타는 묶음인지, 저녁(18~20시)에 몰려 타는
  묶음인지 한눈에 알게, 묶음별 아침·저녁 비율도 표로 보여줘.

8. 확인 문제

지필 문항과 같은 유형입니다. 먼저 스스로 답을 적고 나서 펼쳐 보세요.

문제 1 — 회귀·분류와 달리 오늘의 군집을 '비지도학습'이라 부르는 이유를, '정답표'라는 말을 넣어 한 문장으로 서술하시오.

예시 답안 — 회귀에는 기온, 분류에는 혼잡 단계라는 정답표가 있어 정답을 보고 규칙을 배우지만, 군집에는 "이 역은 무슨 형"이라는 정답표가 없어 컴퓨터가 스스로 비슷한 것끼리 묶기 때문이다.

문제 2 — 승객 수를 그대로 쓰지 않고 역마다 하루 총승차를 100%로 놓은 비율로 바꿔서 묶었다. 그 이유를 서술하시오.

예시 답안 — 큰 역은 어느 시간대든 승객 수가 많아, 그대로 재면 리듬이 아니라 크기가 비슷한 역끼리 묶인다. 비율로 바꾸면 크기가 지워지고 "언제 몰리는가"라는 리듬만 남아, 알고 싶은 기준으로 묶을 수 있다.

문제 3 — 묶음 크기가 172역·356역·1역으로 나왔다. 역이 하나뿐인 묶음이 생겼다는 사실에서 추론할 수 있는 것을 서술하시오.

예시 답안 — 그 역의 하루 리듬이 나머지 모든 역과 동떨어져 있어 가까운 동료가 하나도 없다는 뜻이다. 다른 역과 함께 묶이지 못할 만큼 튀는 값, 곧 이상치일 가능성을 의심하고 왜 튀는지 확인해야 한다.

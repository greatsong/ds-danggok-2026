9차시 본문에서는 영화를 네 속성으로 묶고 묶음마다 이름을 붙였습니다. 이 실험실에서는 세 가지를 더 합니다. 같은 방법을 축구 선수 800명에게 적용해 보고, 표준화를 켜고 끄면서 묶음이 어떻게 달라지는지 화면에서 확인하며, 마지막으로 열을 바꿔 가며 넓혀 봅니다.

  • 3 열을 바꿔 넓히기 — 시장 가치·포지션·소속 팀으로 묶는 대상을 바꿔 본다

본문을 마친 뒤 시간이 남으면 이어서 합니다. 여기에서 만드는 앱은 본문의 영화 앱과 별개이며, main.py를 새로 만듭니다.

1. 축구 선수로도 해 보기 — 800명을 여섯 능력치로

본문에서는 영화를 네 속성으로 묶었습니다. 같은 방법을 대상만 바꾸어 축구 선수에게 적용합니다. 본문 1절의 개념 위젯에서 본 그 데이터입니다.

데이터는 축구 게임 EA FC에 실린 선수 800명의 능력치(eafc_players.csv)입니다. 행 하나가 선수 한 명이고, 열은 이름·포지션·소속 팀·종합 능력치와 속도·슈팅·패스·드리블·수비·몸싸움 여섯 능력치, 시장 가치, 나이, 키입니다. 능력치는 0에서 100 사이의 값이며, 게임이 선수의 플레이를 숫자로 나타낸 것입니다.

📌 스냅샷 표기: 게임사가 공식으로 배포한 파일이 아니라 공개 미러에 정리된 스냅샷입니다. 본문의 영화 표와 달리 날마다 갱신되지 않고, 링크도 고정본을 가리킵니다. 그래서 이 절에 적힌 수치는 언제 실행해도 같은 값이 나옵니다. 다만 고른 능력치·표준화 여부·k를 바꾸면 결과는 달라집니다.

  1. ① 샘플 프롬프트 — 그대로 붙여 넣기
    ① 프롬프트
    "선수 유형 나누기" 스트림릿 앱을 파일 하나(main.py)로 만들어 줘.
화면 맨 위에 앱 제목과 어울리는 아이콘을 넣고, 브라우저 탭에도 그 제목이 표시되게 해 줘.
데이터: https://raw.githubusercontent.com/greatsong/modudata/bb860932644270ad1199f10d3e7670e30231bce4/data/eafc_players.csv
이 파일의 열 이름은 name, long_name, positions, club, overall, pace, shooting, passing, dribbling, defending, physic, value_eur, age, height_cm이고, 인코딩은 UTF-8이야. 축구 게임에 실린 선수 800명의 능력치야.
pace·shooting·passing·dribbling·defending·physic 여섯 능력치는 속도·슈팅·패스·드리블·수비·몸싸움으로 이름을 바꿔서 표시해 줘.
묶는 데 사용할 능력치를 화면 위에서 고르게 해 줘. 둘 이상 고르게 하고 기본은 여섯 개 다야. 고른 능력치를 표준화한 뒤 k-평균으로 묶어 줘. 묶음 수는 2에서 6까지 슬라이더로 고르고 기본은 3으로 해 줘. 다시 실행해도 같은 결과가 나오게 난수를 고정해 줘.
2차원 산점도는 가로축과 세로축에 사용할 능력치를 고르게 해 줘. 그 아래에 3차원 산점도를 하나 더 그려 줘. 3차원은 x·y·z 세 축의 능력치를 고르게 하고, 마우스로 돌릴 수 있고, 묶음마다 색이 다르고, 점에 마우스를 올리면 선수 이름이 보이게 해 줘. 고른 능력치가 셋보다 적으면 3차원 대신 안내 문구를 표시해 줘.
묶음 번호는 0·1·2가 아니라 ㉮·㉯·㉰로 표시하고, 슈팅 평균이 큰 묶음부터 ㉮를 붙여 줘.
묶음마다 인원과 여섯 능력치의 평균을 표로 보여 주고, 종합 능력치(overall)가 높은 선수를 묶음마다 다섯 명씩 보여 줘.
positions 열의 맨 앞 포지션으로 공격수·미드필더·수비수를 나눠서, 묶음과 포지션이 얼마나 겹치는지 교차표로 보여 줘. 포지션은 묶는 데 사용하지 마.
그림은 plotly로만 그려 줘. requirements.txt도 꼭 같이 만들어 줘. streamlit, pandas, plotly, scikit-learn을 버전 숫자 없이 이름만 적어 줘.
    선생님이 실행해 확인한 예시 코드

    main.py와 requirements.txt, 두 파일로 저장합니다.

    main.py — 여기까지가 전체
    # main.py — 선수 유형 나누기: 능력치가 비슷한 축구 선수끼리 묶는다
import streamlit as st
import pandas as pd
import plotly.express as px
from sklearn.preprocessing import StandardScaler
from sklearn.cluster import KMeans

st.set_page_config(page_title="선수 유형 나누기", page_icon="⚽", layout="wide")
st.title("⚽ 선수 유형 나누기")
st.caption("포지션을 사용하지 않고, 고른 능력치가 비슷한 선수끼리 묶습니다.")

DATA = ("https://raw.githubusercontent.com/greatsong/modudata/"
        "bb860932644270ad1199f10d3e7670e30231bce4/data/eafc_players.csv")
능력치 = {"pace": "속도", "shooting": "슈팅", "passing": "패스",
         "dribbling": "드리블", "defending": "수비", "physic": "몸싸움"}
기호 = ["㉮", "㉯", "㉰", "㉱", "㉲", "㉳"]
공격 = {"ST", "CF", "LW", "RW"}
미드 = {"CAM", "CM", "CDM", "LM", "RM"}


def 포지션그룹(칸):
    앞 = 칸.split(",")[0].strip().upper()
    if 앞 in 공격:
        return "공격수"
    if 앞 in 미드:
        return "미드필더"
    return "수비수"


@st.cache_data
def load_data():
    df = pd.read_csv(DATA, encoding="utf-8")
    df = df.dropna(subset=list(능력치) + ["name", "positions"]).reset_index(drop=True)
    df = df.rename(columns=능력치)
    df["포지션"] = df["positions"].map(포지션그룹)
    return df


df = load_data()
항목 = list(능력치.values())

고른항목 = st.multiselect("묶는 데 사용할 능력치 (둘 이상)", 항목, default=항목)
if len(고른항목) < 2:
    st.warning("능력치를 둘 이상 골라 주세요.")
    st.stop()
k = st.slider("몇 묶음으로 나눌까요", 2, 6, 3)

Xs = StandardScaler().fit_transform(df[고른항목])          # 항목마다 변화 폭이 다르므로 표준화한다
번호 = KMeans(n_clusters=k, n_init=10, random_state=42).fit_predict(Xs)
순서 = pd.Series(df["슈팅"].to_numpy()).groupby(번호).mean().sort_values(ascending=False).index
자리 = {g: i for i, g in enumerate(순서)}
df["묶음"] = [기호[자리[g]] for g in 번호]

st.info(f"선수 {len(df):,}명을 {k}묶음으로 나눴습니다. 사용한 능력치: {', '.join(고른항목)}")

st.subheader("묶음 지도 · 2차원")
c1, c2 = st.columns(2)
x축 = c1.selectbox("가로축", 고른항목, index=0)
y축 = c2.selectbox("세로축", 고른항목, index=min(1, len(고른항목) - 1))
fig = px.scatter(df, x=x축, y=y축, color="묶음", hover_name="name",
                 category_orders={"묶음": 기호[:k]})
fig.update_traces(marker=dict(size=7, opacity=0.75))
fig.update_layout(height=460)
st.plotly_chart(fig, width="stretch")
st.caption("점 하나가 선수 한 명입니다. 축을 바꿔 보면 묶음이 나뉘는 축과 섞이는 축이 보입니다.")

st.subheader("묶음 지도 · 3차원")
if len(고른항목) < 3:
    st.info("능력치를 셋 이상 고르면 3차원 그림이 표시됩니다.")
else:
    d1, d2, d3 = st.columns(3)
    x3 = d1.selectbox("x축", 고른항목, index=0, key="x3")
    y3 = d2.selectbox("y축", 고른항목, index=1, key="y3")
    z3 = d3.selectbox("z축", 고른항목, index=2, key="z3")
    fig3 = px.scatter_3d(df, x=x3, y=y3, z=z3, color="묶음", hover_name="name",
                         category_orders={"묶음": 기호[:k]})
    fig3.update_traces(marker=dict(size=2.5, opacity=0.8))
    fig3.update_layout(height=560, legend=dict(orientation="h"))
    st.plotly_chart(fig3, width="stretch")
    st.caption("마우스로 끌면 돌아갑니다. 점에 마우스를 올리면 선수 이름이 보입니다.")

st.subheader("묶음별 인원과 능력치 평균")
요약 = df.groupby("묶음")[항목].mean().round(1)
요약.insert(0, "인원", df.groupby("묶음").size())
st.dataframe(요약.reindex(기호[:k]), width="stretch")

st.subheader("묶음마다 종합 능력치가 높은 다섯 명")
열 = st.columns(k)
for i, 이름 in enumerate(기호[:k]):
    묶음 = df[df["묶음"] == 이름].sort_values("overall", ascending=False).head(5)
    열[i].markdown(f"**{이름} 묶음 ({int((df['묶음'] == 이름).sum()):,}명)**")
    열[i].dataframe(pd.DataFrame({"선수": 묶음["name"].to_numpy(),
                                "종합": 묶음["overall"].to_numpy()}),
                   width="stretch", hide_index=True)

st.subheader("묶음과 포지션은 얼마나 겹치는가")
대조 = pd.crosstab(df["포지션"], df["묶음"]).reindex(columns=기호[:k], fill_value=0)
st.dataframe(대조, width="stretch")
st.caption("포지션은 묶는 데 사용하지 않았습니다. 두 구분이 겹치기는 하지만 일치하지는 않습니다.")

from sklearn.preprocessing import StandardScaler

from sklearn.metrics import silhouette_score

st.title("⚽ 선수 유형 나누기")

    fig3.update_layout(height=560, legend=dict(orientation="h"))
    st.plotly_chart(fig3, width="stretch")
    st.caption("마우스로 끌면 돌아갑니다. 점에 마우스를 올리면 선수 이름이 보입니다.")

st.subheader("묶음별 인원과 능력치 평균")
요약 = df.groupby("묶음")[항목].mean().round(1)
요약.insert(0, "인원", df.groupby("묶음").size())
st.dataframe(요약.reindex(기호[:k]), width="stretch")

st.subheader("묶음마다 종합 능력치가 높은 다섯 명")
열 = st.columns(k)
for i, 이름 in enumerate(기호[:k]):
    묶음 = df[df["묶음"] == 이름].sort_values("overall", ascending=False).head(5)
    열[i].markdown(f"**{이름} 묶음 ({int((df['묶음'] == 이름).sum()):,}명)**")
    열[i].dataframe(pd.DataFrame({"선수": 묶음["name"].to_numpy(),
                                "종합": 묶음["overall"].to_numpy()}),
                   width="stretch", hide_index=True)

st.subheader("묶음과 포지션은 얼마나 겹치는가")
대조 = pd.crosstab(df["포지션"], df["묶음"]).reindex(columns=기호[:k], fill_value=0)
st.dataframe(대조, width="stretch")
st.caption("포지션은 묶는 데 사용하지 않았습니다. 두 구분이 겹치기는 하지만 일치하지는 않습니다.")

# 여기부터 ③ — 묶음 수를 몇으로 할지 정하는 화면
st.divider()

합 = pd.DataFrame({"묶음 수": list(range(1, 8)),
                   "거리 제곱의 합": [round(float(나누기(개수).inertia_), 1) for 개수 in range(1, 8)]})
합["앞보다 줄어든 값"] = ["—" if pd.isna(v) else f"{v:,.1f}" for v in -합["거리 제곱의 합"].diff()]

꺾은선 = px.line(합, x="묶음 수", y="거리 제곱의 합", markers=True)
꺾은선.add_vline(x=k, line_dash="dash", annotation_text=f"지금 고른 묶음 수 {k}")
꺾은선.update_layout(height=380, xaxis_title="묶음 수(k)", yaxis_title="묶음 안 거리 제곱의 합")

st.dataframe(합, width="stretch", hide_index=True)

점수 = pd.DataFrame([{"묶음 수": kk,
                    "실루엣": round(float(silhouette_score(Xs, 나누기(kk).labels_)), 3)}
                   for kk in range(2, 8)])
st.plotly_chart(px.line(점수, x="묶음 수", y="실루엣", markers=True), width="stretch")

화면 읽기 — 어디에서 덜 줄기 시작하는가

아래 위젯은 여섯 능력치를 모두 사용해 선수 800명을 묶었을 때의 값입니다. 왼쪽은 묶음 수를 늘릴 때 군집 내 제곱합이 줄어드는 모습이고, 오른쪽은 묶음 수별 실루엣 점수입니다. k=2의 실루엣이 0.322로 가장 높고 k=3은 0.287입니다. 점수가 가장 높은 묶음 수와 사람이 이해하기 좋은 묶음 수가 늘 같지는 않습니다. 유형 해석 연습은 모든 모둠이 같은 표를 사용하도록 k=3 결과로 진행합니다. k=3이 점수상 최적이라는 뜻은 아닙니다.

k=3 결과 읽기 — 묶음에 이름 붙이기

아래 표는 예시 코드와 같은 조건으로 만든 k=3 군집입니다. 슈팅 평균이 큰 묶음부터 ㉮·㉯·㉰를 붙였으며, 번호에는 순위의 뜻이 없습니다. 각 묶음에 유형 이름을 붙이고 평균 능력치와 대표 선수를 근거로 설명합니다. 본문 4절에서 영화 묶음에 이름을 붙일 때와 같은 방식입니다.

세 줄이 한 칸씩에 몰려 있지 않습니다. 미드필더는 ㉮와 ㉯로 나뉘었고, 수비수도 ㉯와 ㉰로 나뉘었습니다. k-평균은 포지션을 본 적이 없고 능력치만 사용했기 때문입니다. 군집은 분류가 아닙니다. 묶음이 포지션과 얼마나 겹치는지는 결과를 읽은 뒤에 사람이 확인하는 것이지, 알고리즘이 맞히려고 한 목표가 아닙니다.

2. 표준화 스위치 — 변화 폭을 맞추면 누가 옮겨 가는가

여섯 능력치는 모두 0에서 100 사이의 값이지만 벌어지는 폭은 다릅니다. 수비는 포지션에 따라 크게 벌어져 표준편차가 18.1이고, 패스는 7.3에 그칩니다. 폭이 넓은 항목이 거리를 더 많이 정합니다. 아래 그림은 본문 위젯과 같은 선수 114명을 원래 값으로 묶었을 때와 표준화한 뒤 묶었을 때를 비교합니다. 두 결과에서 묶음이 달라지는 선수는 12명입니다. 점 하나를 누르면 그 선수의 원래값과 표준화값이 오른쪽에 함께 표시됩니다.

⚠️ 표준화는 항목의 중요도를 정하지 않습니다

표준화는 항목마다 다른 변화 폭을 맞추는 처리입니다. 폭을 맞춘 뒤에도 어느 항목이 묶음을 실제로 나누었는지는 고르지 않습니다. 아래 막대가 그 점을 보여 줍니다. 어느 항목이 결과를 나누었는지는 묶음별 평균 능력치를 읽어야 알 수 있습니다.

3. 열을 바꿔 넓히기 세 가지

앞 절과 같은 방법을 같은 파일의 다른 열에 적용합니다. 프롬프트에서 사용할 열 이름만 바꾸면 같은 앱이 그대로 동작합니다.

  • 시장 가치·나이·키를 더해 아홉 항목으로 — value_eur는 유로 단위라 수백만까지 올라가고, age는 20 언저리, height_cm는 180 언저리입니다. 단위가 다른 열이 섞이면 표준화 없이는 시장 가치가 거리를 거의 혼자 정합니다. 표준화를 켜고 끄면서 묶음이 어떻게 달라지는지 확인합니다. 본문 1절의 단위 바꾸기 그림이 보여 준 일이 그대로 일어납니다. 시장 가치가 비어 있는 선수 세 명은 빼고 계산해야 합니다.
  • 포지션이 하나뿐인 선수만 골라 묶기 — positions 열에는 RW, ST, CF처럼 포지션이 여러 개 적힌 선수가 있습니다. 쉼표가 없는 선수만 골라 묶은 뒤 포지션과 대조하면 겹치는 정도가 달라집니다. 여러 포지션을 소화하는 선수가 묶음을 흐리게 만든 것인지 확인하는 것이 이 과제입니다. 몇 개짜리까지 남길지를 스스로 정하는 것이 판단할 지점입니다.
  • 선수가 아니라 팀을 묶기 — club 열로 묶어 팀마다 여섯 능력치의 평균을 구하면 행 하나가 선수가 아니라 팀이 됩니다. 그 표를 k-평균으로 묶으면 비슷한 색깔의 팀끼리 모입니다. 다만 소속 선수가 한두 명뿐인 팀은 평균을 믿기 어렵습니다. 최소 몇 명부터 팀으로 볼지를 정하고, 그 기준을 정한 까닭을 적습니다. 6차시의 관측일 필터와 같은 판단입니다.

🎒 오늘의 체크

  • 선수 800명을 여섯 능력치로 묶고, 세 묶음에 이름과 근거를 적었다.
  • 2차원 축을 바꿔 보고, 묶음이 나뉘는 축과 섞이는 축을 구분했다.
  • 3차원 그림을 돌려 보고, 두 축만 볼 때와 무엇이 달라지는지 말했다.
  • 묶음과 포지션 교차표를 읽고, 군집이 분류와 다른 점을 설명했다.
  • 표준화 전과 후에 묶음이 달라진 선수가 누구인지 화면에서 확인했다.
  • 열을 바꿔 넓히기 가운데 하나를 골라 묶고, 묶음마다 이름과 근거를 적었다.

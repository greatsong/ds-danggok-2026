9차시 실험실 · 팀장 보고서와 속성 바꿔 실험하기

9차시 본문에서는 이미 결과가 나온 영화로 두 가지 분류기를 만들고 정확도를 적었습니다. 이 실험실에서는 두 가지를 더 합니다. 아직 결과가 나오지 않은 최근 개봉작에 같은 모델을 적용해 팀장에게 낼 보고서를 만들고, 입력으로 사용할 속성을 바꿔 가며 점수가 어떻게 달라지는지 확인합니다.

  • 2 속성 바꿔 실험하기 — 입력으로 사용할 속성을 바꿔 가며 점수와 트리의 질문이 어떻게 달라지는지 본다

본문 3절의 ③까지 마친 뒤 시간이 남으면 이어서 합니다. 새 앱을 만들지 않고 본문에서 만든 main.py를 그대로 고쳐 갑니다. 두 도전 모두 ③까지 완성한 코드에서 출발합니다.

1. 속성 바꿔 실험하기

이 도전에서는 입력으로 사용할 속성을 화면 맨 위에서 고릅니다. 본문에서 사용한 세 가지 말고도 7차시 실험실에서 사용한 배우 수·주연 수·상영시간·청소년관람불가·대형 배급사를 넣어 볼 수 있습니다. 7차시 실험실이 회귀에서 던진 "속성을 더 모으면 예측이 달라질까"를 분류에서 다시 확인하는 대목입니다. 고른 속성은 정확도만 바꾸지 않습니다. 트리가 던지는 질문, 속성 중요도, 가중치, 그리고 1절의 보고서까지 모두 다시 계산됩니다. 배급사를 넣으면 트리가 첫 질문부터 달라지는지 확인해 봅니다.

  1. 도전 프롬프트 — 입력을 바꿔 가며 실험하기

    이 도전은 9차시 본문에서 만든 앱에 이어서 합니다. 앞에서 만든 main.py를 열어 둔 채로 아래 프롬프트를 붙여 넣습니다. 화면 위쪽의 정확도 카드 셋은 스크린 수·상영 횟수·성수기 세 가지로 학습한 값 그대로이며, 여기에서 속성을 바꾸어도 달라지지 않습니다. 본문의 정확도 표에는 그 고정된 카드의 숫자를 적습니다.

    도전 프롬프트
    앞 코드에 이어서 입력으로 사용할 속성을 바꿔 가며 실험하고 싶어.
바뀐 main.py 전체를 다시 줘. 바뀐 부분만 주지 말고.
이 실험은 새 탭에 넣어 줘. 탭 이름은 "속성 바꿔 실험하기"야.
그 탭 안에서 입력으로 사용할 속성을 고를 수 있게 해 줘. 기본값은 스크린 수·상영 횟수·성수기 세 가지야.
화면 위쪽의 정확도 카드 셋은 스크린 수·상영 횟수·성수기로 학습한 값 그대로 두고, 여기에서 속성을 바꿔도 다시 계산되지 않게 해 줘.
고른 속성으로 두 모델을 다시 학습해서, 그 결과는 이 탭 안에 실험 결과 카드로 따로 보여 주고 고정 카드와의 차이도 함께 표시해 줘.
실험한 트리가 던지는 질문, 속성 중요도, 가중치도 이 탭 안에서 다시 보여 줘.
중요도는 파이 차트로, 가중치는 가로 막대그래프로 그려 줘. 가중치는 0을 기준으로 양수와 음수를 다른 색으로 하고 0 위치에 세로선을 그어 줘.
고를 수 있는 속성에 7차시 실험실에서 사용한 것도 넣어 줘.
https://raw.githubusercontent.com/greatsong/modudata/main/data/kobis_people.csv 에
movieCd·actors_n(배우 수)·lead_n(주연 수)·showTm(상영시간)·watchGrade(관람등급)·company(배급사)가 있어. 인코딩은 utf-8-sig야.
인물 표에도 movieNm과 openDt가 있어서 통째로 합치면 열 이름이 겹쳐. movieCd와 필요한 열만 골라서 합쳐 줘.
movieCd로 left 조인하고, 관람등급에서 청소년관람불가 여부를, 배급사에서 대형 배급사 여부를 0과 1로 만들어 줘.
대형 배급사는 훈련용 데이터에서 많이 나온 상위 다섯 곳으로 정해 줘.
고른 속성의 값이 모두 있는 영화만 사용하고, 몇 편으로 학습했는지 적어 줘.
속성을 바꿔도 훈련용과 테스트용 구분은 달라지지 않게, 영화를 빼기 전에 먼저 정해 줘.
아무것도 고르지 않거나 사용할 수 있는 영화가 너무 적으면 안내 문구를 보여 주고 거기서 멈춰 줘. 이때도 앞 탭의 화면은 그대로 남아 있어야 해.
트리의 질문에는 속성마다 단위를 붙여 줘. 스크린 수는 개, 상영 횟수는 회, 배우 수와 주연 수는 명, 상영시간은 분이야.
성수기·청소년관람불가·대형 배급사처럼 값이 0과 1뿐인 속성은 "성수기에 개봉하지 않았는가?"처럼 예와 아니오로 답하는 질문으로 써 줘.
"상영시간이", "배우 수가"처럼 받침에 맞는 조사를 붙여 줘.
앞에서 정한 네 가지 라이브러리만 사용해 줘. 그림은 plotly로 그려 줘.

    # main.py — 수집된 누적 관객 수가 기준을 넘는지 분류한다
import math
import streamlit as st
import pandas as pd
import plotly.express as px
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score
from sklearn.tree import DecisionTreeClassifier, export_graphviz

st.set_page_config(page_title="흥행 분류기", page_icon="🎬", layout="wide")
st.title("🎬 흥행 분류기")
st.caption("영화가 기준을 넘을지 두 가지 모델로 판정합니다.")

MOVIES = "https://raw.githubusercontent.com/greatsong/modudata/main/data/kobis_movies.csv"
기준 = 1_000_000                                          # 누적 관객 100만 명 이상이면 성공


@st.cache_data
def load_data():
    return pd.read_csv(MOVIES, dtype={"movieCd": str}).sort_values("movieCd").reset_index(drop=True)


df = load_data()
df["성공"] = (df["total_audi"] >= 기준).astype(int)
st.caption(f"누적 관객 {기준:,}명 이상을 성공으로 봅니다 · "
           f"전체 {len(df):,}편 가운데 성공 {df['성공'].sum():,}편")

is_test = pd.Series(df.index % 10 < 3, index=df.index)   # 열 편 중 앞 세 편을 테스트용으로
X = df[["first_scrn", "first_show", "peak"]].rename(
    columns={"first_scrn": "스크린 수", "first_show": "상영 횟수", "peak": "성수기"})
y = df["성공"]

scaler = StandardScaler().fit(X[~is_test])
logi = LogisticRegression(max_iter=2000).fit(scaler.transform(X[~is_test]), y[~is_test])
prob = logi.predict_proba(scaler.transform(X[is_test]))[:, 1]
예측 = (prob >= 0.5).astype(int)

# 트리는 값의 크기에 영향받지 않으므로 표준화하지 않은 X를 그대로 사용한다
# 끝마디에 영화가 다섯 편 미만이면 더 나누지 않는다. 한두 편으로 만든 규칙을 막는다
tree = DecisionTreeClassifier(max_depth=3, min_samples_leaf=5, random_state=0).fit(X[~is_test], y[~is_test])

st.subheader("두 모델의 정확도")
많은쪽 = 1 if y[~is_test].mean() > 0.5 else 0             # 훈련용에서 편수가 많은 범주
기준선 = float((y[is_test] == 많은쪽).mean())              # 그쪽으로만 답했을 때의 정확도
c1, c2, c3 = st.columns(3)
c1.metric("로지스틱 회귀 정확도", f"{accuracy_score(y[is_test], 예측):.3f}")
c2.metric("의사결정트리 정확도", f"{accuracy_score(y[is_test], tree.predict(X[is_test])):.3f}")
c3.metric("한쪽으로만 답했을 때", f"{기준선:.3f}",
          help="입력을 보지 않고 훈련용에서 편수가 많은 쪽으로만 답한 경우입니다.")
맞힌편수 = int((예측 == y[is_test].to_numpy()).sum())
st.caption(f"테스트용 영화 {int(is_test.sum()):,}편 가운데 로지스틱 회귀가 {맞힌편수:,}편을 맞혔습니다 "
           f"({맞힌편수:,} ÷ {int(is_test.sum()):,}).")

단위 = {"스크린 수": "개", "상영 횟수": "회", "배우 수": "명", "주연 수": "명", "상영시간": "분"}
예아니오 = {"성수기": "성수기에 개봉하지 않았는가?",
          "청소년관람불가": "청소년관람불가 등급이 아닌가?",
          "대형 배급사": "대형 배급사가 아닌가?"}


def 조사(말):
    """받침이 있으면 '이', 없으면 '가'를 붙인다."""
    끝 = ord(말[-1])
    받침 = (끝 - 0xAC00) % 28 if 0xAC00 <= 끝 <= 0xD7A3 else 0
    return 말 + ("이" if 받침 else "가")


def 질문(t, 열이름, 마디):
    """분기 조건을 한글 질문으로 바꾼다. '예'가 왼쪽 가지다."""
    속성 = 열이름[t.feature[마디]]
    경계 = float(t.threshold[마디])
    if 속성 in 예아니오:                       # 0과 1뿐인 속성은 경계가 0.5다
        return 예아니오[속성]
    return f"{조사(속성)} {math.floor(경계):,}{단위.get(속성, '')} 이하인가?"


def 마디설명(t, 마디):
    편수 = int(t.n_node_samples[마디])
    성공 = int(round(t.value[마디][0][1] * 편수))
    return f"영화 {편수}편 중 성공 {성공}편"


def 답(t, 마디):
    편수 = int(t.n_node_samples[마디])
    성공 = int(round(t.value[마디][0][1] * 편수))
    return "성공" if 성공 * 2 > 편수 else "기준 미달"


def 트리읽기(t, 열이름, 마디=0, 들여=""):
    """트리를 질문과 예·아니오로 읽어 내려간다."""
    if t.feature[마디] < 0:
        return [f"판정: {답(t, 마디)}  ({마디설명(t, 마디)})"]
    줄 = [f"{질문(t, 열이름, 마디)}  ({마디설명(t, 마디)})"]
    for 답변, 자식 in (("예", t.children_left[마디]), ("아니오", t.children_right[마디])):
        아래 = 트리읽기(t, 열이름, 자식, 들여)
        줄.append(f"{들여}   {답변} → {아래[0]}")
        줄.extend(f"{들여}        {x}" for x in 아래[1:])
    return 줄


열이름 = list(X.columns)


탭1, 탭2, 탭3, 탭4 = st.tabs(["확률로 보기", "질문으로 보기", "무엇을 보고 맞혔나", "속성 바꿔 실험하기"])

with 탭1:
    확률표 = pd.DataFrame({"영화": df.loc[is_test, "movieNm"].values,
                         "추정 확률": prob.round(3),
                         "실제": ["성공" if v else "기준 미달" for v in y[is_test]],
                         "스크린 수": df.loc[is_test, "first_scrn"].values,
                         "누적 관객": df.loc[is_test, "total_audi"].values,
                         "개봉일": pd.to_datetime(df.loc[is_test, "openDt"], format="%Y%m%d",
                                               errors="coerce").dt.strftime("%Y.%m.%d").values})
    확률표 = 확률표.sort_values("추정 확률", ascending=False)
    fig = px.scatter(확률표, x="스크린 수", y="추정 확률", color="실제", hover_name="영화",
                     log_x=True, color_discrete_map={"성공": "#d64545", "기준 미달": "#2b7fd6"})
    fig.add_hline(y=0.5, line_dash="dash", annotation_text="문턱값 0.5")
    fig.update_traces(marker=dict(size=11, opacity=0.8))
    fig.update_layout(height=420, xaxis_title="스크린 수(개) · 로그 눈금", yaxis_title="추정 성공 확률")
    st.plotly_chart(fig, width="stretch")
    st.caption("점 하나가 테스트용 영화 한 편입니다. 색은 실제 레이블이고, "
               "가로 점선 위가 성공으로 예측한 영화입니다. 점에 마우스를 올리면 제목이 표시됩니다.")
    st.dataframe(확률표, width="stretch", hide_index=True, column_config={
        "추정 확률": st.column_config.ProgressColumn("추정 확률", min_value=0.0, max_value=1.0, format="%.2f"),
        "스크린 수": st.column_config.NumberColumn("스크린 수", format="%,d개"),
        "누적 관객": st.column_config.NumberColumn("누적 관객", format="%,d명"),
    })

with 탭2:
    st.subheader("트리는 어떤 질문을 던지나")
    st.markdown("<div style='font-size:1.02rem; line-height:1.95; white-space:pre-wrap'>"
                + "\n".join(트리읽기(tree.tree_, 열이름)) + "</div>", unsafe_allow_html=True)
    st.caption("위에서부터 질문에 답하며 내려가면 마지막 줄의 판정에 닿습니다. "
               "괄호 안은 그 마디에 있는 훈련용 영화의 편수입니다. "
               "끝마디의 판정은 그 안에서 편수가 많은 쪽입니다. "
               "성공과 기준 미달이 같은 수이면 기준 미달로 판정합니다.")

    with st.expander("트리 그림으로 보기"):
        st.graphviz_chart(export_graphviz(tree, out_file=None, feature_names=열이름,
                                          class_names=["기준 미달", "성공"], filled=True, rounded=True))

with 탭3:
    st.subheader("의사결정트리가 본 것 — 속성 중요도")
    중요도 = pd.Series(tree.feature_importances_, index=X.columns).sort_values(ascending=False)
    중요도표 = 중요도.round(3).reset_index()
    중요도표.columns = ["속성", "중요도"]
    st.dataframe(중요도표, width="stretch", hide_index=True)
    st.caption("중요도는 트리가 그 속성으로 얼마나 많이, 얼마나 크게 나눴는지를 나타냅니다. "
               "모두 더하면 1입니다. 0이면 그 속성으로는 한 번도 나누지 않았다는 뜻입니다.")

    st.subheader("로지스틱 회귀가 본 것 — 가중치")
    가중치 = pd.Series(logi.coef_[0], index=X.columns)
    가중치표 = 가중치.reindex(가중치.abs().sort_values(ascending=False).index).round(3).reset_index()
    가중치표.columns = ["속성", "가중치"]
    st.dataframe(가중치표, width="stretch", hide_index=True)
    st.caption(f"절편은 {logi.intercept_[0]:.3f}입니다. 가중치는 표준화한 값에 곱하는 수입니다. "
               "0보다 크면 그 값이 클수록 성공 확률이 올라가고, 작으면 내려갑니다. "
               "중요도와 달리 부호가 있고, 모두 더해도 1이 되지 않습니다.")


with 탭4:
    # 도전 — 입력을 바꿔 가며 실험한다. 위쪽 정확도 카드는 이 선택을 따르지 않는다
    PEOPLE = "https://raw.githubusercontent.com/greatsong/modudata/main/data/kobis_people.csv"

    @st.cache_data
    def load_people():
        return pd.read_csv(PEOPLE, encoding="utf-8-sig", dtype={"movieCd": str})

    확장 = df.merge(load_people()[["movieCd", "actors_n", "lead_n", "showTm", "watchGrade", "company"]],

def 조사(말):
    """받침이 있으면 '이', 없으면 '가'를 붙인다."""
    끝 = ord(말[-1])
    받침 = (끝 - 0xAC00) % 28 if 0xAC00 <= 끝 <= 0xD7A3 else 0
    return 말 + ("이" if 받침 else "가")


def 질문(t, 열이름, 마디):
    """분기 조건을 한글 질문으로 바꾼다. '예'가 왼쪽 가지다."""
    속성 = 열이름[t.feature[마디]]
    경계 = float(t.threshold[마디])
    if 속성 in 예아니오:                       # 0과 1뿐인 속성은 경계가 0.5다
        return 예아니오[속성]
    return f"{조사(속성)} {math.floor(경계):,}{단위.get(속성, '')} 이하인가?"


def 마디설명(t, 마디):
    편수 = int(t.n_node_samples[마디])
    성공 = int(round(t.value[마디][0][1] * 편수))
    return f"영화 {편수}편 중 성공 {성공}편"


def 답(t, 마디):
    편수 = int(t.n_node_samples[마디])
    성공 = int(round(t.value[마디][0][1] * 편수))
    return "성공" if 성공 * 2 > 편수 else "기준 미달"


def 트리읽기(t, 열이름, 마디=0, 들여=""):
    """트리를 질문과 예·아니오로 읽어 내려간다."""
    if t.feature[마디] < 0:
        return [f"판정: {답(t, 마디)}  ({마디설명(t, 마디)})"]
    줄 = [f"{질문(t, 열이름, 마디)}  ({마디설명(t, 마디)})"]
    for 답변, 자식 in (("예", t.children_left[마디]), ("아니오", t.children_right[마디])):
        아래 = 트리읽기(t, 열이름, 자식, 들여)

  • 🔥 대박 조짐이 붙은 영화가 있습니까. 없다면 기간을 바꿔 나타나게 해 봅니다.
  • 실제 칸이 "아직"인 영화는 정답이 나오지 않았습니다. 몇 주 뒤에 다시 열어 확인할 영화를 한 편 골라 적습니다.

🎒 오늘의 체크

  • 최근 개봉작 보고서를 만들고, 두 모델의 판정이 나뉜 영화가 있는지 확인했다.
  • 영화 하나를 골라 트리가 지나온 질문을 처음부터 끝까지 따라 읽었다.
  • 입력으로 사용할 속성을 바꿔 학습하고, 점수가 오른 경우와 내려간 경우를 확인했다.

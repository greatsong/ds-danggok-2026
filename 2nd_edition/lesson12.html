"셀 수 있다고 다 중요한 것은 아니고, 중요하다고 다 셀 수 있는 것도 아니다."
윌리엄 브루스 캐머런 (1963) — 정확도 하나로는 보이지 않는 것을 오늘 손으로 셉니다 윌리엄 브루스 캐머런(1915~1983)은 미국의 사회학자입니다. 위 문장은 오랫동안 아인슈타인이 한 말로 퍼져 지금도 그렇게 인용되지만, 실제로 적은 사람은 캐머런이고 출처는 그가 1963년에 펴낸 사회학 입문서입니다. 유명한 문장일수록 출처가 뒤바뀐 채 도는 일이 흔합니다. 숫자든 인용이든 어디에서 나온 것인지 확인하는 일이 오늘 수업의 주제이기도 합니다.

지난 시간에 검진 기록으로 뇌졸중 여부를 맞히는 모델 두 개를 만들고, 정확도 세 값을 표에 적었습니다. 세 값은 모두 높았습니다. 오늘은 그 정확도가 무엇을 맞힌 값인지 확인합니다. 맞힌 경우와 틀린 경우를 네 칸으로 나누고 정확도·정밀도·재현율·F1을 손으로 계산한 뒤, 내가 만든 앱이 같은 방법으로 같은 값을 내는지 대조합니다.

🧪 도입 — 정확도 99.7%짜리 검사
  • 문제 1. 어떤 코로나 검사 방법의 정확도가 99.7%입니다. 믿고 사용해도 되겠습니까.
    이 방법은 검사를 하지 않고 모두 음성이라고 답하기입니다. 수도권 임시선별검사소에서 2020년 12월부터 2021년 7월까지 약 800만 건을 검사했고, 그 가운데 확진은 약 2만 5천 명이었습니다. 모두 음성이라고 답하면 틀리는 것은 그 2만 5천 명뿐입니다. 800만 − 2만 5천 = 797만 5천이므로 정확도는 약 99.7%입니다.
  • 문제 2. 감염자 다섯 명 가운데 한 명만 찾아내는 자가검사키트(민감도 20%, 특이도 100%)로 같은 800만 명을 검사하면 정확도는 얼마입니까.
    틀리는 것은 놓친 감염자 약 2만 명뿐입니다. 800만 − 2만 = 798만이므로 정확도는 약 99.75%입니다. 검사를 하지 않았을 때와 0.06%p 차이입니다.
  • 문제 3. 정확도가 거의 같은 두 방법에서 실제로 달라진 것은 무엇입니까.

0. 오늘의 목표

위험한 분을 놓치는 오류와 위험하지 않은 분에게 안내를 보내는 오류는 미치는 영향이 다릅니다. 정확도는 두 오류를 구분하지 않고 합쳐서 셉니다. 지난 시간에 읽은 정확도가 무엇을 말해 주지 않는지 먼저 확인하고, 두 오류를 나누어 세는 방법을 손으로 익힙니다.

  • 실제 범주와 예측 범주를 혼동행렬의 네 칸(TP·FP·FN·TN)으로 나누어 채울 수 있다.
  • 네 칸에서 정확도·정밀도·재현율·F1을 손으로 계산하고, 각 지표의 분모가 다른 까닭을 설명할 수 있다.
  • 드문 쪽의 무게를 맞춘 전과 후를 비교해 무엇이 늘고 무엇이 줄었는지 표로 읽을 수 있다.
  • 어느 오류의 대가가 더 큰지를 근거로 볼 지표를 정하고, 그 모델을 사용해도 되는지 판단할 수 있다.

"정밀도는 모델이 양성으로 예측한 것 중 실제 양성인 데이터의 비율을 나타낸다. 재현율은 실제 양성인 데이터 중 모델이 정확하게 예측한 데이터의 비율을 나타낸다." (139쪽)

→ 혼동행렬은 실제 범주와 예측 범주를 교차해 나타낸 표입니다. 오늘의 지표는 모두 이 표에서 계산합니다. 우리가 찾으려는 것은 뇌졸중을 겪은 사람이므로 그쪽을 양성, 겪지 않은 사람을 음성이라고 부릅니다. 본문과 활동지와 위젯에서 같은 이름을 사용합니다.

양성은 좋은 쪽이라는 뜻이 아닙니다. 찾아내려는 쪽을 양성이라고 부릅니다. 스팸 필터에서는 스팸이 양성이고, 오늘 문제에서 찾으려는 것은 뇌졸중 위험이 높은 분이므로 뇌졸중이 양성입니다.

실제와 예측을 짝지으면 네 가지 경우가 나옵니다. 각각을 TP·FP·FN·TN이라는 영어 약자로 부릅니다. 약자는 글자 두 개가 각각 다른 것을 가리킵니다.

  • 앞 글자 T와 F는 True와 False입니다. 그 예측이 맞았는지 틀렸는지를 나타냅니다.
  • 뒤 글자 P와 N은 Positive와 Negative, 곧 양성과 음성입니다. 무엇이라고 예측했는지를 나타냅니다.

그래서 FP는 False Positive, 뇌졸중(양성)이라고 예측했는데 틀린 경우입니다. 실제로는 건강한 분에게 안내를 보내게 됩니다. FN은 False Negative, 아니라고(음성) 예측했는데 틀린 경우이며 실제로는 위험한 분입니다. 뒤 글자는 언제나 예측을 가리킨다는 것만 기억하면 네 칸이 헷갈리지 않습니다.

오늘부터 네 칸을 우리말로도 부릅니다. TP는 찾아낸 환자, FN은 놓친 환자, FP는 헛짚은 사람입니다. 3절부터는 이 이름으로 읽습니다.

🧮 F1 — 두 값 가운데 낮은 쪽에 더 끌려가는 평균

정밀도와 재현율은 서로 다른 모델을 가리키는 일이 자주 있습니다. 둘을 한 값으로 모아 보는 것이 F1입니다. 보통의 평균과 달리 두 값 가운데 낮은 쪽에 더 끌려갑니다. 그래서 한쪽만 높은 모델은 F1이 높아지지 않습니다. 정밀도와 재현율 가운데 하나라도 구할 수 없거나 0이면 F1도 0으로 둡니다.

③ 정밀도 · 재현율TP ÷ (TP + FP)와 TP ÷ (TP + FN)분자는 같고 분모가 다릅니다. 정밀도는 예측이 기준, 재현율은 실제가 기준입니다.
④ F12 × 정밀도 × 재현율 ÷ (정밀도 + 재현율)③에서 구한 두 값으로 계산합니다. 두 문제 모두 같은 수로 나누게 되어 있습니다.
⑤ 판단볼 지표와 고를 모델, 그리고 그렇게 정한 까닭①~④에서 구한 값을 보고 판단하는 단계입니다. 네 지표가 같은 모델을 가리키는지부터 확인합니다.

기본 문제의 세 규칙 가운데 규칙 C는 전부 아니라고만 답하는 규칙입니다. 1절에서 본 기준 모델과 같은 방식입니다. 정확도가 모델 A와 같게 나오는데 F1은 다르게 나옵니다. 그 까닭을 활동지 ⑤에 적습니다.

기본 문제를 손으로 다 푼 뒤, 아래 화면에서 같은 표를 사례 순서대로 확인합니다. 값이 다르면 어느 단계에서 어긋났는지 되짚습니다.

import streamlit as st

from sklearn.preprocessing import StandardScaler

데이터주소 = "https://raw.githubusercontent.com/greatsong/modudata/main/data/stroke.csv"
입력열 = ["age", "avg_glucose_level", "hypertension", "heart_disease"]


@st.cache_data

    return pd.read_csv(데이터주소, encoding="utf-8").sort_values("id").reset_index(drop=True)


df = 데이터_읽기()
채점용 = pd.Series(df.index % 10 < 3, index=df.index)   # '분류 모델' 페이지와 같은 방법으로 나눈다
X = df[입력열]

def 네칸(예측값):
    """행은 실제, 열은 예측. 네 칸의 사람 수를 센다."""
    TP = int(((실제 == 1) & (예측값 == 1)).sum())        # 뇌졸중을 뇌졸중이라 맞힌 사람 (찾아낸 환자)
    FN = int(((실제 == 1) & (예측값 == 0)).sum())        # 뇌졸중을 아니라고 놓친 사람 (놓친 환자)
    FP = int(((실제 == 0) & (예측값 == 1)).sum())        # 아닌데 뇌졸중이라 헛짚은 사람
    TN = int(((실제 == 0) & (예측값 == 0)).sum())        # 아닌 사람을 아니라고 맞힌 사람
    return TP, FN, FP, TN


def 혼동행렬표(TP, FN, FP, TN):
    표 = pd.DataFrame(
        [[f"{TP}명 (TP)", f"{FN}명 (FN)", f"{TP + FN}명"],
         [f"{FP}명 (FP)", f"{TN}명 (TN)", f"{FP + TN}명"],
         [f"{TP + FP}명", f"{FN + TN}명", f"{TP + FN + FP + TN}명"]],
        index=["실제 뇌졸중", "실제 아님", "열 합계"],
        columns=["뇌졸중이라 예측", "아니라고 예측", "행 합계"])
    표.index.name = "행 = 실제 · 열 = 예측"
    return 표


def 지표(TP, FN, FP, TN):
    """네 칸에서 네 지표를 구한다. 분모가 0이면 None을 돌려준다."""
    정확도 = (TP + TN) / (TP + FN + FP + TN)
    정밀도 = TP / (TP + FP) if (TP + FP) > 0 else None   # 분모는 뇌졸중이라 예측한 사람 수
    재현율 = TP / (TP + FN) if (TP + FN) > 0 else None   # 분모는 실제 뇌졸중인 사람 수
    if 정밀도 is None or 재현율 is None or (정밀도 + 재현율) == 0:
        F1 = None
    else:
        F1 = 2 * 정밀도 * 재현율 / (정밀도 + 재현율)
    return 정확도, 정밀도, 재현율, F1


def 소수(값):
    return "계산할 수 없음" if 값 is None else f"{값:.4f}"

def 학습(무게):

def 네칸(예측값):
    TP = int(((실제 == 1) & (예측값 == 1)).sum())
    FN = int(((실제 == 1) & (예측값 == 0)).sum())
    FP = int(((실제 == 0) & (예측값 == 1)).sum())
    TN = int(((실제 == 0) & (예측값 == 0)).sum())
    return TP, FN, FP, TN


def 지표(TP, FN, FP, TN):
    정확도 = (TP + TN) / (TP + FN + FP + TN)
    정밀도 = TP / (TP + FP) if (TP + FP) > 0 else None
    재현율 = TP / (TP + FN) if (TP + FN) > 0 else None
    if 정밀도 is None or 재현율 is None or (정밀도 + 재현율) == 0:
        F1 = None
    else:
        F1 = 2 * 정밀도 * 재현율 / (정밀도 + 재현율)
    return 정확도, 정밀도, 재현율, F1

6. 정리 — 네 칸에서 판단까지

오늘 한 일을 순서대로 되짚으면 이렇습니다. 먼저 정확도 하나로는 세 모델을 구별할 수 없다는 것을 확인했습니다. 그다음 맞힘과 틀림을 네 칸으로 나누고, 네 칸에서 정확도·정밀도·재현율·F1을 손으로 계산했습니다. 정밀도와 재현율은 분자가 같고 분모가 다르며, F1은 두 값 가운데 낮은 쪽에 더 끌려갑니다.

그다음 학습 방법을 한 가지 바꾸어 다시 채점했습니다. 정확도는 내려갔고 찾아낸 환자는 늘었습니다. 이 변화를 좋아졌다고 읽을지 나빠졌다고 읽을지는 지표가 정해 주지 않습니다. 어느 오류의 대가가 더 큰지를 정한 사람이 읽습니다. 마지막으로 그 판단을 한 장에 적었습니다.

지금까지 다섯 시간 동안 모델을 만들고 채점했습니다. 그동안 데이터는 주소 하나로 불러왔습니다. 다음 시간에는 그 데이터가 어디에 어떤 모양으로 놓여 있는지를 봅니다. 데이터가 사는 곳을 데이터베이스라고 합니다.

7. 확인 문제

문제 1 채점용 1,533명 가운데 실제 뇌졸중은 82명입니다. 어떤 모델이 뇌졸중이라고 답한 사람은 465명이고, 그 가운데 실제 환자는 67명이었습니다. 이 모델의 재현율을 구할 때 분모는 얼마입니까?
재현율의 분모는 실제가 기준입니다. 실제 뇌졸중인 82명이 분모이므로 67 ÷ 82입니다. 465는 정밀도의 분모이고, 1,533은 정확도의 분모입니다.
문제 2 어떤 모델의 정밀도가 1.00, 재현율이 0.25였습니다. 이 모델의 F1은 얼마입니까?
2 × 1.00 × 0.25 ÷ (1.00 + 0.25) = 0.50 ÷ 1.25 = 0.40입니다. 두 값의 보통 평균은 0.63이지만 F1은 그보다 낮습니다. F1은 두 값 가운데 낮은 쪽에 더 끌려가기 때문입니다. 활동지 기본 문제의 모델 B가 이 값입니다.
✍️ 문제 3 · 두 줄로 적습니다
  • 스위치를 켜자 정확도는 내려갔고 찾아낸 환자는 늘었습니다. 검진센터는 어느 쪽을 골라야 합니까. 고른 지표 이름 하나와 까닭을 적습니다. 까닭에는 줄이려는 오류가 무엇인지, 그 대가를 누가 치르는지를 함께 적습니다.

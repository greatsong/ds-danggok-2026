데이터베이스

데이터베이스: 여러 사람이 공유할 수 있도록 통합 관리하는 데이터의 집합
파일 사본을 따로 고칠 때
  • 두 사람이 같은 파일의 사본을 각자 가져감
  • 각자 다른 부분을 고친 뒤 원래 자리에 저장
  • 나중에 저장한 파일이 앞의 파일을 덮어씀
  • 결과: 먼저 고친 변경 일부를 잃음
데이터베이스의 기능
  • 동시 사용: 여러 사람이 한꺼번에 고쳐도 변경을 잃지 않음
  • 조건 검색: 조건에 맞는 데이터만 찾기
  • 권한 관리: 사람마다 읽기·수정 권한을 따로 부여

                        학번이름면접
                        
          
        
                        
      
                        
      
                          
        
                        • 한 행만 바꾸거나 지울 때: 기본 키로 지정 WHERE 학번 = 20133
                          • 
        
                        • 이름으로 지정하면 동명이인까지 바뀌거나 지워질 수 있음
                          • 
        
                        • WHERE가 없어도 오류 없이 실행됨 (경고 없음)
                          • 
      
                        
    
                        
  
                        
  
                        

                        



                        
  
                        정리
                        
  
                        SQL 문법 한눈에 보기
                        
  
                        
    
                        SELECT 열 FROM 테이블열 고르기 (* = 모든 열)
                        
    
                        WHERE 조건행 고르기 · 문자·날짜는 '따옴표'
                        
    
                        ORDER BY 열 ASC / DESC정렬 · 생략하면 ASC
                        
    
                        LIMIT n앞에서 n행만
                        
    
                        GROUP BY 열 · COUNT(*)묶음마다 행 수 · AVG(열)은 평균
                        
    
                        열1 + 열2 AS 이름계산 열 · 결과 열에 별칭 붙이기
                        
    
                        WHERE 열 LIKE '윤%'글자 패턴으로 행 고르기 · % = 0개 이상의 아무 글자
                        
    
                        INSERT INTO 테이블 (열, …) VALUES (…)행 추가 · 열을 생략하면 모든 열을 열 순서대로
                        
    
                        UPDATE 테이블 SET 열 = 값, … WHERE 조건값 바꾸기 · SET이 WHERE보다 앞
                        
    
                        DELETE FROM 테이블 WHERE 조건행 삭제
                        
    
                        SELECT → FROM → WHERE → GROUP BY → ORDER BY → LIMIT절을 적는 순서
                        
  
                        
  
                        UPDATE·DELETE에서 WHERE 생략 → 모든 행이 대상

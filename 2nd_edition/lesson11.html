"얼굴이 한쪽으로 처지는가, 팔에 힘이 빠지는가, 말이 어눌해지는가."
대한뇌졸중학회 FAST 캠페인

현장에서는 이 세 가지를 확인해 둘 중 하나를 정합니다. 오늘 만들 모델이 하는 일도 그렇습니다.

5,110명의 건강 기록을 바탕으로 뇌졸중을 겪은 사람과 겪지 않은 사람을 구분해 봅니다. 기온이나 관객 수처럼 숫자를 예측하는 것이 아니라, 정해진 두 범주 가운데 하나를 예측하는 문제입니다.

🚑 도입 — 뇌졸중은 드문 병이 아닙니다

뇌졸중은 뇌로 가는 혈관이 막히거나 터져서 발생하는 질환입니다. 치료가 늦어지면 심각한 후유증이 남을 수 있습니다.

2021년 한 해 동안 새로 발생한 뇌졸중 환자는 10만 8,950명으로, 하루 평균 약 300명꼴입니다. 인구 10만 명당 발생률은 212.2건이며, 이는 2011년보다 9.5% 증가한 수치입니다. 특히 80세 이상에서는 10만 명당 1,508.4건으로 발생률이 크게 높아집니다.

판단은 결국 둘 중 하나입니다. 뇌졸중인가, 아닌가. 이렇게 정해진 범주 가운데 하나를 맞히는 문제를 분류라고 합니다.

  • 분류 모델 만들기 — 두 가지 분류 모델을 학습하고 기준 모델과 정확도를 비교한다

0. 오늘의 목표

건강 기록의 네 가지 항목으로 뇌졸중 여부를 예측하는 두 가지 분류 모델을 만듭니다. 학습에 사용하지 않은 데이터를 따로 남겨 두고, 모델이 얼마나 맞히는지 확인합니다.

  • 맞혀야 할 답의 모양으로 회귀와 분류를 구분할 수 있다.
  • 데이터의 게시자·라이선스·사사 표기를 확인하고, 분석 결과를 어디까지 해석할 수 있는지 설명할 수 있다.
  • 두 가지 분류 모델을 만들고, 채점용 데이터에서 정확도를 계산해 비교할 수 있다.
🏥 우리는 DG메디컬 건강검진센터의 데이터 과학 인턴입니다

검진센터는 뇌졸중을 겪은 적이 있는 분께 재발을 막는 생활 관리 상담을 안내합니다. 다만 모든 기록에 뇌졸중 병력이 적혀 있지는 않습니다. 예전에 문진표를 받은 5,110명분의 기록에는 뇌졸중 여부가 기재되어 있지만, 올해 새로 들어온 검진 결과에는 해당 항목이 비어 있습니다.

센터장은 답이 적힌 5,110명분의 데이터로 모델을 만들어, 답이 없는 기록에서 상담 안내 대상을 가려내려 합니다. 안내 한 통에는 비용이 들고, 상담할 수 있는 인원도 정해져 있어 전원에게 보낼 수는 없습니다.

하지만 모델부터 만들지는 않습니다. 데이터가 어디서 왔는지 먼저 확인합니다.

DG메디컬은 이 수업에서만 사용하는 가상의 검진센터입니다. 분석에 사용하는 건강 기록은 캐글에 공개된 교육용 데이터입니다.

import pandas as pd
import streamlit as st

st.set_page_config(page_title="뇌졸중 예측 실습실", page_icon="🩺", layout="wide")
st.title("🩺 뇌졸중 예측 실습실")
st.write("건강 기록 5,110명분을 읽어 옵니다. 왼쪽 메뉴에서 페이지를 넘기며 들여다보고, 모델을 만들고, 채점합니다.")

데이터주소 = "https://raw.githubusercontent.com/greatsong/modudata/main/data/stroke.csv"


@st.cache_data
def 데이터_읽기():
    """UTF-8로 저장된 csv를 읽는다. bmi 열의 빈 값은 그대로 빈 값으로 남는다."""
    return pd.read_csv(데이터주소, encoding="utf-8")


df = 데이터_읽기()

st.subheader("한눈에 보기")
칸1, 칸2, 칸3, 칸4 = st.columns(4)
칸1.metric("전체 사람 수", f"{len(df):,}명")
칸2.metric("열 개수", f"{df.shape[1]}개")
칸3.metric("뇌졸중을 겪은 사람", f"{int(df['stroke'].sum()):,}명")
칸4.metric("그 비율", f"{df['stroke'].mean() * 100:.2f}%")

st.subheader("열마다 무엇이 들어 있는가")
st.caption("우리말 뜻 칸은 비어 있습니다. 교재의 열 대응표를 보고 직접 채워 넣으세요. 적은 내용은 저장되지 않습니다.")


def 값의_종류(열):
    """숫자 열은 가장 작은 값과 가장 큰 값을, 글자 열은 값의 가짓수와 실제 값을 적는다."""
    칸 = df[열].dropna()
    if pd.api.types.is_numeric_dtype(칸) and 칸.nunique() > 2:
        return f"숫자 {칸.min():g} ~ {칸.max():g}"
    값들 = sorted(칸.unique().astype(str))
    return f"{len(값들)}가지 · " + " · ".join(값들)


열설명 = pd.DataFrame({
    "열 이름": df.columns,
    "우리말 뜻": [""] * df.shape[1],
    "값의 종류": [값의_종류(열) for 열 in df.columns],
    "빈 값 개수": [int(df[열].isna().sum()) for 열 in df.columns],
})
st.data_editor(
    열설명,
    width="stretch",
    hide_index=True,
    disabled=["열 이름", "값의 종류", "빈 값 개수"],   # 우리말 뜻 칸만 고쳐 쓸 수 있다
    key="열설명표",
)

st.subheader("앞 다섯 줄 그대로 보기")
st.dataframe(df.head(5), width="stretch", hide_index=True)

st.subheader("이 데이터는 어디서 왔는가")

st.text_area("교재를 보고 여기에 적습니다", value=출처_기본값, height=170, key="출처")
st.caption("이 데이터를 올린 사람은 원본 데이터가 어디서 왔는지 밝히지 않았고, 교육 목적으로만 사용하라고 적어 두었습니다. "

2. 데이터 살펴보기

어떤 항목이 뇌졸중 여부를 구분하는 데 도움이 될까요? 모델을 만들기 전에 값의 분포, 두 그룹의 차이, 비어 있는 값을 살펴봅니다. 이처럼 데이터의 특성을 파악하는 과정을 탐색적 데이터 분석이라고 합니다.

뇌졸중을 겪은 그룹과 겪지 않은 그룹에서 값의 분포가 비슷하다면, 그 항목만으로 두 그룹을 구분하기는 어렵습니다. 탐색 결과를 바탕으로 모델의 입력 후보를 고릅니다.

4. 분류 모델 만들고 평가하기

첫 분류 모델의 입력으로는 나이 · 평균 혈당 · 고혈압 · 심장병을 사용합니다. 2절에서 두 그룹의 차이를 확인했고, 빈 값도 없는 네 항목입니다. 다른 열은 다음 이유로 이번 입력에서 제외합니다.

  • 성별 · 거주 지역 — 성별과 사는 곳으로 사람을 나누면 편향이 생깁니다. 오늘은 넣지 않습니다.
  • 결혼 경험 · 직업 형태 — 결혼한 적이 있는 사람은 대체로 나이가 많습니다. 나이를 이미 넣었으므로 같은 것을 두 번 넣지 않습니다.
  • 체질량지수 — 값이 비어 있는 기록이 있습니다. 빈 값을 어떻게 처리할지는 다음 시간에 판단합니다.
  • 흡연 상태 — ‘알 수 없음’으로 기록된 값이 많습니다. 이번에는 분포를 확인하고 입력에서는 제외합니다.

데이터를 훈련용과 채점용으로 나눕니다. 열 명 가운데 앞 세 명의 기록은 채점용으로 남겨 두고, 나머지 기록으로만 학습합니다. 채점용 데이터는 학습에 사용하지 않습니다. 나이와 혈당의 크기를 맞출 때도 훈련용 데이터에서 구한 값만 사용합니다.

비교 대상으로 입력을 보지 않고, 훈련용 데이터에서 사람이 더 많은 범주로만 예측하는 모델도 만듭니다. 이 모델을 기준으로 삼아, 학습한 두 모델이 얼마나 다른 결과를 내는지 확인합니다.

먼저 네 항목을 기본 입력으로 사용해 세 모델의 정확도를 기록합니다. 그다음 입력 속성을 바꾸면서 정확도가 어떻게 달라지는지 비교합니다.

데이터주소 = "https://raw.githubusercontent.com/greatsong/modudata/main/data/stroke.csv"
고를수있는열 = ["age", "avg_glucose_level", "bmi", "hypertension", "heart_disease"]
기본열 = ["age", "avg_glucose_level", "hypertension", "heart_disease"]

    return pd.read_csv(데이터주소, encoding="utf-8").sort_values("id").reset_index(drop=True)


def 우리말(열):
    return 입력이름[열]


df = 데이터_읽기()

    st.warning("속성을 두 개 이상 골라 주세요. 하나만으로는 그림의 두 축을 만들 수 없습니다.")
    st.stop()

채점용 = pd.Series(df.index % 10 < 3, index=df.index)   # 열 명 중 앞 세 명이 채점용

y = df["stroke"]                                        # 1이면 뇌졸중, 0이면 아님. 뇌졸중이 양성이다

def 학습(열들):
    """고른 열로 두 모델을 학습해 돌려준다. 설정은 늘 같다."""
    훈련 = X.loc[~채점용, 열들]
    크기맞추기 = StandardScaler().fit(훈련)   # 크기 맞추기도 훈련용으로만 한다
    확률모델 = LogisticRegression(max_iter=2000).fit(크기맞추기.transform(훈련), y[~채점용])
    # 질문으로 답하는 모델은 값의 크기에 영향받지 않으므로 크기를 맞추지 않은 값을 그대로 사용한다
    질문모델 = DecisionTreeClassifier(max_depth=3, min_samples_leaf=5, random_state=0).fit(훈련, y[~채점용])
    return 크기맞추기, 확률모델, 질문모델


크기맞추기, 확률모델, 질문모델 = 학습(입력열)

        f"채점용 {int(채점용.sum()):,}명(그중 실제 뇌졸중 {int(실제.sum()):,}명)으로 채점합니다.")

def 눈금(열):
    """채점용에서 가장 작은 값부터 가장 큰 값까지 고르게 나눈 값들을 돌려준다."""
    작은값, 큰값 = float(채점입력[열].min()), float(채점입력[열].max())
    큰값 = 큰값 if 큰값 > 작은값 else 작은값 + 1.0
    return [작은값 + (큰값 - 작은값) * i / (칸수 - 1) for i in range(칸수)]


def 두줄로(값들):   # 한 줄로 늘어선 값을 세로줄마다 잘라 표 모양으로 만든다
    return [값들[i * 칸수:(i + 1) * 칸수] for i in range(칸수)]


가로눈금, 세로눈금 = 눈금(가로), 눈금(세로)

화면 읽기 — 세 모델의 정확도 비교하기

화면 상단의 카드에서 세 모델의 정확도를 확인해 아래 표에 옮겨 적습니다. 정확도는 채점용 데이터에서 뇌졸중 여부를 맞힌 비율입니다.

모델답하는 방식내 앱의 정확도
확률로 답하는 모델0부터 1 사이의 확률
질문으로 답하는 모델질문의 순서(규칙)
한쪽으로만 답하는 모델입력을 보지 않고 훈련용에서 많은 쪽

앱의 그래프에서 두 모델이 사람들을 어떻게 나누는지 비교합니다. 점 하나는 채점용 데이터의 한 사람을 나타냅니다. 질문으로 답하는 모델의 첫 질문과 기준값을 기록하고, 그 항목이 2절에서 두 그룹의 차이가 두드러졌던 항목과 같은지 비교합니다.

세 모델의 정확도는 모두 높고 차이도 크지 않습니다. 그런데 이 중 하나는 입력을 전혀 보지 않은 모델입니다. 학습하지 않아도 높은 정확도를 얻는 이유는 무엇일까요?

5. 정리

오늘은 출처 확인 → 탐색 → 입력 선택 → 훈련/채점 분리 → 모델 비교 순서로 진행했습니다. 마지막에는 두 분류 모델과 기준 모델의 정확도를 나란히 적었습니다.

다른 데이터로 분류 모델을 만들 때도 이 흐름을 활용할 수 있습니다. 오늘 만든 세 화면의 파일을 정리하면 다음과 같습니다.

오늘이 끝나면
내 저장소/
├── main.py                 ← 첫 화면: 이 데이터는 무엇인가
├── requirements.txt        ← 저장소에 하나. 앱 전체에 적용된다
└── pages/
    ├── 1_탐색.py            ← 분포·두 그룹 비교·비어 있는 값
    └── 2_분류_모델.py        ← 두 모델 학습, 정확도 세 값

4절에 기록한 세 모델의 정확도는 다음 시간에 다시 사용합니다. 높은 정확도가 무엇을 맞히고 무엇을 놓친 결과인지 예측 결과를 네 칸으로 나누어 확인합니다.

6. 확인 문제

문제 1 6차시 기온 예측, 7차시 영화 관객 수 예측, 9차시 영화 유형 묶기, 오늘의 뇌졸중 여부 맞히기 가운데 분류는 무엇일까요? 답을 눌러 확인합니다.
분류는 맞혀야 할 답이 정해진 범주 가운데 하나인 문제입니다. 뇌졸중 여부는 겪었다와 겪지 않았다 둘 중 하나이므로 분류입니다. 기온과 관객 수는 답이 숫자이므로 회귀이고, 영화 유형 묶기는 맞혀야 할 답 자체가 없으므로 군집입니다.
문제 2 확률로 답하는 모델이 어떤 사람에게 0.32라는 값을 계산했습니다. 이 모델은 그 사람을 어느 쪽으로 예측할까요?
교과서 136쪽이 적은 대로 출력값이 0.5보다 크면 양성, 작으면 음성으로 분류합니다. 0.32는 0.5보다 작으므로 답은 뇌졸중이 아니다입니다. 모델이 계산하는 것은 확률이지만, 그 확률을 0.5와 비교해 둘 중 하나로 답하는 것까지가 분류 모델이 하는 일입니다.
문제 3 오늘 입력에서 체질량지수를 넣지 않았습니다. 그렇게 정한 이유는 무엇일까요?
체질량지수 열에는 값이 비어 있는 사람이 있습니다. 비어 있는 값을 어떻게 다룰지는 그 자체로 하나의 판단이므로, 첫 분류 모델을 만드는 오늘은 값이 모두 채워진 네 항목만 사용했습니다. 값의 범위가 다른 것은 크기를 맞추면 되는 일이고, 두 그룹의 값이 똑같지도 않습니다.

🎒 오늘의 체크

  • 맞혀야 할 답의 모양으로 회귀와 분류를 구분해 말할 수 있다.
  • 이 데이터의 게시자·라이선스·사사 표기를 읽고, 실제 의학적 판단에 사용하지 않는 이유를 말할 수 있다.
  • 뇌졸중을 겪은 사람의 비율을 화면에서 확인하고 적었다.
  • 확률이 0과 1 사이에서만 움직이고 0.5를 기준으로 답이 나뉜다는 것을 말할 수 있다.
  • 세 모델의 정확도를 비교하고, 기준 모델이 입력을 보지 않고 한 범주로만 예측한다는 것을 설명할 수 있다.

용어뜻
분류정해진 범주 가운데 하나를 맞히는 것. 범주가 둘뿐이면 이진 분류라고 한다.

1. 가설 세우기 — 무엇이 흥행을 가른다고 생각합니까

예측 모델을 만들 때 가장 먼저 할 일은 코드를 쓰는 것이 아닙니다. 무엇을 재료로 삼을지 정하는 것입니다. 데이터에 있는 열을 전부 넣고 결과를 기다리면 점수가 오르든 내리든 그 까닭을 설명할 수 없습니다. 그래서 데이터를 열기 전에 가설을 먼저 적습니다.

가설은 두 부분으로 이루어집니다. 무엇이 흥행에 영향을 준다는 주장, 그리고 그렇게 생각하는 까닭입니다. 여기에 조건이 하나 더 붙습니다. 그 주장은 표의 한 열로 옮길 수 있어야 합니다. "재미있는 영화가 흥행한다"는 맞는 말일 수 있지만 재미를 적어 둔 열이 없으므로 확인할 방법이 없습니다. "상영시간이 길면 관객이 적을 것이다"는 상영시간이라는 열만 있으면 바로 확인할 수 있습니다.

가설을 적을 때 가중치의 부호까지 함께 생각해 두면 나중에 결과를 읽기 쉬워집니다. 주연이 많을수록 관객이 많아진다고 보았다면 그 속성의 가중치는 양수여야 하고, 상영시간이 길수록 관객이 줄어든다고 보았다면 음수여야 합니다. 학습을 마친 뒤 부호가 예상과 반대로 나오면 그때부터 살펴볼 대목이 생깁니다. 가설이 틀렸을 수도 있고, 함께 넣은 다른 변수가 같은 것을 담고 있어서 부호가 뒤집혔을 수도 있습니다.

💡 가설을 적어 본 예
가설그렇게 생각한 까닭확인할 방법
주연이 여럿인 영화일수록 관객이 많을 것이다.이름이 알려진 배우를 여럿 세운 영화는 홍보가 크게 붙는다.주연 수를 세어 둔 열이 있는지 확인하고, 있으면 모델에 넣어 점수 변화를 본다.
상영시간이 길면 총 관객이 적을 것이다.한 상영관에서 하루에 돌릴 수 있는 회차가 줄어든다.상영시간 열을 넣어 보고 가중치의 부호를 확인한다.
청소년 관람 불가 등급은 총 관객이 적을 것이다.볼 수 있는 관객의 범위가 좁다.관람등급을 0과 1로 바꾼 열을 만들어 넣는다.

2. API 문서에서 확인하기 — 있는 열과 없는 열

가설을 적었으면 다음은 그 속성이 실제로 있는지 확인하는 순서입니다. 데이터를 받기 전에 무엇이 들어 있는지 알려 주는 문서를 먼저 읽습니다. 영화진흥위원회 오픈 API는 영화 한 편의 상세 정보를 돌려주는 창구를 따로 두고 있고, 거기에서 감독·배우·상영시간·관람등급·배급사를 받을 수 있습니다. 이 실험실에서는 그 결과를 미리 모아 둔 표를 사용합니다.

실제로 데이터를 다루는 일은 대체로 이 순서로 이루어집니다. 필요한 것을 먼저 정하고, 그것을 어디에서 얻을 수 있는지 문서에서 찾고, 얻을 수 없으면 계획을 고칩니다. 데이터를 먼저 받아 놓고 무엇을 할지 정하면, 이미 가진 열에 맞추어 질문이 바뀝니다.

🔎 데이터에 없는 것
  • 제작비와 홍보비 — 공개하지 않는 영화가 많아 이 표에 없습니다.
  • 예고편 조회수 — 영화진흥위원회가 모으는 데이터가 아닙니다.
  • 감독의 이전 흥행 기록 — 감독 이름은 있지만 이전 작품의 관객 수는 없습니다.

감독의 이전 흥행 기록은 특히 아쉬운 항목입니다. 감독 이름이 표에 있으니 이전 작품의 관객 수만 붙이면 될 것처럼 보입니다. 그런데 이 표는 최근에 10위권에 든 영화만 모은 것이라 한 감독의 영화가 대체로 한 편씩만 올라 있습니다. 감독 이름으로 묶어 보면 같은 감독의 이전 작품이 함께 들어 있는 경우가 드물어서, 이전 흥행 기록을 계산할 데이터 자체가 없습니다. 표에서 감독 이름별로 몇 편이 올라 있는지 직접 세어 보면 이 사정이 그대로 보입니다.

가설을 적었는데 확인할 데이터가 없는 일은 자주 일어납니다. 그때 할 수 있는 일은 세 가지입니다. 첫째, 뜻이 비슷한 다른 열로 대신합니다. 둘째, 데이터를 더 모읍니다. 여러 해에 걸친 기록을 모으면 같은 감독의 영화가 여러 편 들어오므로 이전 흥행 기록을 계산할 수 있습니다. 셋째, 지금은 확인할 수 없다고 적어 두고 다음으로 넘어갑니다. 확인하지 못한 가설을 기록으로 남기는 것도 결과입니다.

3. 데이터 수집 — 과거 영화와 최근 개봉작을 나눈다

영화별 표와 인물 표를 영화 코드로 합칩니다. 일별 박스오피스 표도 함께 읽어 실제 데이터의 마지막 날짜를 확인합니다. 영화 이름을 고르면 스크린 수·상영 횟수·배우 수·상영시간 등을 자동으로 불러오므로 숫자를 직접 입력할 필요가 없습니다.

최근 개봉작이 정답과 함께 학습에 들어가지 않도록 먼저 분리합니다. 데이터 기준일로부터 최근 30일 안에 개봉한 영화는 예측 전용으로 남기고, 개봉 후 60일 이상 지난 영화만 훈련용·테스트용으로 나눕니다. 아직 개봉하지 않은 영화와 필수 속성이 없는 영화는 선택 목록에서 제외합니다.

예측 목표는 과거 작품의 마지막 관측일 누적관객입니다. 모든 영화의 최종 관객 수가 확정된 표는 아닙니다. 스크린 수와 상영 횟수는 첫 관측일의 실적이므로 이번 활동은 개봉 후 데이터를 이용한 예측입니다.

필수 입력이 비거나 스크린 수·상영 횟수·상영시간이 0 이하인 영화는 빼고, 결측 편수와 사용 편수를 보여 줘.

from datetime import datetime
from io import BytesIO
from urllib.request import urlopen
from zoneinfo import ZoneInfo

import pandas as pd
import plotly.express as px
import streamlit as st
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_absolute_error, r2_score

ROOT = "https://raw.githubusercontent.com/greatsong/modudata/main/data/"
FONT_URL = "https://raw.githubusercontent.com/google/fonts/main/ofl/nanumgothic/NanumGothic-Bold.ttf"
BASE = ["first_scrn", "first_show", "peak"]
EXTRA = {"배우 수": "actors_n", "주연 수": "lead_n", "상영시간": "showTm",
         "청소년관람불가": "adult", "대형 배급사": "bigco"}
LABELS = dict(zip(BASE, ["첫 관측일 스크린 수", "첫 관측일 상영 횟수", "성수기 개봉"]))
LABELS.update({v: k for k, v in EXTRA.items()})
NEEDED = ["actors_n", "lead_n", "showTm", "watchGrade", "company"]


@st.cache_data(ttl=3600, show_spinner=False)
def fetch(url):
    with urlopen(url, timeout=25) as response:
        return response.read()


def prepare(movies, people, daily, today):
    # '최근'은 달력과 실제 데이터 마지막 날짜를 모두 확인한다.
    daily = daily.copy()
    daily["관측일"] = pd.to_datetime(daily["날짜"].astype(str), format="%Y%m%d", errors="coerce")
    daily = daily[daily["관측일"].notna() & (daily["관측일"] <= today)]
    if daily.empty:
        raise ValueError("오늘까지의 관측 기록이 없습니다.")
    asof = daily["관측일"].max()
    if movies["movieCd"].duplicated().any() or people["movieCd"].duplicated().any():
        raise ValueError("영화 코드가 중복되어 있습니다. 데이터 갱신 후 다시 확인하세요.")
    df = movies.merge(people[["movieCd", "director"] + NEEDED], on="movieCd", how="inner", validate="one_to_one")
    merged_n = len(df)
    for col in BASE + ["actors_n", "lead_n", "showTm"]:
        df[col] = pd.to_numeric(df[col], errors="coerce")
    for col in ["watchGrade", "company"]:
        df[col] = df[col].replace(r"^\s*$", pd.NA, regex=True)
    missing = df[BASE + NEEDED].isna().sum()
    df["개봉일"] = pd.to_datetime(df["openDt"].astype(str), format="%Y%m%d", errors="coerce")
    df["첫 관측일"] = pd.to_datetime(df["first_date"].astype(str), format="%Y%m%d", errors="coerce")
    df = df.dropna(subset=BASE + NEEDED + ["개봉일", "첫 관측일"])
    df = df[(df["first_scrn"] > 0) & (df["first_show"] > 0) & (df["showTm"] > 0)
            & (df["첫 관측일"] <= asof) & (df["개봉일"] <= asof)].copy()
    df["adult"] = (df["watchGrade"] == "청소년관람불가").astype(int)

    history = df[df["개봉일"] <= cutoff].sort_values("movieCd").reset_index(drop=True)

    train, test = history[~mask].copy(), history[mask].copy()

def evaluate(model, data, cols):
    pred = model.predict(data[cols])
    r2 = r2_score(data["total_audi"], pred) if data["total_audi"].nunique() > 1 else float("nan")
    return {"영화 수": len(data), "R²": r2,
            "MAE(명)": mean_absolute_error(data["total_audi"], pred)}


def score(train, test, cols):
    model = LinearRegression().fit(train[cols], train["total_audi"])
    return model, evaluate(model, train, cols), evaluate(model, test, cols)

6. 이상치 검토 — 일부 훈련 영화를 제외하고 다시 평가한다

수정본 적용: 기존 STEP 6 전체를 교체합니다. 같은 선택 위젯을 두 번 넣으면 중복 키 오류가 납니다. STEP 6 교체용 코드 다운로드 · 앞 단계에서 만든 변수와 함수를 사용하는 부분 코드입니다.

첫 평가 뒤에는 산점도에서 모델이 크게 빗나간 영화를 먼저 살펴봅니다. 가로축은 실제 관측 누적관객, 세로축은 예측 관객이며, 점선은 두 값이 같은 위치입니다. 점에 마우스를 올려 영화 이름과 오차를 확인하고, 주변 영화와 얼마나 떨어져 있는지 살핍니다. 샘플은 훈련 데이터의 절대오차가 Q3 + 1.5 × IQR보다 큰 영화를 후보로 표시합니다. IQR은 가운데 50% 범위의 폭(Q3 − Q1)입니다. 크게 흥행한 실제 영화일 수도 있으므로 후보를 자동으로 삭제하지 않습니다.

제외할 영화를 선택하면 남은 훈련 영화로 다시 학습합니다. 테스트 영화는 한 편도 바꾸지 않고 제외 전후 R²·MAE를 비교합니다. 훈련 데이터는 줄었으므로 편수도 함께 확인합니다. 제외했는데 테스트 성능이 나빠졌다면 그 결과도 남깁니다.

6단계 프롬프트
첫 평가 다음에 이상치 후보를 검토하는 단계를 추가해 줘.
훈련 영화별 실젯값·예측값·절대오차를 계산하고, 절대오차의 3사분위수에 사분위 범위의 1.5배를 더한 기준보다 큰 영화를 후보로 보여 줘.
사분위 범위는 가운데 50% 범위의 폭이라고 짧게 설명해 줘. 후보라고 오류인 것은 아니니 자동 삭제하지 마.
후보 표와 제외 선택보다 먼저 모든 훈련 영화의 산점도를 접지 않고 보여 줘. 가로축은 실제 관측 누적관객, 세로축은 예측 관객으로 해 줘.
실젯값과 예측값이 같은 점선을 넣고, 음수 예측도 보이는 선형 축과 같은 숫자 범위를 써 줘.
후보는 주황색 마름모, 나머지는 파란 원으로 구분하고, 점에 마우스를 올리면 영화 이름·영화 코드·실젯값·예측값·절대오차가 나오게 해 줘.
점선과의 세로 차이가 오차임을 설명하고, 확대해서 분포와 영화 정보를 먼저 확인한 후 제외 여부를 판단하도록 안내해 줘.
제외할 영화는 학생이 직접 선택하게 하고, 선택하면 남은 훈련 데이터로 다시 학습·평가해 줘.
테스트 영화는 제외하거나 교체하지 마. 배급사 기준과 선택 속성도 바꾸지 마.
제외 전후의 훈련·테스트 R²와 MAE, 영화 수를 같은 표에 보여 줘. 테스트 MAE가 줄면 개선으로 표시해 줘.

7. 최근 개봉작 예측 — 이 영화, 어디까지 갈까?

최근 개봉작 목록에서 영화 이름을 선택합니다. 필요한 입력을 자동으로 불러와 재평가한 모델의 예측과 기본 속성 모델의 예측을 나란히 보여 줍니다. 두 모델은 같은 제외 후 훈련 데이터를 사용합니다. 이미 관측된 관객 수는 참고로만 표시하고 입력에는 넣지 않습니다.

마지막에는 NEXT SCENE 공유 카드를 만듭니다. 영화 제목, 예상 관객, 데이터 기준일, 테스트 점수, 제외한 훈련 영화 수를 담은 1080 × 1350 PNG를 저장할 수 있습니다. 게시글 설명도 함께 내려받아 인스타그램 등에 직접 올릴 수 있습니다.

현재 목록은 박스오피스 10위권에 관측되었고 필요한 입력이 있는 최근 개봉작입니다. 모든 상영작이 들어 있는 것은 아닙니다.

선택한 영화의 스크린 수·상영 횟수·성수기 여부와 고른 추가 속성을 데이터에서 자동으로 불러와 보여 줘.
이 영화는 훈련·테스트 데이터 모두에서 제외되어 있어야 해. 현재까지의 누적관객은 참고로만 보여 주고 입력에 넣지 마.
바로 앞 단계에서 이상치 후보를 제외하고 재평가한 모델로 예측해 줘. 기본 속성 모델도 동일한 제외 후 훈련 데이터로 학습해 나란히 비교해 줘.
영화 제목과 관객 예측을 크게 보여 주는 'NEXT SCENE — 이 영화, 어디까지 갈까?' 카드를 만들어 줘.
짙은 남색 배경에 밝은 연두색 숫자, 큰 한글 제목으로 편집해 줘. 긴 영화명은 줄바꿈해서 다 보여 줘.
1080×1350 PNG로 저장하고, 함께 올릴 설명은 TXT로 내려받게 해 줘. 외부 포스터 없이 글자와 도형으로 만들어 줘.
카드에는 데이터 기준일·첫 관측일·테스트 R²와 MAE·제외한 훈련 영화 수·데이터 출처를 함께 적어 줘.
실제 집계나 개봉 전 전망이 아닌 학습용 예측임을 표시해 줘. 최종 관객 수나 흥행 성공을 확정한다고 쓰지 마.
예측이 음수이거나 이미 관측된 관객보다 작으면 값을 올려 맞추지 말고 안내해 줘. 학습 범위 밖의 입력도 확인하고, 이 경우 공유 카드 생성을 보류해 줘.
한글 글꼴은 Google Fonts의 Nanum Gothic Bold를 불러와 Pillow로 그려 줘. 글꼴을 못 받으면 예측값은 유지하고 카드 저장만 다시 시도하도록 안내해 줘.

    """외부 포스터 없이 직접 그리는 1080×1350 공유 카드."""
    image = Image.new("RGB", (1080, 1350), "#10192b")
    draw = ImageDraw.Draw(image)
    ink, muted, accent = "#f7f4ed", "#bac4d7", "#d5ff67"
    def font(size):
        return ImageFont.truetype(BytesIO(font_bytes), size)
    def write(text, xy, size, color=ink):
        draw.text(xy, str(text), font=font(size), fill=color)
    def wrap(text, max_width, size):
        lines, line = [], ""
        for char in str(text):
            if draw.textlength(line + char, font=font(size)) > max_width and line:
                lines.append(line); line = char
            else:
                line += char
        if line:
            lines.append(line)
        return lines

def prepare(movies, people, daily, today):
    # '최근'은 달력과 실제 데이터 마지막 날짜를 모두 확인한다.
    daily = daily.copy()
    daily["관측일"] = pd.to_datetime(daily["날짜"].astype(str), format="%Y%m%d", errors="coerce")
    daily = daily[daily["관측일"].notna() & (daily["관측일"] <= today)]
    if daily.empty:
        raise ValueError("오늘까지의 관측 기록이 없습니다.")
    asof = daily["관측일"].max()
    if movies["movieCd"].duplicated().any() or people["movieCd"].duplicated().any():
        raise ValueError("영화 코드가 중복되어 있습니다. 데이터 갱신 후 다시 확인하세요.")
    df = movies.merge(people[["movieCd", "director"] + NEEDED], on="movieCd", how="inner", validate="one_to_one")
    merged_n = len(df)
    for col in BASE + ["actors_n", "lead_n", "showTm"]:
        df[col] = pd.to_numeric(df[col], errors="coerce")
    for col in ["watchGrade", "company"]:
        df[col] = df[col].replace(r"^\s*$", pd.NA, regex=True)
    missing = df[BASE + NEEDED].isna().sum()
    df["개봉일"] = pd.to_datetime(df["openDt"].astype(str), format="%Y%m%d", errors="coerce")
    df["첫 관측일"] = pd.to_datetime(df["first_date"].astype(str), format="%Y%m%d", errors="coerce")
    df = df.dropna(subset=BASE + NEEDED + ["개봉일", "첫 관측일"])
    df = df[(df["first_scrn"] > 0) & (df["first_show"] > 0) & (df["showTm"] > 0)
            & (df["첫 관측일"] <= asof) & (df["개봉일"] <= asof)].copy()
    df["adult"] = (df["watchGrade"] == "청소년관람불가").astype(int)
    # 관측일이 확인되는 일별 표의 마지막 누적관객을 사용한다.
    latest = daily.sort_values("관측일").drop_duplicates("영화코드", keep="last")
    latest = latest[["영화코드", "관측일", "누적관객"]].rename(columns={
        "영화코드": "movieCd", "관측일": "마지막 관측일", "누적관객": "관측 누적관객"})
    latest["관측 누적관객"] = pd.to_numeric(latest["관측 누적관객"], errors="coerce")
    df = df.merge(latest, on="movieCd", how="inner", validate="one_to_one")
    df = df.dropna(subset=["관측 누적관객"])
    df = df[df["관측 누적관객"] > 0].copy()
    df["total_audi"] = df["관측 누적관객"]
    # 최근 30일 개봉작은 예측 전용. 최소 60일 지난 작품만 훈련·테스트에 쓴다.
    cutoff = asof - pd.Timedelta(days=60)
    history = df[df["개봉일"] <= cutoff].sort_values("movieCd").reset_index(drop=True)
    recent = df[df["개봉일"] > asof - pd.Timedelta(days=30)].copy()
    mask = history.index % 10 < 3
    train, test = history[~mask].copy(), history[mask].copy()
    if len(train) < 20 or len(test) < 5:
        raise ValueError("훈련·테스트에 쓸 과거 영화가 부족합니다.")
    # 배급사 상위 5곳도 훈련 데이터로만 정한다.
    big = train["company"].value_counts().head(5).index
    for part in [train, test, recent]:
        part["bigco"] = part["company"].isin(big).astype(int)
    recent = recent.sort_values(["개봉일", "first_scrn"], ascending=[False, False])
    return train, test, recent, asof, missing, merged_n


def evaluate(model, data, cols):
    pred = model.predict(data[cols])
    r2 = r2_score(data["total_audi"], pred) if data["total_audi"].nunique() > 1 else float("nan")
    return {"영화 수": len(data), "R²": r2,
            "MAE(명)": mean_absolute_error(data["total_audi"], pred)}


def score(train, test, cols):
    model = LinearRegression().fit(train[cols], train["total_audi"])
    return model, evaluate(model, train, cols), evaluate(model, test, cols)

from PIL import Image, ImageDraw, ImageFont


def report_png(movie, prediction, baseline, evaluation, asof, cols, excluded_count, font_bytes):
    """외부 포스터 없이 직접 그리는 1080×1350 공유 카드."""
    image = Image.new("RGB", (1080, 1350), "#10192b")
    draw = ImageDraw.Draw(image)
    ink, muted, accent = "#f7f4ed", "#bac4d7", "#d5ff67"
    def font(size):
        return ImageFont.truetype(BytesIO(font_bytes), size)
    def write(text, xy, size, color=ink):
        draw.text(xy, str(text), font=font(size), fill=color)
    def wrap(text, max_width, size):
        lines, line = [], ""
        for char in str(text):
            if draw.textlength(line + char, font=font(size)) > max_width and line:
                lines.append(line); line = char
            else:
                line += char
        if line:
            lines.append(line)
        return lines
    # 필름 프레임과 큰 활자. 제목은 줄바꿈해 긴 영화명도 담는다.
    draw.rounded_rectangle((42, 42, 1038, 1308), radius=26, outline="#3d4a62", width=2)
    draw.rounded_rectangle((72, 75, 385, 127), radius=26, fill=accent)
    write("NEXT SCENE / 07", (91, 86), 25, "#10192b")
    write(f"DATA {asof:%Y.%m.%d}", (720, 90), 24, muted)
    write("이 영화, 어디까지 갈까?", (76, 163), 39)
    title_size = 65
    while title_size > 24 and len(wrap(movie["movieNm"], 914, title_size)) > 3:
        title_size -= 2
    y = 231
    for line in wrap(movie["movieNm"], 914, title_size):
        write(line, (76, y), title_size)
        y += title_size + 12
    write(f"개봉 {movie['개봉일']:%Y.%m.%d}  ·  {movie['watchGrade']}", (77, 476), 25, muted)
    draw.line((76, 533, 1004, 533), fill="#3d4a62", width=2)
    write("관객 예측", (76, 571), 29, muted)
    number = f"{prediction / 10000:,.1f}만 명"
    size = 108
    while draw.textlength(number, font=font(size)) > 922 and size > 30:
        size -= 2
    write(number, (70, 626), size, accent)
    write("실제 집계가 아닌 모델의 추정", (77, 769), 26, muted)
    write(f"기본 속성 모델  {baseline / 10000:,.1f}만 명", (77, 828), 28)
    write(f"테스트 R²  {evaluation['R²']:.3f}", (77, 883), 28)
    write(f"테스트 MAE  {evaluation['MAE(명)'] / 10000:,.1f}만 명", (540, 883), 28)
    write(f"입력 {len(cols)}개 · 훈련 {excluded_count}편 제외 후 재평가", (77, 944), 25, muted)
    draw.line((76, 1004, 1004, 1004), fill="#3d4a62", width=2)

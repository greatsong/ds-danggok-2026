# 브라우저에서 도는 실습 앱

학생이 만들 앱을 그대로 배포해 둔 것입니다. 파이썬을 설치하지 않아도
주소만 열면 돌아갑니다(stlite — 브라우저 안에서 파이썬을 실행합니다).

| 폴더 | 차시 | 주소 |
|---|---|---|
| `stroke/` | 11·12 | https://greatsong.github.io/ds-danggok-2026/app/stroke/ |

## 사용하는 자리

- 실습 시간이 모자랄 때 선생님 화면으로 시연합니다.
- 학생 컴퓨터에서 설치가 막혔을 때 임시로 사용합니다.

처음 열 때 파이썬과 라이브러리를 내려받느라 30초에서 1분쯤 걸립니다.
두 번째부터는 브라우저에 남아 있어 빠릅니다.

## 코드는 교재가 원본입니다

`stroke/main.py`와 `stroke/pages/*.py`는 교재 lesson11·lesson12의 예시 코드
블록을 그대로 옮긴 것입니다. 손으로 고치지 않습니다. 교재 코드가 바뀌면
`_workspace/lesson11-12/code/`로 다시 추출한 뒤 이 폴더로 복사합니다.

## stlite 판 번호를 올릴 때

`index.html`은 `@stlite/browser@1.4.0`을 부릅니다. 1.7 이후 판은
`st.data_editor`가 동작하지 않아(`arrow_table` 오류) main.py의 열 대응표가
깨집니다. 판 번호를 올리기 전에 여섯 페이지를 모두 열어 확인합니다.

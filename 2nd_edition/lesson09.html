2. 로지스틱 회귀 분류 모델 만들기

첫 번째로 만들 것은 영화마다 성공할 확률을 계산해 주는 분류기입니다. 로지스틱 회귀는 스크린 수와 상영 횟수 같은 값을 보고 0과 1 사이의 확률 하나를 내놓습니다. 확률이 0.5를 넘으면 성공으로 봅니다.

아래 프롬프트를 그대로 붙여 넣으면 앱이 만들어집니다. 만든 뒤에 화면에 표시된 확률과 정확도를 읽는 것이 이 절에서 할 일입니다. 정확도 옆에는 입력을 보지 않고 한쪽으로만 답했을 때의 점수가 함께 나옵니다. 두 값을 견주어 보는 이야기는 10차시에서 이어집니다. 입력은 첫 관측일의 스크린 수, 같은 날의 상영 횟수, 성수기 개봉 여부 세 가지입니다.

이 표는 날마다 새로 수집하므로 화면에 나오는 편수와 점수가 사람마다, 날마다 다릅니다. 그리고 표에는 개봉한 지 얼마 안 된 영화도 들어 있어, 오늘 하는 일은 개봉 전 예측이 아니라 수집된 누적 관객 기록이 기준을 넘는지 분류하는 연습입니다.

입력에서 빼는 값도 있습니다. 첫 주 관객 수와 7차시에서 만든 상영당 관객 수는 둘 다 관객 수를 품고 있습니다. 오늘의 정답 레이블을 바로 그 총 관객 수로 만들었으므로, 이 값을 입력에 넣으면 정답의 일부를 미리 알려 주게 됩니다. 두 값을 빼는 이유는 이 하나입니다. 스크린 수와 상영 횟수도 상영당 관객 수와 같은 날의 집계이지만 관객 수를 품고 있지 않아 남겨 둡니다. 어느 시점의 값을 입력에 사용할 수 있는지는 7차시에서 다뤘습니다.

스크린 수는 수백, 성수기는 0과 1이라 값의 크기가 크게 다릅니다. 로지스틱 회귀는 값의 크기에 민감하므로 훈련용 데이터의 평균과 퍼짐을 기준으로 모든 입력의 크기를 맞춥니다. 이것을 표준화라고 하며 11차시에서 다시 다룹니다.

    # main.py — 수집된 누적 관객 수가 기준을 넘는지 분류한다
import streamlit as st
import pandas as pd
import numpy as np
import plotly.express as px
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score

st.set_page_config(page_title="흥행 분류기", page_icon="🎬", layout="wide")
st.title("🎬 흥행 분류기")
st.caption("영화가 기준을 넘을지 두 가지 모델로 판정합니다.")

MOVIES = "https://raw.githubusercontent.com/greatsong/modudata/main/data/kobis_movies.csv"


@st.cache_data
def load_data():
    return pd.read_csv(MOVIES, dtype={"movieCd": str}).sort_values("movieCd").reset_index(drop=True)


df = load_data()
기준 = st.selectbox("성공이라고 부를 기준 (누적 관객)",
                  [100_000, 300_000, 500_000, 1_000_000, 3_000_000], index=3,
                  format_func=lambda v: f"{v // 10_000}만 명 이상 ({v:,}명)")
df["성공"] = (df["total_audi"] >= 기준).astype(int)
st.caption(f"누적 관객 {기준:,}명 이상을 성공으로 봅니다 · "
           f"전체 {len(df):,}편 가운데 성공 {df['성공'].sum():,}편")
st.info("수집된 누적 관객 기록의 분류 연습입니다. 개봉 전 예측 성능을 뜻하지 않습니다.")

is_test = pd.Series(df.index % 10 < 3, index=df.index)   # 열 편 중 앞 세 편을 테스트용으로
X = df[["first_scrn", "first_show", "peak"]].rename(
    columns={"first_scrn": "스크린 수", "first_show": "상영 횟수", "peak": "성수기"})
y = df["성공"]

scaler = StandardScaler().fit(X[~is_test])
logi = LogisticRegression(max_iter=2000).fit(scaler.transform(X[~is_test]), y[~is_test])
prob = logi.predict_proba(scaler.transform(X[is_test]))[:, 1]

st.subheader("정확도")
많은쪽 = 1 if y[~is_test].mean() > 0.5 else 0          # 훈련용에서 편수가 많은 범주
기준선 = float((y[is_test] == 많은쪽).mean())            # 그쪽으로만 답했을 때의 정확도
c1, c3 = st.columns(2)
c1.metric("로지스틱 회귀 정확도", f"{accuracy_score(y[is_test], (prob >= 0.5).astype(int)):.3f}")
c3.metric("한쪽으로만 답했을 때", f"{기준선:.3f}", help="입력을 보지 않고 훈련용에서 편수가 많은 쪽으로만 답한 경우입니다.")

🧮 확률은 어디에서 나오나

세 가지 입력에 각각 가중치를 곱해 모두 더하고, 어느 영화에나 같은 수 하나를 더합니다. 이렇게 나온 수가 가중합입니다. 가중치는 사람이 정한 것이 아니라 훈련용 데이터로 학습한 값입니다.

가중합은 아주 큰 값도 작은 값도 될 수 있어 그대로는 확률이 아닙니다. 시그모이드 함수가 어떤 수든 0과 1 사이로 바꿔 줍니다. 선형 회귀를 먼저 학습한 뒤 출력만 바꾸는 절차가 아니라, 처음부터 분류에 맞게 가중치를 학습합니다. 그 확률을 가르는 경계가 문턱값이고, 이 실습에서는 0.5입니다.

더 알아보기 — 로지스틱 회귀라는 이름은 어디에서 왔나

시그모이드라는 말은 그리스 문자 시그마의 이름에 ‘닮은’이라는 뜻의 말꼬리가 붙어 만들어졌습니다. 이 이름은 함수의 성질이 아니라 곡선의 모양을 가리킵니다. 우리말로 옮기면 ‘S자를 닮은’이라는 뜻입니다.

로지스틱이라는 이름은 벨기에 수학자 피에르 프랑수아 베르휠스트가 1845년에 붙였습니다. 그는 인구가 늘어나다가 한계에 부딪혀 완만해지는 곡선을 연구하면서 이 곡선에 로지스틱이라는 이름을 붙이겠다고만 적었습니다. 왜 그 이름인지는 밝히지 않았습니다. 로지스틱은 ‘계산에 밝은’이라는 뜻의 그리스어에서 온 말입니다. 베르휠스트가 이 곡선을 로그 곡선과 나란히 놓고 설명했기 때문에 그 대비에서 나온 이름으로 추정할 뿐, 확실한 근거는 없습니다.

회귀라는 말은 영국의 프랜시스 골턴이 1886년 논문에서 사용했습니다. 그는 키가 아주 큰 부모의 자녀가 부모보다 작고, 키가 아주 작은 부모의 자녀가 부모보다 큰 쪽으로 평균에 되돌아가는 현상을 회귀라고 불렀습니다. 그 뒤 회귀라는 말의 쓰임이 넓어져, 변수 사이의 관계를 하나의 식으로 맞추는 일 전체를 회귀라고 부르게 되었습니다. 그래서 로지스틱 회귀는 범주를 예측하는데도 회귀라는 이름이 붙습니다. 답의 형태가 회귀여서가 아니라, 가중합이라는 식을 데이터에 맞추는 절차가 회귀에서 왔기 때문입니다.

def load_data():
    return pd.read_csv(MOVIES, dtype={"movieCd": str}).sort_values("movieCd").reset_index(drop=True)


df = load_data()

                  [100_000, 300_000, 500_000, 1_000_000, 3_000_000], index=3,

def 조사(말):
    """받침이 있으면 '이', 없으면 '가'를 붙인다."""
    끝 = ord(말[-1])
    받침 = (끝 - 0xAC00) % 28 if 0xAC00 <= 끝 <= 0xD7A3 else 0
    return 말 + ("이" if 받침 else "가")


def 질문(마디):
    """분기 조건을 한글 질문으로 바꾼다. '예'가 왼쪽 가지다."""
    속성 = 열이름[t.feature[마디]]
    경계 = float(t.threshold[마디])
    if 속성 in 예아니오:                       # 0과 1뿐인 속성은 경계가 0.5다
        return 예아니오[속성]
    return f"{조사(속성)} {math.floor(경계):,}{단위.get(속성, '')} 이하인가?"


def 마디설명(마디):
    편수 = int(t.n_node_samples[마디])
    성공 = int(round(t.value[마디][0][1] * 편수))
    return f"영화 {편수}편 중 성공 {성공}편"


def 답(마디):
    편수 = int(t.n_node_samples[마디])
    성공 = int(round(t.value[마디][0][1] * 편수))
    return "성공" if 성공 * 2 > 편수 else "기준 미달"


def 트리읽기(마디=0, 들여=""):
    """트리를 질문과 예·아니오로 읽어 내려간다."""
    if t.feature[마디] < 0:
        return [f"판정: {답(마디)}  ({마디설명(마디)})"]
    줄 = [f"{질문(마디)}  ({마디설명(마디)})"]
    for 답변, 자식 in (("예", t.children_left[마디]), ("아니오", t.children_right[마디])):

        줄.extend(f"{들여}        {x}" for x in 아래[1:])
    return 줄

def 조사(말):
    """받침이 있으면 '이', 없으면 '가'를 붙인다."""
    끝 = ord(말[-1])
    받침 = (끝 - 0xAC00) % 28 if 0xAC00 <= 끝 <= 0xD7A3 else 0
    return 말 + ("이" if 받침 else "가")


def 질문(마디):
    """분기 조건을 한글 질문으로 바꾼다. '예'가 왼쪽 가지다."""
    속성 = 열이름[t.feature[마디]]
    경계 = float(t.threshold[마디])
    if 속성 in 예아니오:                       # 0과 1뿐인 속성은 경계가 0.5다
        return 예아니오[속성]
    return f"{조사(속성)} {math.floor(경계):,}{단위.get(속성, '')} 이하인가?"


def 마디설명(마디):
    편수 = int(t.n_node_samples[마디])
    성공 = int(round(t.value[마디][0][1] * 편수))
    return f"영화 {편수}편 중 성공 {성공}편"


def 답(마디):
    편수 = int(t.n_node_samples[마디])
    성공 = int(round(t.value[마디][0][1] * 편수))
    return "성공" if 성공 * 2 > 편수 else "기준 미달"


def 트리읽기(마디=0, 들여=""):
    """트리를 질문과 예·아니오로 읽어 내려간다."""
    if t.feature[마디] < 0:
        return [f"판정: {답(마디)}  ({마디설명(마디)})"]
    줄 = [f"{질문(마디)}  ({마디설명(마디)})"]
    for 답변, 자식 in (("예", t.children_left[마디]), ("아니오", t.children_right[마디])):
        아래 = 트리읽기(자식, 들여)
        줄.append(f"{들여}   {답변} → {아래[0]}")
        줄.extend(f"{들여}        {x}" for x in 아래[1:])
    return 줄

속성 중요도는 의사결정트리에만 있는 값입니다. 로지스틱 회귀가 내놓는 것은 가중치이고, 둘은 읽는 법이 다릅니다. 중요도는 크기만 말하고, 가중치는 그 값이 클수록 성공 확률이 올라가는지 내려가는지까지 말합니다.

이 단계부터 입력으로 사용할 속성을 화면 맨 위에서 고릅니다. 세 가지 말고도 7차시 실험실에서 사용한 배우 수·주연 수·상영시간·청소년관람불가·대형 배급사를 넣어 볼 수 있습니다. 실험실이 회귀에서 던진 "속성을 더 모으면 예측이 달라질까"를 분류에서 다시 확인하는 대목입니다. 고른 속성은 정확도만 바꾸지 않습니다. 트리가 던지는 질문, 속성 중요도, 가중치, 그리고 5절의 보고서까지 모두 다시 계산됩니다. 배급사를 넣으면 트리가 첫 질문부터 달라지는지 확인해 봅니다.

인물 표에 값이 없는 영화는 그 속성을 고른 순간 학습에서 빠집니다. 화면에 몇 편으로 학습했는지 표시되므로 함께 봅니다. 속성을 더했는데 점수가 내려가는 경우도, 뺐는데 오히려 오르는 경우도 나옵니다.

속성 중요도도 가중치도 이 모델이 무엇을 단서로 삼았는지 보여 줄 뿐 인과관계의 증거가 아닙니다.

오늘 사용한 입력은 스크린 수, 상영 횟수, 성수기 세 가지뿐입니다. 속성을 더 모으면 분류 결과가 달라질지 궁금할 수 있습니다. 7차시 실험실인 "속성을 더 모으면 예측이 달라질까"에서 그 물음을 이미 다루었습니다. 그 실험실에서는 영화진흥위원회 오픈 API로 감독, 배우 수, 상영시간, 관람등급, 배급사를 따로 모아 회귀 모델에 하나씩 넣어 보며 훈련용 점수와 테스트용 점수를 비교했습니다. 속성을 더한다고 점수가 늘 오르지는 않습니다. 대형 배급사를 넣어 계산해 보면 정확도가 오르는 날도 있고 그대로인 날도 있습니다. 늘 좋아지지는 않습니다. 넣기 전과 넣은 뒤를 같은 데이터에서 비교해야 알 수 있습니다. 궁금하면 7차시 실험실로 돌아가 확인해 보시기 바랍니다.

여기까지는 이미 결과가 나온 영화로 연습했습니다. 정답을 알고 맞히는 일이었습니다. 이제 아직 결과가 나오지 않은 영화에 같은 모델을 적용합니다. 막 개봉한 영화에도 스크린 수와 상영 횟수는 이미 나와 있습니다. 아직 나오지 않은 것은 최종 관객 수뿐입니다. 그러니 이 예측은 연습이 아니라 진짜 예측입니다. 맞았는지는 몇 주 뒤에 알게 됩니다. 이 표가 팀장에게 낼 보고서입니다.

def 조사(말):
    """받침이 있으면 '이', 없으면 '가'를 붙인다."""
    끝 = ord(말[-1])
    받침 = (끝 - 0xAC00) % 28 if 0xAC00 <= 끝 <= 0xD7A3 else 0
    return 말 + ("이" if 받침 else "가")


def 질문(마디):
    """분기 조건을 한글 질문으로 바꾼다. '예'가 왼쪽 가지다."""
    속성 = 열이름[t.feature[마디]]
    경계 = float(t.threshold[마디])
    if 속성 in 예아니오:                       # 0과 1뿐인 속성은 경계가 0.5다
        return 예아니오[속성]
    return f"{조사(속성)} {math.floor(경계):,}{단위.get(속성, '')} 이하인가?"


def 마디설명(마디):
    편수 = int(t.n_node_samples[마디])
    성공 = int(round(t.value[마디][0][1] * 편수))
    return f"영화 {편수}편 중 성공 {성공}편"


def 답(마디):
    편수 = int(t.n_node_samples[마디])
    성공 = int(round(t.value[마디][0][1] * 편수))
    return "성공" if 성공 * 2 > 편수 else "기준 미달"


def 트리읽기(마디=0, 들여=""):
    """트리를 질문과 예·아니오로 읽어 내려간다."""
    if t.feature[마디] < 0:
        return [f"판정: {답(마디)}  ({마디설명(마디)})"]
    줄 = [f"{질문(마디)}  ({마디설명(마디)})"]
    for 답변, 자식 in (("예", t.children_left[마디]), ("아니오", t.children_right[마디])):
        아래 = 트리읽기(자식, 들여)
        줄.append(f"{들여}   {답변} → {아래[0]}")
        줄.extend(f"{들여}        {x}" for x in 아래[1:])
    return 줄

분류정해진 범주 중 하나를 예측하는 문제(이진 분류: 두 범주)
레이블모델이 예측하려는 정답 값. 없으면 사람이 기준을 정해 붙인다.
로지스틱 회귀입력의 가중합에 시그모이드를 적용해 확률을 추정하고 분류하는 모델
시그모이드 함수실수 입력을 0과 1 사이 값으로 바꾸는 S자 형태의 함수
의사결정트리질문을 차례로 던져 가지를 나누며 분류하는 모델. 판단 순서가 그림으로 보인다.
불순도(섞임)한 마디에 두 범주가 얼마나 섞여 있는지 나타내는 값. 한 범주만 있으면 0이다. 교과서가 사용하는 말은 불순도이고, 이 교재 본문과 그림에서는 "섞임"이라고 적는다. 이 실습이 사용하는 계산 방법은 지니 불순도이다.
문턱값확률을 범주로 바꾸는 경계(이 실습: 0.5 이상이면 양성)
표준화입력마다 다른 값의 크기를 훈련용 데이터의 평균과 퍼짐을 기준으로 맞추는 처리. 11차시에서 다시 다룬다.
정확도테스트용 데이터에서 예측이 실제와 같았던 비율. 맞힌 편수 ÷ 전체 편수로 구한다.
속성 중요도(feature importance)각 속성의 분기가 불순도를 줄이는 데 기여한 정도를 나타내는 상대적인 값. 단서일 뿐 원인의 증거는 아니다.

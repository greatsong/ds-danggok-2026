회귀 · 직선을 긋다

"모든 모델은 틀렸다. 다만 일부는 쓸모가 있다."
조지 박스 (1987) · 모델이 설명할 수 있는 것과 한계를 함께 살펴봅니다.

오늘은 서울의 연도별 평균기온을 직선으로 나타냅니다. 연도와 기온의 관계를 직선으로 요약하는 방법을 단순 선형회귀라고 합니다. 직선의 기울기를 읽고, 학습에 사용하는 기간을 바꾸었을 때 결과가 어떻게 달라지는지 비교합니다.

수업 예시의 재현을 위해 데이터 버전을 고정했습니다. 기온은 2025년까지, 영화는 2025년 9월~2026년 8월 자료를 기준으로 합니다.

🎯 오늘 하는 것
  • 상관에서 회귀로 — 산점도와 상관계수를 읽고, 그 관계를 회귀 직선으로 나타낸다
  • 바이브 코딩 — 연도를 선택하면 예상 기온이 표시되는 앱을 만든다
  • 판단 — 학습 기간에 따라 기울기와 예측값이 얼마나 달라지는지 비교한다

0. 왜 배우나

기온이나 전기 사용량처럼 수치로 나타내는 값을 예측할 때 회귀를 활용할 수 있습니다. 이번 시간에는 연도와 연평균기온의 관계를 직선으로 요약합니다. 예측값을 읽을 때는 어떤 기간의 자료로 만든 직선인지 함께 확인합니다.

1. 개념 이해 — 상관에서 회귀로

📖 교과서의 정의 『데이터 과학』 70·119쪽

"상관계수는 상관관계의 강도와 방향을 나타내는 정량적인 단위로, 값의 범위는 −1부터 +1 까지이다." (70쪽)

"선형 회귀는 두 가지 이상의 속성 사이에 선 모양의 관계가 있다고 가정하고 데이터를 가장 잘 대표하는 선을 찾는 분석 방법이다." (119쪽)

→ 이번에 사용하는 상관계수는 두 변수의 선형적 관계를 수치로 나타냅니다. 단순 선형회귀는 그 관계를 직선으로 요약해 값을 예측합니다.

더 알아보기 — 회귀라는 이름의 유래

회귀라는 이름은 어디서 왔나

회귀(回歸)는 "돌아올 회, 돌아갈 귀"로 되돌아간다는 뜻입니다. 영어 regression도 라틴어 regredi에서 왔고, re는 뒤로, gradi는 걷다를 뜻하므로 의미가 같습니다. 직선을 긋는 계산에 왜 되돌아감이라는 이름이 붙었는지는 1886년 영국의 프랜시스 골턴이 발표한 연구에서 비롯되었습니다.

골턴은 부모 205쌍과 그 자녀 928명의 키를 조사했습니다. 키가 아주 큰 부모의 자녀는 평균적으로 부모보다 작았고, 키가 아주 작은 부모의 자녀는 평균적으로 부모보다 컸습니다. 자녀의 키가 전체 평균 쪽으로 되돌아가는 경향이 있었습니다. 골턴은 이 현상에 평범함으로의 회귀라는 이름을 붙였고, 부모 키와 자녀 키의 산점도에 직선을 그어 그 경향을 나타냈습니다.

오늘날 회귀는 되돌아가는 현상과 관계없이, 데이터의 관계를 선으로 요약해 값을 예측하는 방법 전체를 가리킵니다. 방법에 처음 붙은 이름이 그대로 남은 경우입니다. 용어의 이름이 방법의 내용을 모두 설명하지는 않으므로, 이름의 유래를 알아 두면 혼동이 줄어듭니다.

평균으로 되돌아가는 현상 자체는 지금도 평균으로의 회귀라는 이름으로 부릅니다. 시험을 유난히 잘 본 학생이 다음 시험에서는 평소 실력에 가까운 점수를 받는 일이 그 예입니다.

먼저 산점도에서 관계의 모양을 살펴보고, 상관계수와 회귀선을 함께 읽습니다. 상관계수만으로 관계의 모양을 모두 알 수는 없습니다. 우리 문제에서 예측에 사용하는 독립 변수는 연도이며, 예측하려는 종속 변수는 연평균기온입니다.

단계도구묻는 말
① 산점도점 그래프두 속성이 함께 움직이는 모양이 보이는가
② 상관계수−1 ~ +1의 수치그 관계가 얼마나 강한가, 방향은 어느 쪽인가
③ 회귀선가장 잘 맞는 직선이 관계로 새 값을 예측하면 얼마가 나오는가

직선을 읽는 두 숫자 — 기울기와 편향

직선은 예측값 = 기울기 × 독립 변수 + 절편으로 나타냅니다. 기울기는 독립 변수가 1 증가할 때 예측값이 얼마나 달라지는지를 뜻합니다. 이번 문제에서는 연도가 1 증가할 때 예상 연평균기온이 변하는 양이며, 100을 곱하면 100년 단위의 변화량이 됩니다. 절편은 독립 변수가 0일 때의 예측값입니다. 교과서에서는 기울기를 가중치, 절편을 편향이라고 부릅니다(119쪽). 절편이 첫 관측 연도의 기온을 뜻하는 것은 아닙니다.

어느 직선이 "가장 잘 맞는" 직선인가

같은 산점도에도 여러 직선을 그을 수 있습니다. 이번 실습에서는 각 점의 실젯값과 예측값의 차이를 제곱해 더한 값이 가장 작아지도록 기울기와 절편을 구합니다. 이 계산이 오늘 수행하는 학습입니다. 8차시에는 오차를 직접 계산하며 이 기준을 확인합니다.

2. 실습 — 기온 예측기 만들기 (바이브 코딩)

새 앱에서 연도와 연평균기온의 산점도를 확인합니다. 점들이 어떤 모양으로 분포하는지 살핀 뒤, 상관계수와 회귀 직선을 함께 읽습니다. 직선으로 충분히 설명되지 않는 부분이 있는지도 관찰합니다.

연평균을 구하기 전에 관측 기간을 확인해야 합니다. 서울 기온 자료에는 한국전쟁 시기의 결측이 있습니다. 일부 계절만 관측한 해의 평균은 한 해를 충분히 대표하지 못할 수 있습니다. 이번 수업에서는 2025년까지의 자료 가운데 관측일이 300일 이상인 114개 연도(1908~2025)를 사용합니다.

💡 전처리 판단의 기준 — 믿을 수 없는 값 제거와 불리한 값 제거

관측일 수가 적은 해를 제외하는 이유는 연간 기온을 충분히 대표하기 어려울 수 있기 때문입니다. 300일은 이 수업에서 정한 분석 기준이며, 연평균의 품질을 보장하는 절대 기준은 아닙니다. 어떤 계절의 자료가 빠졌는지도 확인해야 합니다. 제외 기준과 근거를 먼저 정하고, 앱과 보고서에 기록합니다. 점수를 높이기 위해 결과에 불리한 자료만 골라 제외해서는 안 됩니다.

    main.py와 requirements.txt, 두 파일로 저장합니다.

    main.py
    # main.py — 연평균기온에 직선을 맞추고 예측한다
import streamlit as st
import pandas as pd
import numpy as np
import plotly.express as px

DATA_URL = "https://raw.githubusercontent.com/greatsong/modudata/bb860932644270ad1199f10d3e7670e30231bce4/data/seoul.csv"

st.title("기온 예측기")


@st.cache_data
def load_yearly():
    df = pd.read_csv(DATA_URL)
    df["연도"] = pd.to_datetime(df["날짜"]).dt.year
    grouped = df.groupby("연도")["평균기온"].agg(["mean", "count"]).reset_index()
    # 2026년 수업은 2025년까지, 유효 관측일 300일 이상인 해를 사용한다.
    valid = (grouped["연도"] <= 2025) & (grouped["count"] >= 300)
    return grouped[valid].rename(columns={"mean": "연평균기온"})


yearly = load_yearly()
a, b = np.polyfit(yearly["연도"], yearly["연평균기온"], 1)   # 기울기, 절편

fig = px.scatter(yearly, x="연도", y="연평균기온", opacity=0.6)
fig.add_scatter(x=yearly["연도"], y=a * yearly["연도"] + b, mode="lines", name="회귀 직선")
st.plotly_chart(fig, width="stretch")
st.caption(f"직선을 만든 해: {len(yearly)}개 ({yearly['연도'].min()}~{yearly['연도'].max()}년)")

st.metric("연도와 연평균기온의 상관계수", f"{yearly['연도'].corr(yearly['연평균기온']):.3f}")
year = st.slider("연도를 고르세요", 1900, 2100, 2045)
st.metric(f"{year}년 예상 연평균기온", f"{a * year + b:.1f}℃")
if year < yearly["연도"].min() or year > yearly["연도"].max():
    st.info("학습 범위 밖의 외삽값입니다. 실제 미래 기온을 보장하지 않습니다.")

✍️ 화면에 보이는 숫자 적기

화면에 보이는 숫자는 언제나 어떤 범위의 데이터에서 나온 값입니다. 그 범위를 적어 두지 않으면 나중에 그 숫자가 어디까지 통하는지 알 수 없습니다. 공책에 그대로 옮겨 적어 두면 다음 차시에서 같은 질문을 다시 만날 때 도움이 됩니다.

  1. 직선을 만드는 데 사용한 해의 개수와 기간
  2. 내가 슬라이더로 고른 해와 그때 나온 예상 기온
  3. 그 해가 위의 기간 안쪽인지 바깥쪽인지

3. 결과 비교 — 학습 기간에 따라 달라지는 기울기

③을 실행하면 전체 기간과 최근 20년의 기울기가 표시됩니다. 아래 표는 같은 방법으로 최근 50년과 30년까지 비교한 결과입니다. 최근 기간은 모두 2025년을 끝으로 정했습니다. 기울기의 단위는 ℃/100년입니다.

학습 기간기울기 (℃/100년)읽기
전체 114개 해+2.60한 세기를 관통하는 완만한 상승
최근 50년+3.961976~2025년의 평균 상승 추세입니다.
최근 30년+3.821996~2025년의 평균 상승 추세입니다.
최근 20년+8.14전체 기간의 3배가 넘는 가파름

점의 위치는 추세를 나타낸 모식 표기입니다. 같은 점들 위에서 학습 기간이 다른 두 직선이, 같은 2045년에 13.9℃와 15.7℃로 갈라집니다.

⚠️ 두 직선은 서로 다른 기간을 요약합니다

두 직선은 같은 계산 방법으로 서로 다른 기간의 추세를 요약합니다. 전체 기간의 직선과 최근 20년의 직선은 2045년 기온을 각각 13.9℃와 15.7℃로 예측합니다. 계산이 올바르다는 사실만으로 미래 예측이 정확하다고 판단할 수는 없습니다. 학습 기간과 예측하려는 시점을 함께 확인합니다.

슬라이더를 2045년과 2100년으로 옮겨 봅니다. 두 연도 모두 학습에 사용한 1908~2025년의 범위 밖에 있습니다. 학습 범위 밖의 값을 추정하는 것을 외삽이라고 합니다. 계산된 수치가 실제 미래 기온을 보장하지는 않습니다.

4. 판단 — 상관은 인과가 아니다

"상관관계가 있는 데이터 속성 중에서 원인과 결과의 관계가 있는 데이터 속성 간 관계를 인과관계라고 한다." (72쪽)

→ 두 변수가 함께 변한다는 사실만으로 한쪽이 다른 쪽의 원인이라고 결론지을 수는 없습니다.

여름철에 아이스크림 판매량과 물놀이 사고 건수가 함께 늘었다고 하겠습니다. 기온과 야외 활동량 같은 공통 요인이 두 값에 영향을 주었을 수 있습니다. 상관만으로 아이스크림 판매가 사고의 원인이라고 결론지을 수는 없습니다. 연도와 기온의 관계도 마찬가지입니다. 이번 회귀선은 시간에 따른 기온 추세를 요약하며, 기온 변화의 원인을 확인하려면 별도의 자료와 검증이 필요합니다.

실제 사례로 보는 상관과 인과

상관계수의 절댓값이 크다는 사실은 두 값이 함께 움직인다는 관찰일 뿐입니다. 이 관찰은 한쪽이 다른 쪽의 원인이라는 뜻을 포함하지 않습니다. 실제로 발표된 분석에서도 이러한 혼동이 자주 일어납니다.

5. 개념 정리 — 모델·학습·예측의 한계

모델과 모델링 — 오늘 만드는 것의 이름

이 단원의 이름이 "Ⅲ. 데이터 모델링과 평가"이고, 교과서가 정리한 데이터 과학 문제 해결 6단계 가운데 네 번째가 모델링하기, 다섯 번째가 모델 평가하기, 여섯 번째가 모델 활용하기입니다(14쪽). 오늘 긋는 직선이 모델이며, 직선을 만드는 과정이 모델링입니다.

모델은 목적에 필요한 관계를 간단한 형태로 나타낸 것입니다. 이번 모델은 기울기와 절편으로 연도와 기온의 관계를 요약합니다. 모든 변동을 설명하지는 못하므로, 어떤 목적에 사용할 수 있는지 판단해야 합니다.

데이터 과학의 모델도 이와 같습니다. 서울 기온 데이터에는 하루하루의 날씨와 계절, 관측의 사정이 모두 들어 있지만, 오늘 만드는 모델은 그 가운데 "연도가 1 늘 때 기온이 얼마나 변하는가" 하나만 남깁니다. 100여 년의 기록이 기울기와 편향, 숫자 두 개로 요약됩니다.

모델링 단계하는 일오늘의 경우
① 형태 정하기관계를 어떤 모양으로 요약할지 고른다직선 하나로 요약한다
② 학습데이터에 가장 잘 맞는 숫자를 찾는다제곱오차 합이 가장 작은 기울기와 절편
③ 평가그 모델을 얼마나 믿을 수 있는지 잰다예측값과 실젯값의 차이를 수치로 잰다

모델의 매개변수를 데이터에서 구하는 과정을 학습이라고 합니다. 이번 실습에서는 제곱오차 합이 가장 작아지는 기울기와 절편을 구했습니다. 실제 자료에는 직선으로 설명하지 못하는 변동도 있으므로, 모델을 어디까지 활용할 수 있는지 판단해야 합니다.

기계학습은 무엇을 배우는가

교과서 11쪽은 데이터 과학을 통계, 데이터 분석, 기계학습 및 관련 방법을 통합하는 학문 분야로 정의합니다. 오늘 한 일은 이 정의 가운데 기계학습에 해당합니다. 기계학습(machine learning)은 기계가 데이터로부터 배운다는 뜻입니다. 기계가 배우는 대상은 모델을 이루는 숫자입니다.

사람이 계산 규칙을 직접 정하는 방식과 비교하면 차이가 분명해집니다. 사람이 기울기와 절편을 지정하면 그대로 계산합니다. 반면 이번 실습에서는 데이터에 맞는 두 값을 계산으로 구합니다.

이번 실습에서는 직선이라는 형태와 사용할 데이터를 사람이 정합니다. 계산은 제곱오차 합이 작아지는 기울기와 절편을 찾습니다. 기계학습, 학습, 모델을 구분하면 다음과 같습니다.

낱말무엇을 가리키나오늘의 경우
기계학습데이터에서 규칙을 찾는 방법 전체직선의 숫자를 계산이 찾게 한 방식
학습모델을 이루는 숫자를 찾는 계산제곱오차 합이 가장 작아지는 기울기와 절편을 구한 계산
모델학습이 끝나고 남는 결과물기울기와 편향으로 정해진 직선

기계가 학습한다고 해서 사람이 할 일이 없어지지는 않습니다. 어떤 데이터를 사용할지, 믿을 수 없는 값을 어떻게 걸러 낼지, 어떤 형태로 요약할지, 나온 결과를 믿을지는 사람이 판단합니다. 관측일이 300일이 안 되는 해를 걸러 낸 것도 사람의 판단이었습니다.

오늘은 산점도와 상관계수로 관계를 살피고, 단순 선형회귀로 연도와 기온의 관계를 요약했습니다. 학습 기간을 바꾸면 기울기와 예측값도 달라졌습니다. 결과를 설명할 때는 사용한 자료의 범위, 제외 기준, 예측의 한계를 함께 제시해야 합니다.

다음 시간에는 여러 변수를 사용하는 영화 예측 모델을 만듭니다. 8차시에는 오차와 결정계수를 직접 계산하며 모델을 평가하는 기준을 살펴봅니다.

6. 확인 문제

문제 1 우리 기온 예측기의 전체 기간 기울기는 +2.60℃/100년입니다. 이 숫자의 뜻으로 옳은 것을 고르세요.
직선은 매년 균일한 상승이라는 관측 사실이 아니라, 전체 기간을 관통하는 평균 추세의 요약입니다. 또한 직선은 학습 범위(1908~2025) 안의 추세를 요약할 뿐, 범위 밖의 미래를 보장하지 않습니다.
문제 2 전체 기간으로 구한 기울기는 +2.60, 최근 20년으로 구한 기울기는 +8.14였습니다.
(가) 한쪽이 계산을 틀린 것일까요?
두 직선은 서로 다른 기간의 자료를 사용했습니다. 따라서 기울기가 달라도 계산 오류라고 단정할 수 없습니다. 각각의 기간에서 얻은 추세를 설명하고, 미래 예측의 정확성은 별도로 평가해야 합니다.
(나) 그렇다면 "서울은 더워지고 있는가"라는 질문에는 어떻게 답해야 할까요? 자기 말로 답해 본 뒤 펼쳐 보세요.
예시 답 펼쳐 보기

"더워지고 있다"는 방향은 두 직선이 같습니다. 다만 속도를 말할 때는 반드시 어느 기간에서 잰 기울기인지 밝혀야 합니다. 전체 기간 직선은 한 세기의 평균 추세를, 최근 20년 직선은 최근의 가파름을 요약합니다.

문제 3 "아이스크림 판매량과 물놀이 사고 건수의 상관이 강하므로, 사고를 줄이려면 아이스크림 판매를 규제해야 한다." 이 주장에 대한 판단으로 옳은 것을 고르세요.
상관만으로 원인과 결과를 확정할 수는 없습니다. 기온이나 야외 활동량 같은 공통 요인이 있을 수 있습니다. 정책의 효과를 판단하려면 추가 자료와 검증이 필요합니다.
문제 4 골턴이 부모와 자녀의 키를 조사한 뒤 이 방법에 회귀라는 이름을 붙인 까닭으로 옳은 것을 고르세요.
골턴은 부모 205쌍과 자녀 928명의 키를 조사하여, 자녀의 키가 전체 평균 쪽으로 되돌아가는 경향을 발견하고 평범함으로의 회귀라는 이름을 붙였습니다. 오늘날 회귀는 되돌아가는 현상과 관계없이 데이터의 관계를 선으로 요약해 값을 예측하는 방법 전체를 가리키므로, 이름은 유래만 남은 채 사용됩니다.
문제 5 기온 예측기를 만드는 과정에서 일어난 일 가운데 학습에 해당하는 것을 고르세요.
학습은 모델을 이루는 숫자, 즉 기울기와 편향을 찾는 계산입니다. 관측일이 300일 미만인 해를 걸러 낸 것은 어떤 데이터를 사용할지 사람이 판단한 일이며, 나온 기울기를 100년에 2.60도라고 바꾸어 읽은 것은 결과를 사람이 해석한 일입니다.

🎒 오늘의 체크

  • 산점도 → 상관계수 → 회귀선의 순서와 각 단계가 답하는 질문을 말할 수 있다.
  • 연도를 고르면 예상 기온이 표시되는 예측기 앱을 만들어 실행했다.
  • 전체 기간과 최근 20년의 기울기가 +2.60과 +8.14로 갈라지는 이유를 설명할 수 있다.
  • 상관관계와 인과관계의 차이를 예를 들어 설명할 수 있다.

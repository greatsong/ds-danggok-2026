1 · 데이터베이스

데이터셋 · 데이터베이스 · 테이블

  • 데이터셋: 한 주제에 관련된 데이터의 집합 (예: CSV 파일)
  • 데이터베이스: 여러 사람이 공유할 수 있도록 통합 관리하는 데이터의 집합
  • 데이터베이스의 기능: 동시 사용(여러 사람이 한꺼번에 고쳐도 변경을 잃지 않음) · 조건 검색 · 권한 관리
  • 테이블: 데이터베이스에서 데이터를 행과 열로 저장하는 단위
  • 행(가로 한 줄) = 데이터 하나 · 열(세로 한 줄) = 속성
  • 기본 키: 각 행을 유일하게 식별하는 열 · 값이 행마다 달라야 하고 비워 둘 수 없음

SELECT 정리 · 파이썬과 비교

파이썬 대신 SQL을 사용하는 이유

파이썬: 찾는 절차를 직접 작성
result = []
for row in rows:
    if row["지원동아리"] == "방송부":
        result.append(row)
result.sort(key=lambda r: r["면접"], reverse=True)
names = [r["이름"] for r in result]
SQL: 원하는 결과만 작성
SELECT 이름 FROM 지원WHERE 지원동아리 = '방송부'ORDER BY 면접 DESC;
두 코드의 결과: 한별, 박솔, 서도윤, 석하람, 황지후, 허윤슬, 신유찬, 홍예린
  • 원하는 결과만 적기: 찾는 방법은 데이터베이스가 결정
  • 필요한 행만 받아 오기: 수억 개 가운데 조건에 맞는 행만 전송, 검색하는 열에 색인(인덱스)을 만들어 두면 빠르게 검색
  • 동시에 읽고 쓰기: 여러 사용자의 요청이 동시에 들어와도 서로의 변경을 덮어쓰지 않도록 조정, 데이터 손실 없이 처리
  • 공통 언어: 자바·자바스크립트·파이썬 어디서나 SQL로 요청
역할 분담 SQL = 저장하고 꺼내기 · 파이썬 = 분석·시각화·모델

3 · SQL 데이터 변경 · UPDATE

UPDATE: 값 바꾸기

UPDATE 지원SET 자소서 = 40, 면접 = 44WHERE 학번 = 20133;
  • SET 뒤: 바꿀 열 = 새 값 · 여러 열은 쉼표로 구분
  • WHERE 뒤: 바꿀 행의 조건 (기본 키 학번으로 한 행만)
  • 순서: UPDATE → SET → WHERE (SET이 WHERE보다 앞)
  • 앞 장에서 제출한 20133 서다온의 빈 점수 채우기
시스템에서는 미술부 담당이 점수 입력 후 [저장] → 합격 현황이 바로 바뀜

시스템에서는 학생 화면의 [지원 취소]
WHERE를 빠뜨린 문장
UPDATE 지원 SET 면접 = 42;
DELETE FROM 지원;
  • WHERE를 빠뜨리면 모든 행이 바뀌거나 지워짐 (위: 30행 모두 면접 42점, 아래: 0행)
  • WHERE가 없어도 오류 없이 실행됨 (경고 없음)
  • 한 행만 바꾸거나 지울 때: 기본 키로 지정 WHERE 학번 = 20116
  • 이름으로 지정하면 동명이인까지 바뀌거나 지워질 수 있음
정리

SQL 문법 한눈에 보기

SELECT 열 FROM 테이블열 고르기 (* = 모든 열)
WHERE 조건행 고르기 · 문자·날짜는 '작은따옴표'
ORDER BY 열 ASC / DESC정렬 · 생략하면 ASC
LIMIT n앞에서 n행만
GROUP BY 열 · COUNT(*)묶음마다 행 수 · AVG(열)은 평균
COUNT(*) AS 인원결과 열 이름 바꾸기
WHERE 열 LIKE '윤%'글자 패턴으로 행 고르기 · % = 0개 이상의 아무 글자
INSERT INTO 테이블 (열, …) VALUES (…)행 추가 · 열을 생략하면 모든 열을 열 순서대로
UPDATE 테이블 SET 열 = 값, … WHERE 조건값 바꾸기 · SET이 WHERE보다 앞
DELETE FROM 테이블 WHERE 조건행 삭제
SELECT → FROM → WHERE → GROUP BY → ORDER BY → LIMIT절을 적는 순서
UPDATE·DELETE에서 WHERE 생략 → 모든 행이 대상 (오류 없이 실행)

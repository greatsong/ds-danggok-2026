이미지도 784개의 숫자다 · 팀 짜기

"세상의 데이터 대부분은 표가 아니다. 그러나 분석은 언제나 숫자 표에서 시작된다."
오늘의 관통 문장 — 비정형과 정형이 만나는 자리

지금까지 다룬 기온·혼잡도·지하철은 모두 표 안의 숫자였습니다. 오늘은 손글씨 이미지를 열어 봅니다. 이미지마저 숫자의 묶음이라는 것을 확인하고, 이어서 팀을 짜고 우리 프로젝트 주제를 정합니다.

🎯 오늘 하는 것
  • 이미지 데모 — 손글씨 숫자 한 장을 열어 784개의 숫자로 보기 (선생님 시연)
  • 팀 주제 카드 — 2~3인 팀을 짜고 회귀·분류·군집 중 하나를 골라 주제를 적기

0. 왜 배우나

여러분의 휴대전화 사진첩에는 표가 한 장도 없습니다. 사진, 영상, 메시지, 음성 녹음. 세상에서 만들어지는 데이터의 대부분은 이런 모양입니다. 그런데 우리는 14차시 동안 행과 열이 있는 표만 다뤘습니다. 표 밖의 데이터는 분석할 수 없는 걸까요? 오늘 앞부분에서 그 답을 눈으로 확인합니다. 손글씨 그림 한 장을 열어 보면, 그림이 사실은 처음부터 숫자 표였다는 것이 드러납니다.

오늘의 두 번째 일은 더 큽니다. 공통 수업이 오늘로 마무리되고, 다음 시간부터는 5주 동안 15차시의 팀 프로젝트가 이어집니다. 어떤 팀과 어떤 질문으로 그 5주를 보낼지 오늘 정합니다. 프로젝트의 절반은 질문에서 정해지므로, 오늘의 30분이 앞으로의 15차시를 좌우합니다.

1. 개념 이해 — 이미지도 숫자다

📖 교과서의 정의 『데이터 과학』 20쪽

"비정형 데이터(unstructured data)는 구조를 명확하게 정의하기 어려운 데이터를 말한다."

"비정형 데이터는 정형 데이터처럼 명확한 속성이 정의되어 있지 않지만, 데이터를 가공하여 속성을 추출할 수 있다."

→ 이미지도 784개의 숫자로 가공하면 표가 된다 — 오늘의 손글씨 데모가 바로 "가공하여 속성을 추출"하는 장면이다.

흑백 사진 한 장은 784칸의 표다

흑백 사진을 계속 확대하면 어느 순간 작은 정사각형 칸이 드러납니다. 이 칸이 픽셀입니다. 칸 하나에는 모양도 선도 없고, 오직 밝기 하나만 있습니다. 완전한 검정을 0, 완전한 흰색을 1로 정하면 칸 하나는 숫자 하나가 됩니다. 오늘 볼 손글씨 그림은 가로 28칸, 세로 28칸이므로, 그림 한 장이 곧 28 × 28 = 784개의 밝기 숫자입니다.

이 784개를 한 줄로 늘어놓으면 무엇이 될까요? 우리가 지금까지 다룬 표의 한 행이 됩니다. 그림이 7,000장이면 7,000행 × 784열의 표입니다. 기온 데이터가 "연도마다 한 행"이었다면, 이 데이터는 "그림마다 한 행"일 뿐입니다. 열의 이름이 '연도'와 '기온' 대신 '1번 칸의 밝기'부터 '784번 칸의 밝기'까지로 바뀌었을 뿐, 표라는 사실은 같습니다.

비정형이 정형으로 바뀌는 순간

2차시에서 데이터의 두 갈래를 구분했습니다. 행과 열이 있는 표가 정형 데이터, 이미지·글·소리처럼 표가 아닌 것이 비정형 데이터였습니다. 그때 "15차시에서 잠깐 만나요"라고 했던 약속이 오늘입니다. 핵심은 한 문장입니다. 비정형 데이터는 숫자 표로 바뀌어야 분석이 시작됩니다. 컴퓨터가 하는 모든 계산(평균 내기, 거리 재기, 직선 긋기)이 숫자를 재료로 하기 때문입니다.

비정형 데이터숫자 표로 바뀌는 방식
이미지칸(픽셀)마다 밝기·색을 숫자 하나로 — 오늘의 784개
글낱말마다 번호를 붙이거나, 낱말이 나온 횟수를 세어 숫자로
소리공기의 떨림(파형)의 크기를 아주 짧은 간격으로 재어 숫자로

사진을 알아보고 글을 읽는 요즘의 인공지능도 출발은 같습니다. 이미지든 글이든 먼저 숫자로 바꾸고, 그 숫자로 계산합니다. 오늘 확인하는 "이미지도 숫자다"는 손글씨 데모 하나의 이야기가 아니라, 인공지능이 세상을 읽는 공통 원리입니다.

숫자만 읽고 93%

오늘 시연에서 컴퓨터는 그림을 눈으로 보지 않습니다. 784개의 숫자만 읽고 어떤 숫자의 그림인지 맞힙니다. 그런데 약 93%를 맞힙니다. 이 성적을 읽을 때도 앞서 기른 습관이 그대로 쓰입니다. 이 데이터에는 0부터 9까지 열 종류가 고르게 들어 있으므로, 아무렇게나 찍으면 약 10%를 맞힙니다. 기준선 10% 위의 93%이므로 뜻이 있는 성적입니다. 정확도를 기준선과 견주던 분류의 판단이, 표를 떠나 이미지에서도 똑같이 통한다는 것을 오늘 확인합니다.

2. 본 활동 ① — 이미지 데모 (선생님 시연)

  • 이미지 같은 비정형 데이터도 결국 숫자 표(정형)로 바꿔 다룬다 — 2차시에 본 두 갈래가 여기서 만남

손글씨 숫자 데이터 mnist_small.npz에는 숫자 그림 7,000장이 들어 있습니다. 그림 한 장은 가로 28칸 × 세로 28칸, 즉 784칸입니다. 칸마다 0(검정)부터 1(흰색)까지의 밝기 숫자가 하나씩 들어 있습니다. 그림을 열어 보면 결국 784개의 숫자입니다.

🔎 데이터 출처 — MNIST
  • 손글씨 숫자 mnist_small.npz는 MNIST(Yann LeCun 등이 공개한 손글씨 숫자 데이터)에서 7,000장을 추린 것이다. 기계학습 입문에서 널리 쓰는 공개 데이터다.
  • 믿을 수 있는 이유 — 30년 가까이 전 세계 연구·교육에서 성능을 겨루는 표준 기준으로 검증돼 온 데이터다.
💡 왜 선생님 시연인가

  • 아래 ①②③은 눈으로 따라오면 충분하다. 배포는 하지 않는다.
① 샘플 프롬프트
손글씨 숫자 이미지 데이터(mnist_small.npz)를 스트림릿으로 불러오는 앱을 만들어 줘. 이미지를 하나 골라서 그림으로 크게 보여 주고, 그 그림이 사실은 784개의 밝기 숫자로 이루어져 있다는 걸 나란히 보여 줘.

- 데이터 주소: https://raw.githubusercontent.com/greatsong/modudata/main/data/mnist_small.npz
- 슬라이더로 몇 번째 이미지를 볼지 고를 수 있게
- 그림 한 장은 가로 28칸, 세로 28칸으로 되어 있음
② AI가 준 코드 예시
import io
import urllib.request
import numpy as np
import streamlit as st

st.title("이미지도 784개의 숫자다")

URL = "https://raw.githubusercontent.com/greatsong/modudata/main/data/mnist_small.npz"

@st.cache_data
def load():
    with urllib.request.urlopen(URL) as r:
        d = np.load(io.BytesIO(r.read()))
        return d["X"], d["y"]   # X: 밝기 숫자(7000, 784), y: 정답 숫자

X, y = load()

# 몇 번째 이미지를 볼지 고르기
i = st.slider("몇 번째 이미지를 볼까요", 0, len(X) - 1, 0)

one = X[i]                  # 숫자 784개가 한 줄로
img = one.reshape(28, 28)   # 28 x 28 그림으로 되돌리기

col1, col2 = st.columns(2)
with col1:
    st.write("이 그림은")
    st.image(img, width=180, clamp=True)   # 밝기 숫자를 그림으로
    st.write("정답:", int(y[i]))
with col2:
    st.write("사실은 이런 숫자 784개")
    st.write("가로 28 x 세로 28 =", 28 * 28, "칸")
    st.dataframe(img.round(2))             # 칸마다 밝기 숫자 하나씩
⚠️ 결과가 똑같지 않아도 괜찮아요

②는 "이런 모습이면 성공"이라는 안심용 예시입니다. AI가 준 코드가 조금 달라도, 그림 한 장이 784개의 숫자로 펼쳐지면 성공입니다.

  • 컴퓨터는 이 숫자들만 보고 약 93%를 맞힌다. 우리가 앞서 다룬 표와 똑같이, 이미지도 숫자를 읽는 문제였다.

  • 관심 진로 분야에도 데이터가 있다 · 팀 주제를 고를 때 내 진로와 잇는 것도 좋은 선택

3. 본 활동 ② — 팀 짜고 주제 정하기

공통 15차시가 끝나면 팀 프로젝트가 시작됩니다. 2~3인 팀이 질문 하나를 정해 데이터를 구하고, AI에게 분석을 주문하고, 결과를 의심하고, 한계까지 발표하는 5주의 여정입니다. 오늘은 그 출발점으로 팀을 짜고 주제의 뼈대를 잡습니다. 앞서 배운 세 트랙 중 우리 팀 질문에 맞는 틀을 하나 고릅니다.

  1. 팀 짜기
    2~3인으로 팀을 만든다. 서로 관심 주제가 통하는 사람과 묶이면 좋다.
  2. 틀 고르기
    우리 질문이 숫자를 맞히는 문제면 회귀, 단계·종류를 맞히는 문제면 분류, 정답 없이 비슷한 것끼리 묶는 문제면 군집이다.
  3. 데이터 후보 적기
    답을 데이터로 확인할 수 있는 질문인지 따져 본다. 쓸 만한 데이터 후보를 3개 적는다.
  4. 주제 카드 제출
    아래 항목을 채워 클래스룸에 제출한다.
💡 우리 팀 주제 카드 (이 항목을 채워요)
  • 팀 이름 · 팀원 (2~3인)
  • 우리 질문 한 문장 — 데이터로 답할 수 있고 범위가 명확하게
  • 고른 틀 — 회귀 / 분류 / 군집 중 하나 + 고른 이유
  • 데이터 후보 3개 — 어디서 구할지도 함께
  • 예상되는 구멍 — 이 데이터에 있을 법한 이상치·결측·편향 하나
⚠️ 답할 수 없는 질문은 피하기

"우리 동네는 왜 살기 좋은가" 같은 질문은 데이터로 답하기 어렵습니다. "우리 동네 지하철역은 아침에 붐비는가"처럼 측정할 수 있고 범위가 분명한 질문으로 바꿉니다.

좋은 팀 주제의 조건 다섯

주제 카드를 채우기 전에, 우리 팀 질문을 아래 다섯 조건에 대 봅니다. 다음 시간의 데이터 승인 심사에서도 같은 기준으로 살펴보므로, 오늘 미리 대 본 팀이 유리합니다.

조건스스로 묻는 말어긋난 예 → 고친 예
측정할 수 있다답을 숫자나 범주로 잴 수 있는가"살기 좋은가"(취향) → "아침에 붐비는가"(승하차 인원)
데이터가 실제로 있다공공·공식 출처에서 구할 수 있는가 (출처 1~2개)"친구들의 속마음" → 공공데이터포털에 있는 자료로
범위가 분명하다어디의, 언제의, 무엇을 보는지 정했는가"전국, 1년 내내" → "우리 구, 등교 시간대"
개인 정보가 없다특정 개인을 알아볼 수 있는 자료는 아닌가개인 성적·개인 위치 기록 → 지역·시간대 단위 집계 자료로
구멍을 예상할 수 있다이상치·결측·편향이 어디 있을 법한가"완벽한 데이터일 것" → 예상되는 구멍을 카드에 미리 적기

다섯 가운데 가장 자주 걸리는 것이 첫째와 셋째입니다. "왜 ~일까"처럼 이유나 취향을 묻는 질문은 잴 수가 없고, 범위가 넓은 질문은 5주 안에 끝나지 않습니다. 질문을 "~는 정말 ~인가" 형태로 다듬으면 잴 것과 범위가 저절로 또렷해집니다. 그리고 데이터의 결함은 감점 사유가 아닙니다. 구멍이 있는 데이터를 골라 그 구멍을 스스로 찾고 다루는 과정이 오히려 평가의 중심입니다.

4. 개념 정리 — 오늘의 세 장면

오늘 본 것을 세 장면으로 정리합니다.

장면정리
그림 한 장 = 784개의 숫자비정형 데이터는 숫자 표(정형)로 바뀌어야 분석이 시작된다. 기온·혼잡도·지하철·이미지가 모두 같은 표의 세계였다
93% vs 기준선 10%데이터가 바뀌어도 판단 습관은 같다 — 성적은 언제나 기준선과 견주어 읽는다
팀 주제 카드좋은 주제 = 측정 가능 + 데이터 존재 + 범위 분명. 프로젝트의 절반은 질문에서 정해진다

5. 확인 문제

먼저 스스로 답을 적고 나서 펼쳐 보세요.

문제 1 — 흑백 손글씨 그림 한 장이 가로 28칸, 세로 28칸이다. 이 그림은 숫자 몇 개에 해당하는지 쓰고, 그 숫자 하나하나가 무엇을 나타내는지 한 문장으로 서술하시오.

예시 답안 — 28 × 28 = 784개의 숫자에 해당한다. 숫자 하나는 그림의 한 칸(픽셀)의 밝기로, 0이면 완전한 검정, 1이면 완전한 흰색을 나타낸다.

문제 2 — "이미지 같은 비정형 데이터는 표가 아니라서 분석할 수 없다"는 주장이 왜 정확하지 않은지, 오늘 본 손글씨 그림을 예로 들어 서술하시오.

예시 답안 — 비정형 데이터는 그대로는 계산할 수 없지만, 숫자 표(정형)로 바꾸면 분석할 수 있다. 손글씨 그림도 칸마다 밝기를 재어 784개의 숫자, 곧 표의 한 행으로 바뀌었고, 컴퓨터는 그 숫자만 읽고 약 93%를 맞혔다.

문제 3 (자가 점검) — 어느 팀이 "우리 학교 학생들은 왜 아침을 안 먹을까"를 주제 카드에 적었다. 좋은 팀 주제의 조건에 비추어 문제를 하나 들고, 측정할 수 있는 질문으로 고쳐 쓰시오.

예시 답안 — "왜"는 마음속 이유를 묻는 질문이라 데이터로 재기 어렵다(측정 가능 조건 위반). "아침을 거르는 학생 비율은 정말 학년이 올라갈수록 높아지는가"처럼 셀 수 있는 값으로 바꾸면 답할 수 있는 질문이 된다. 우리 팀 카드의 질문도 같은 방식으로 점검한다.

🎒 오늘의 체크

  • 이미지 한 장이 28 × 28 = 784개의 숫자라는 걸 설명할 수 있다.
  • 기온·혼잡도·지하철·이미지가 모두 표 안의 숫자였음을 안다.
  • 팀(2~3인)을 짰다.
  • 회귀·분류·군집 중 우리 틀을 골랐고 이유를 말할 수 있다.
  • 데이터 후보 3개를 적어 주제 카드를 제출했다.

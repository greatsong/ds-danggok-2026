다중 선형 회귀의 정의

다중 선형 회귀(multiple linear regression)는 영향을 미치는 요인이 여러 개인 경우에 종속 변수를 설명하기 위해 여러 개의 독립 변수를 이용하는 회귀 분석이다

독립 변수 하나 → 단순 회귀 · 여럿 → 다중 회귀

7-3 · 교과서 119쪽

속성 · 독립 변수 · 종속 변수

선형 회귀는 두 가지 이상의 속성 사이에 선 모양의 관계가 있다고 가정하고 데이터를 가장 잘 대표하는 선을 찾는 분석 방법이다
  • 표의 한 열 = 속성 · 스크린 수 · 장르 · 개봉일
  • 영어로는 feature · 코드와 설명서에 그대로 등장
  • 교과서와 교재는 속성, 코드 안에서는 feature
  • 독립 변수 — 예측에 쓰는 속성
  • 종속 변수 — 예측하려는 값 · 오늘은 총 관객 수 하나
7-4 · 원리

직선에서 평면으로

  • 단순 회귀 — 독립 변수 하나로 예측
  • 다중 회귀 — 변수마다 가중치를 곱해 더한 뒤 편향 추가
  • 독립 변수 둘 — 평면으로 표현
  • 가중치 — 다른 변수의 값이 같을 때 1 증가당 예측값의 변화량

단위가 다른 가중치 · 크기만으로 중요도 비교 불가

학습 데이터와 평가 데이터의 분리

샘플 프롬프트 작성 (1)

"영화 흥행 예측기" 스트림릿 앱을 만들어 줘. 파일 하나로.
박스오피스 데이터(kobis_daily.csv)와 영화 정보 표(kobis_movies.csv)를 합쳐서
영화의 총 관객 수를 예측하는 다중 회귀 모델을 만들어 줘.
어떤 변수를 쓸지는 내가 체크박스로 고를 수 있게 하고,
학습에 쓰지 않은 영화로 평가한 점수와
예측이 실제와 얼마나 빗나가는지도 함께 보여 줘.
영화별 표를 영화코드 순으로 정렬한 다음, 열 편마다 앞의 세 편을 시험용으로 떼어 놓고 나머지로 학습해 줘.
영화별 표에 있는 영화를 모두 사용해 줘.
학습에 쓴 영화 편수와 점수를 평가한 영화 편수, 기준 기간을 화면에 적어 줘.
시험용 영화의 실제 총 관객 수를 가로축, 예측한 총 관객 수를 세로축에 둔 산점도를 그리고,
예측이 실제와 같을 때를 나타내는 기준선도 함께 표시해 줘.
관객 수는 편차가 크니 두 축을 로그로 그려 줘.
예측이 1,000명보다 작게 나온 영화는 그래프 바닥에 붙여 표시하고 몇 편인지 적어 줘.
그래프는 plotly로 그려 줘.

교재 ①과 같은 문장 · 앞부분에 담긴 조건 — 두 표의 결합 · 체크박스 변수 선택 · 분할 규칙 · 화면 표기 항목 · 산점도와 로그 축

결정계수 R²의 기준

R² = 1 − (내 모델의 오차 제곱합 ÷ 평균만 답했을 때의 오차 제곱합)

  • 1 — 오차 0
  • 0 — 평균만 답하는 모델과 동일
  • 음수 — 평균만 답하는 것보다 큰 오차
결정 계수가 0에 가깝다면 회귀 모델이 데이터의 평균을 맞추는 정도로 예측했고, 회귀 모델의 유의미성이 떨어진다는 뜻이다
7-10 · 그림

비교 대상에 따라 달라지는 R²

완벽한 예측 · 잘 맞는 직선 · 평균만 예측 · 엉뚱한 직선 네 경우의 비교

7-11 · 교과서 131쪽

평균절대오차와 평균제곱오차

실젯값과 예측값의 차이를 모두 제곱하여 평균한 값으로, 이 값이 작을수록 예측 성능이 좋다
  • MAE — 차이의 절댓값 평균 · 단위는 명 · 앱 화면의 평균 오차
  • MSE — 차이의 제곱 평균 · 크게 빗나간 한 편에 민감
  • R² — 비율이므로 단위 없음

R²는 평균만 답하는 모델과의 상대 성적, MAE·MSE는 빗나간 크기

세 지표의 손계산은 8차시

데이터 누수

예측 시점에 알 수 없는 정보가 변수로 새어 들어와 점수를 부풀리는 것

  • 첫 주 관객 수를 개봉 전 예측에 사용하는 경우가 그 예
  • 점수 상승 = 성능 향상 아님
  • 높은 점수 자체가 누수의 증거는 아님 · 판정 기준은 정보의 시점
  • 이 데이터의 기본 변수에도 사후 집계값 포함

점수의 크기와 정보의 시점

  • 변수 조합에 따라 달라지는 점수

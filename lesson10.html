0. 왜 배우나

중요한 메일을 스팸으로 분류하는 오류와 스팸을 받은편지함에 남기는 오류는 미치는 영향이 다릅니다. 정확도는 두 오류를 구분하지 않습니다. 어떤 오류를 줄여야 하는지 판단하려면 혼동행렬과 여러 지표를 함께 살펴야 합니다.

1. 개념 이해 — 네 칸과 세 지표

📖 교과서의 정의 『데이터 과학』 139·140쪽

"오분류표란 각각의 실제 클래스와 예측 결과를 행렬로 나타낸 것이다." (139쪽)

"정확도는 전체 데이터 중 실제와 같게 예측한 데이터의 비율을 나타내며, 레이블별 분포가 균일하지 않은 경우 정확도로 모델을 평가하는 것은 부적절하다." (139쪽)

"문제 상황에 따라 적합한 성능 지표가 다르므로, 상황에 맞는 지표를 선택해야 한다." (140쪽)

→ 혼동행렬은 실제 범주와 예측 범주를 교차해 나타낸 표입니다. 정확도·정밀도·재현율은 이 표에서 계산합니다. 오늘은 양성을 “기록된 관객 수가 100만 명 이상인 성공”, 음성을 “기준 미달”로 정합니다. 실제 흑자·적자 구분은 아닙니다.

영어 약자보다 우리말이 먼저입니다. "성공"을 양성(Positive)이라 할 때, 예측은 네 가지 중 하나로 결정됩니다. 곧 만날 약자 TP·FP·FN·TN은 True/False(예측이 맞음/틀림)와 Positive/Negative(성공/기준 미달로 예측)의 조합입니다.

칸우리말로영화라면
TP양성 예측 · 실제 양성성공이라 예측했고 실제로 성공
FP양성 예측 · 실제 음성성공이라 예측했지만 실제는 기준 미달
FN음성 예측 · 실제 양성기준 미달로 예측했지만 실제는 성공 (놓친 성공작)
TN음성 예측 · 실제 음성기준 미달로 예측했고 실제로 기준 미달

정확도의 분자는 맞힌 전체 건수(TP+TN)이고, 정밀도와 재현율의 분자는 맞힌 양성 건수(TP)입니다. 정밀도는 예측 양성, 재현율은 실제 양성을 분모로 삼습니다. 분모가 0이면 해당 비율은 계산할 수 없습니다. 코드에서 0으로 표시하는 경우에는 계산을 위한 처리임을 구분해야 합니다.

지표계산 (140쪽 공식)묻는 말
정확도(TP+TN) ÷ 전체전체 중 얼마나 맞혔는가
정밀도TP ÷ (TP+FP)"성공"이라 말한 것 중 진짜 성공은 얼마인가
재현율TP ÷ (TP+FN)실제 성공작 중 얼마나 잡아냈는가

2. 손 활동지 — 교과서 해 보기부터

✍️ 활동지 2 문제 1 (교과서 139~140쪽 해 보기 ④)

교과서 139쪽의 토마토 농장 사례를 펼칩니다. 과일 이미지를 토마토인지 아닌지 분류한 결과가 본문에 있습니다. 활동지에서 오분류표의 네 칸을 채우고 정밀도·재현율·정확도를 차례로 구합니다. 마지막 물음 — "정밀도가 낮으면 이 농장에 무슨 일이 벌어지는가" — 까지 문장으로 써 보세요. 같은 계산을 폼 Ⅲ-02d에 기록합니다.

활동지 문제 2~5에서는 영화와 스팸 필터를 다룹니다. 혼동행렬을 채우고 기준 모델과 비교한 뒤, 놓친 성공작과 잘못 추천한 영화를 각각 어떤 비용으로 볼지 토의합니다. 정밀도·재현율 중 하나를 분야 이름만으로 정하기보다, 문제의 목적과 오류의 영향을 근거로 선택합니다.

💡 지표 선택은 계산이 아니라 판단이다

확률 문턱값을 낮추면 양성으로 예측하는 대상이 늘어납니다. 같은 예측 확률에서 재현율은 유지되거나 높아지지만, 정밀도가 항상 낮아지는 것은 아닙니다. 도전 문제에서는 여러 문턱값의 혼동행렬을 직접 비교하고, 어느 오류를 줄일지 정해 봅니다.

3. 비교 활동 — 다수 범주만 예측한다면

전체 영화 216편 중 성공 라벨이 붙은 영화는 23편입니다. 전부 기준 미달로 예측하면 193편을 맞혀 전체 자료의 정확도는 약 89%입니다. 모델과 공정하게 비교하려면 같은 시험용 자료를 사용해야 합니다. 아래 표는 9차시 코드의 시험용 66편으로 계산했으며, 실제 성공은 6편, 기준 미달은 60편입니다.

⚠️ 정확도만 보면 놓치는 세 가지
  • 기준 모델과 비교합니다. 90.9%는 성공작을 한 편도 찾지 않고 얻은 정확도입니다. 높은 정확도만으로 목적을 달성했다고 판단할 수 없습니다.
  • 오류의 종류를 확인합니다. 로지스틱 회귀는 92.4%를 맞혔지만 성공작 6편 중 5편을 놓쳤습니다. 성공작 발굴이 목적이라면 이 한계를 함께 보고해야 합니다.
  • 입력의 수집 시점을 확인합니다. 점수가 올랐다는 사실만으로 개선이나 누수를 판정할 수 없습니다. 실제 예측 시점에 그 값을 사용할 수 있는지 확인합니다.

9차시와 같은 시험용 66편으로 평가합니다. 파일 하나(app.py)로 저장합니다. 아래 표의 각 모델을 이 코드에서 다시 계산할 수 있습니다.

app.py
# 혼동행렬과 기준선 — 정확도만 보면 놓치는 것
import streamlit as st
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.tree import DecisionTreeClassifier
from sklearn.metrics import confusion_matrix, accuracy_score, recall_score

MOVIES = "https://raw.githubusercontent.com/greatsong/modudata/bb860932644270ad1199f10d3e7670e30231bce4/data/kobis_movies.csv"


@st.cache_data
def load_data():
    df = pd.read_csv(MOVIES, dtype={"movieCd": str}).sort_values("movieCd").reset_index(drop=True)
    df["장르"] = df["genre"].str.split("|").str[0]
    df["국가"] = df["nation"].str.split("|").str[0]
    df["성공"] = (df["total_audi"] >= 1_000_000).astype(int)
    return df


df = load_data()
is_test = df.index % 10 < 3
features = df[["first_scrn", "first_show", "peak", "장르", "국가"]]
Xtr = pd.get_dummies(features[~is_test])
Xte = pd.get_dummies(features[is_test]).reindex(columns=Xtr.columns, fill_value=0)
ytr, yte = df["성공"][~is_test], df["성공"][is_test]
scaler = StandardScaler().fit(Xtr)
model = LogisticRegression(max_iter=2000).fit(scaler.transform(Xtr), ytr)
pred = (model.predict_proba(scaler.transform(Xte))[:, 1] >= 0.5).astype(int)
tree = DecisionTreeClassifier(max_depth=3, random_state=0).fit(Xtr, ytr)
week_tr, week_te = Xtr.copy(), Xte.copy()
week_tr["first_week_audi"] = df.loc[~is_test, "first_week_audi"]
week_te["first_week_audi"] = df.loc[is_test, "first_week_audi"]
week_scaler = StandardScaler().fit(week_tr)
week_model = LogisticRegression(max_iter=2000).fit(week_scaler.transform(week_tr), ytr)
week_pred = (week_model.predict_proba(week_scaler.transform(week_te))[:, 1] >= 0.5).astype(int)

predictions = {"전부 기준 미달": [0] * len(yte), "로지스틱 회귀": pred,
               "의사결정트리": tree.predict(Xte), "로지스틱 + 첫 주 관객": week_pred}
st.info("기록된 자료의 분류 연습입니다. 개봉 전 예측 성능을 뜻하지 않습니다.")
rows = []
for name, values in predictions.items():
    tn, fp, fn, tp = confusion_matrix(yte, values, labels=[0, 1]).ravel()
    rows.append({"모델": name, "정확도": round(accuracy_score(yte, values), 3),
                 "정밀도": f"{tp / (tp + fp):.3f}" if tp + fp else "계산 불가",
                 "재현율": f"{tp / (tp + fn):.3f}" if tp + fn else "계산 불가"})
st.dataframe(pd.DataFrame(rows), hide_index=True)
name = st.selectbox("혼동행렬을 볼 모델", list(predictions), index=1)
tn, fp, fn, tp = confusion_matrix(yte, predictions[name], labels=[0, 1]).ravel()
st.dataframe(pd.DataFrame([[tn, fp], [fn, tp]],
                          index=["실제 기준 미달", "실제 성공"],
                          columns=["예측 기준 미달", "예측 성공"]))
st.caption(f"시험용 {len(yte)}편 중 실제 성공은 {int(yte.sum())}편입니다. "
           "정밀도·재현율의 분모가 0이면 계산 불가로 표시합니다.")

4. 입력 점검 — 레이블 누수

7차시에서는 첫 주 관객 수를 추가했을 때 테스트 R²가 약 0.24에서 0.90으로 높아졌습니다. 이번 분류 예제에서도 같은 시험용 자료에서 정확도가 0.924에서 0.955로 바뀝니다. 그러나 개봉 전 흥행 예측이라는 목표에서 첫 주 관객 수는 사용할 수 없는 미래 정보입니다.

레이블 누수는 정답 관련 정보가 부적절하게 입력에 들어가 평가를 왜곡하는 문제입니다. 총 관객 수와 관련이 높다는 사실 자체가 누수의 이유는 아닙니다. 예측할 때 사용할 수 없는 값을 학습·평가에 썼다는 것이 핵심입니다. 이 자료의 first_scrn·first_show도 첫 관측일 집계이므로 개봉 전에는 확보했다고 볼 수 없습니다. 실제 개봉 전 예측을 검증하려면 입력 자료부터 다시 설계해야 합니다. 활동지 문제 6에서는 예측 시점을 먼저 적고 변수별 사용 가능 여부를 판단합니다.

5. 개념 정리 — 기준선이라는 습관

분류 모델은 같은 시험용 자료의 기준 모델, 혼동행렬, 목적에 맞는 지표를 함께 살펴 평가합니다. 기준 모델보다 정확도가 낮더라도 중요한 오류를 줄이는 모델이 유용할 수 있습니다. 반대로 정확도가 높아도 목적에 필요한 대상을 대부분 놓칠 수 있습니다. 최종 판단에는 오류의 비용과 입력 자료의 적절성이 함께 필요합니다.

시험용 자료를 보고 반복해서 모델을 고르면 평가가 그 자료에 맞춰질 수 있습니다. 이번 실습의 비교 결과는 탐색 결과로 기록하고, 실제 적용 전에는 별도의 자료로 검증합니다.

6. 확인 문제

문제 1 영화 216편 중 성공작이 23편입니다. 전부 "기준 미달"로만 찍는 모델의 성적을 구해 보세요.
(a) 이 모델의 정확도는?
기준 미달 193편을 전부 맞히므로 193÷216 ≈ 0.89입니다.
(b) 이 모델의 성공 재현율은?
실제 성공작 23편 중 잡아낸 것이 0편 — 0÷23 = 0.00. 정확도 0.89와 재현율 0.00의 공존이 "정확도만 보면 안 되는" 첫 증거입니다.
문제 2 로지스틱 회귀의 정확도는 0.924입니다. 이 값만으로 성공작을 충분히 잘 찾는다고 말할 수 있을까요?
시험용 66편 중 기준 미달이 60편입니다. 모두 기준 미달로 예측해도 정확도는 0.909입니다. 성공작 발굴이 목적이라면 재현율 1÷6 ≈ 0.167도 함께 보고해야 합니다.
문제 3 개봉 전에 예측하려는 모델에 첫 주 관객 수를 넣어 평가 점수가 올랐습니다. 이 결과를 개봉 전 예측 성능의 개선이라 부를 수 있을까요?
개봉 전에는 첫 주 관객 수를 알 수 없습니다. 따라서 이 값을 넣은 평가 점수로 개봉 전 예측 성능을 주장할 수 없습니다. 누수 여부는 점수의 크기가 아니라 입력을 실제로 확보할 수 있는 시점으로 판단합니다.

🎒 오늘의 체크

  • 혼동행렬 네 칸을 우리말("양성 예측 · 실제 음성" 등)로 설명할 수 있다.
  • 교과서 해 보기 ④의 정밀도·재현율·정확도를 손으로 계산했다.
  • 같은 시험용 66편에서 기준 모델과 분류기의 정확도·재현율을 비교했다.
  • 개봉 전 예측에서 첫 주 관객 수가 레이블 누수인 이유를 한 문장으로 말할 수 있다.

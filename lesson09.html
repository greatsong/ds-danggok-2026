회귀 vs 분류 · 첫 분류 모델

🎯 오늘 만드는 것
  • 혼잡도 분류기 초안 — 장소·요일·시간을 보고 강남역이 붐빌지 4단계로 맞히는 첫 모델

0. 왜 배우나

내일 아침 집을 나서기 전에 우리가 던지는 질문은 두 갈래입니다. "오늘 몇 도지?"는 숫자를 묻고, "우산 챙겨야 하나?"는 챙긴다와 안 챙긴다, 두 칸 중 하나를 묻습니다. 지난 8차시 동안 우리는 앞의 질문처럼 숫자를 맞히는 회귀를 다뤘습니다. 오늘부터는 뒤의 질문처럼 정해진 칸 중 하나를 맞히는 분류를 시작합니다. "내일 강남역은 붐빌까?" 붐비는 정도를 네 단계로 나눠 놓고 그중 하나를 골라 맞히는 문제입니다. 오늘 첫 분류기를 돌리면 정확도라는 점수가 나옵니다. 꽤 높아 보이는 숫자가 나올 텐데, 그 첫인상을 어디까지 믿을지는 다음 차시에 다시 따져 봅니다.

1. 개념 이해 — 답의 모양이 문제를 가른다

📖 교과서의 정의 『데이터 과학』 138쪽

"대표적인 성능 지표로는 정확도(accuracy), 정밀도(precision), 재현율(recall), F1-score가 있다."

→ 오늘 만난 88.8%는 이 중 정확도다. 나머지 지표가 왜 필요한지는 다음 차시에서 알게 된다.

숫자 하나냐, 칸 하나냐

"어제 서울의 평균기온은?"의 답은 12.3℃처럼 어떤 값이든 나올 수 있는 연속된 숫자입니다. 반면 "내일 저녁 강남역은 붐빌까?"의 답은 여유·보통·약간 붐빔·붐빔, 미리 정해진 네 칸 중 하나입니다. 이 차이가 두 문제를 가릅니다. 답이 연속된 숫자 하나로 나오면 회귀, 정해진 칸 중 하나로 나오면 분류입니다. 두 문제는 물음이 비슷해 보여도 답의 모양이 다르고, 답의 모양이 다르면 쓰는 도구와 점수를 매기는 방법까지 달라집니다. 그래서 새로운 예측 문제를 만나면 방법을 고르기 전에 답의 모양부터 확인합니다.

질문답의 모양회귀 / 분류

이 메일은 스팸일까스팸·정상 두 칸 중 하나분류

정답의 이름만 바뀔 뿐, 배우는 방식은 같다

회귀와 분류는 둘 다 정답이 붙은 데이터로 배우는 지도학습입니다. 5차시 기온 예측기는 연도마다 실제 기온이라는 정답이 붙은 데이터로 배웠고, 오늘 혼잡도 분류기는 시각마다 실제 혼잡 단계라는 정답이 붙은 데이터로 배웁니다. 분류에서는 이 정답을 레이블이라고 부릅니다. 그래서 학습시키는 코드도 회귀 때 본 것과 같은 한 줄입니다. 바뀌는 것은 정답의 모양, 즉 숫자냐 칸이냐뿐입니다. 겁먹을 새 개념이 아니라, 이미 아는 틀에서 정답의 모양 하나가 바뀐 문제입니다.

정확도 — 전체 중 맞힌 비율

분류기의 점수로 가장 먼저 만나는 것이 정확도입니다. 뜻은 단순합니다. 전체 예측 가운데 맞힌 비율. 100번 예측해서 88번 맞히면 정확도 88%입니다. 오늘 첫 분류기는 약 88.8%가 나옵니다. 열에 아홉을 맞힌 셈이라 첫인상이 좋습니다. 그런데 이 첫인상에는 아직 비교 기준이 없습니다. 88.8%가 정말 높은 점수인지 판단하려면 무엇과 견줘야 하는지, 그리고 이 점수가 어떤 데이터 위에서 나온 것인지를 봐야 합니다. 오늘은 이 물음만 챙겨 두고, 다음 차시에 88.8%라는 숫자를 세 각도에서 다시 봅니다.

② AI가 준 코드 (예시)
import streamlit as st
import pandas as pd
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

st.title("🚇 강남역, 내일 붐빌까?")

# 데이터 불러오기 — 서울 23곳, 매시간 혼잡도
url = "https://raw.githubusercontent.com/greatsong/modudata/main/data/seoul_congestion_log.csv"
df = pd.read_csv(url)

# 시각에서 요일과 시간을 뽑기
df["시각"] = pd.to_datetime(df["시각"])
df["요일"] = df["시각"].dt.dayofweek   # 월=0 … 일=6
df["시간"] = df["시각"].dt.hour

# 입력(특징): 장소·요일·시간 / 정답(레이블): 혼잡도
X = pd.get_dummies(df[["지역명", "요일", "시간"]], columns=["지역명"])
y = df["혼잡도"]

# 학습용·시험용으로 나누기 (4분의 1은 시험용)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.25, random_state=42)

# 랜덤 포레스트로 학습 — 이 한 줄이 '학습'
model = RandomForestClassifier(random_state=42)
model.fit(X_train, y_train)

# 시험용으로 정확도 재기
acc = accuracy_score(y_test, model.predict(X_test))
st.metric("정확도", f"{acc:.1%}")

  • 첫 정확도는 약 88.8% — 열에 아홉은 맞힌 셈

8. 확인 문제

지필 문항과 같은 유형입니다. 먼저 스스로 답을 적고 나서 펼쳐 보세요.

문제 1 — "역의 하루 승객 수 예측"과 "혼잡 단계 예측" 중 분류는 어느 쪽인지 고르고, 판별 기준을 한 문장으로 서술하시오.

예시 답안 — 혼잡 단계 예측이 분류다. 답이 연속된 숫자 하나로 나오면 회귀, 정해진 칸(여유·보통·약간 붐빔·붐빔) 중 하나로 나오면 분류이기 때문이다.

문제 2 — 전체 3,608건 중 '여유'가 2,706건이다. 아무것도 배우지 않고 무조건 '여유'로만 답하는 모델의 정확도를 구하시오.

예시 답안 — 2,706 ÷ 3,608 = 75.0%. 가장 흔한 답만 찍어도 나오는 이 값이 다음 차시에서 88.8%를 읽는 비교 기준(기준선)이 된다.

문제 3 — 오늘 분류기의 정확도 88.8%가 뜻하는 바를 쓰고, 이 숫자 하나로 "잘 만든 모델"이라고 판단하기 전에 확인할 것을 한 가지 서술하시오.

예시 답안 — 시험용 데이터 전체 중 88.8%를 맞혔다는 뜻이다. 판단하기 전에 단계별 분포('여유' 쏠림)와 단계별로 얼마나 맞히는지를 확인해야 한다. 가장 흔한 단계만 찍어도 점수가 높게 나올 수 있기 때문이다.

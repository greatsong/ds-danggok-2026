분류 · 로지스틱 회귀와 의사결정트리

"문제를 잘 정의하면 절반은 푼 것이다."
존 듀이 『논리학』(1938) — 성공의 기준선을 정하는 일부터가 분류 문제의 절반입니다

7차시의 영화 데이터로 이번에는 관객 수가 정한 기준 이상인지 분류합니다. 관객 수를 숫자로 예측하는 회귀와, 기준 충족 여부를 예측하는 분류의 차이를 살펴봅니다. 먼저 학급에서 관객 수 기준을 정하고, 두 모델의 확률과 판단 규칙을 비교합니다.

이 수업에서 사용하는 표는 어제까지 모인 데이터입니다. 데이터가 하루씩 쌓이므로 화면에 나오는 편수와 점수는 사람마다, 날마다 조금씩 다릅니다. 숫자가 다른 것은 잘못이 아니며, 그 숫자를 어떻게 읽을지가 오늘의 과제입니다.

🎯 오늘 하는 것
  • 기준 정하기 — "흥행 성공"의 관객 수 기준선을 학급이 함께 정한다 (라벨은 사람이 정한다)
  • 바이브 코딩 — 로지스틱 회귀로 성공 확률을, 의사결정트리로 판단 규칙을 만든다
  • 관찰 — 트리 그림에서 모델이 질문을 던지는 순서를 읽는다

0. 오늘의 목표

스팸 메일 필터, 감염병 검사의 양성·음성 판정처럼 세상의 많은 예측은 숫자가 아니라 "인가, 아닌가"를 답합니다. 오늘은 그런 문제를 알아보고, 정답을 만들고, 두 가지 모델로 풀어 보는 순서로 진행합니다.

  • 묻는 말과 답의 형태로 회귀 문제와 이진 분류 문제를 구분할 수 있다.
  • 레이블(라벨)이 사람이 정한 기준으로 만들어진다는 것을 알고, 기준을 정하고 그 이유를 설명할 수 있다.
  • 로지스틱 회귀가 추정하는 확률과 문턱값, 의사결정트리가 던지는 질문의 순서를 읽고 두 모델을 비교할 수 있다.

1. 개념 이해 — 회귀에서 분류로

📖 교과서의 정의 『데이터 과학』 135·136쪽

"분류 모델 중 이진 분류는 어떤 특성을 '띤다' 또는 '띠지 않는다' 두 가지 경우의 수 중 하나로 예측하는 것을 말한다." (135쪽)

"로지스틱 회귀는 선형 회귀 모델을 로지스틱 함수와 결합하여 각 범주에 해당할 확률을 바탕으로 분류하는 방법이다." (135쪽)

"… 출력값이 0.5보다 크면 양성, 작으면 음성으로 분류한다." (136쪽)

→ 로지스틱 회귀는 양성일 확률을 추정합니다. 이 실습에서는 0.5 이상이면 양성, 미만이면 음성으로 분류합니다.

구분묻는 말답의 형태영화 데이터라면
회귀 (6~8차시)얼마나?연속적인 숫자총 관객 수는 몇 명일까
분류 (오늘)어느 쪽?정해진 범주 중 하나흥행에 성공할까, 못 할까

범주가 두 개면 이진 분류, 세 개 이상이면 다중 분류입니다. 오늘의 "성공/기준 미달"은 이진 분류입니다. 교과서의 책 장르처럼 여러 범주 중 하나를 고르는 문제는 다중 분류입니다.

🧮 시그모이드와 문턱값 — 확률을 범주로 바꾸는 두 단계

로지스틱 회귀는 입력 변수의 가중합에 시그모이드 함수를 적용해 양성일 확률을 추정합니다. 시그모이드는 어떤 실수든 0과 1 사이의 값으로 바꾸는 S자 곡선입니다. 선형 회귀를 먼저 학습한 뒤 출력을 바꾸는 방식이 아니라, 처음부터 분류에 맞게 가중치를 학습합니다.

추정한 확률은 아직 범주가 아닙니다. 확률을 성공과 기준 미달로 가르는 경계를 문턱값이라고 하며, 위 교과서 인용의 0.5가 그 값입니다. 0.5는 관례이고 바꿀 수 있습니다. 관객 수로 정답을 만드는 라벨 기준과, 확률을 범주로 바꾸는 문턱값은 서로 다른 층위입니다. 앞의 것은 정답 쪽을, 뒤의 것은 예측 쪽을 움직입니다.

의사결정트리도 확률을 추정할 수 있지만, 이 시간에는 조건에 따라 가지가 나뉘는 판단 과정에 주목합니다.

더 알아보기 — 실제 사례 · 챌린저호 O-링과 로지스틱 회귀

챌린저호 O-링과 로지스틱 회귀

1986년 1월 28일 미국 항공우주국 우주왕복선 챌린저호가 발사 73초 만에 공중분해되었고 승무원 7명이 사망했습니다. 사고 이전 23회 발사에 발사 당시 기온과 O-링 손상 여부가 기록으로 남아 있었습니다. 손상이 기록된 발사는 23회 중 7회입니다. 1989년 미국통계학회 학술지(JASA)에 실린 달랄 연구진의 분석은 로지스틱 회귀로 화씨 31도의 발사 조건에서 접합부 O-링 파손 확률을 최소 13%로, 화씨 60도로 연기했다면 최소 2%로 계산했습니다.

항목챌린저호 사례이 차시 개념과의 연결
무엇을 예측했나O-링 손상 여부(손상 있음·손상 없음 두 범주)오늘의 성공·기준 미달과 같은 이진 분류
입력발사 당시 기온(화씨) 하나오늘은 스크린 수·상영 횟수·성수기·장르·국가 다섯
데이터의 범위23회 발사, 손상 기록 7회, 최저 기온 화씨 53도발사 예정 기온 화씨 31도는 데이터 바깥

오늘 만든 로지스틱 회귀와 같은 형태로 입력 하나(기온)에서 확률을 추정하고 문턱값으로 판단을 정합니다. 학습 데이터에 화씨 53도보다 낮은 발사가 하나도 없어 데이터 바깥 구간의 확률을 그대로 받아들일 수 없다는 한계가 있습니다. 기준과 입력을 사람이 정한다는 이 차시의 논점으로 이어집니다.

출처: Dalal, Fowlkes & Hoadley (1989), JASA 84(408)

2. 성공의 기준선 — 라벨은 사람이 정한다

🎬 우리는 DGV 배급사의 데이터 과학 인턴입니다

DGV는 이 수업에서만 쓰는 가상의 영화사입니다(DG는 당곡입니다). 분석에 쓰는 흥행 기록은 영화진흥위원회의 실제 데이터입니다.

배급사는 개봉 전에 어떤 영화를 밀어줄지 정합니다. 그 일을 하려면 먼저 무엇을 성공이라고 부를지부터 정해야 합니다. 표에는 관객 수만 있고 성공이라는 열은 없습니다.

인턴은 판단을 혼자 정하고 끝내지 않습니다. 근거를 들어 팀장에게 보고합니다.

📖 교과서의 정의 『데이터 과학』 138쪽

"레이블은 모델이 예측하고자 하는 정답 값을 의미한다." (138쪽)

→ 분류 모델을 만들려면 각 데이터에 정답(레이블)이 먼저 붙어 있어야 합니다. 그런데 우리 영화 표에는 "성공/기준 미달" 열이 없습니다.

🏷️ 레이블 — 데이터에 없던 정답을 사람이 만든다

스팸 메일 판정처럼 레이블이 이미 붙어 있는 문제도 있고, 오늘처럼 없는 레이블을 사람이 만들어 붙이는 문제도 있습니다. 영화 표에는 관객 수가 있지만 "흥행 성공"이라는 열은 없습니다. 이 수업에서는 기록된 누적 관객 수가 100만 명 이상이면 성공(1), 미만이면 기준 미달(0)로 정합니다. 제작비와 수익 데이터가 없으므로 실제 흑자와 적자를 뜻하지 않습니다.

오해하기 쉬운 지점: 레이블은 데이터에 원래 있던 사실처럼 보이지만 사람의 판단입니다. 기준을 바꾸면 정답이 바뀌고, 정답이 바뀌면 같은 모델의 성능 수치도 바뀝니다.

기준선을 어디에 그을지는 무엇을 하려는 일이냐가 정합니다. 광고비를 크게 쓸 대상을 고르는 일이라면 기준을 높게 긋고, 상영관을 조금 더 얹어 줄 대상을 고르는 일이라면 낮게 긋습니다. 같은 데이터에 같은 모델이어도 기준선이 달라지면 성공으로 뽑히는 편수도, 정확도도, 쓸모 있는 모델도 달라집니다.

❓ 기준선을 정하기 전에 답할 질문
  • DGV 배급팀이 "흥행 성공"이라고 부를 관객 수는 몇 명입니까. 그 숫자를 고른 이유는 무엇입니까.
  • 기준을 낮추면 성공 라벨이 붙는 영화가 늘어납니다. 성공이라는 말이 그만큼 흔해져도 괜찮습니까.
  • 제작비와 수익을 알 수 없는 데이터로 정한 이 라벨을 실제 흑자·적자와 같다고 말할 수 있습니까.
    관객 수는 흥행의 한 측면일 뿐입니다. 오늘 만드는 라벨은 우리 반이 정한 기준이며, 실제 손익과는 다른 값입니다.

3. 실습 — 영화 흥행 분류기 (바이브 코딩)

4차시의 영화별 표(kobis_movies.csv)로 앱을 만듭니다. 개봉 전 흥행 예측이 목표라면 입력도 개봉 전에 확보한 값이어야 합니다. 그러나 이 표의 first_scrn·first_show는 10위권에 처음 관측된 날의 집계값이고, total_audi도 수집 기간에 기록된 누적값입니다. 아래 결과는 개봉 전 예측 성능이 아니라 기록된 데이터의 분류 연습입니다.

    main.py와 requirements.txt, 두 파일로 저장합니다. 데이터가 날마다 쌓이므로 편수와 정확도는 실행하는 날에 따라 달라집니다. 라이브러리 버전이나 설정을 바꾸어도 결과가 달라질 수 있습니다.

    main.py
    # main.py — 기록된 관객 수의 기준 충족 여부를 분류한다
import streamlit as st
import pandas as pd
import plotly.express as px
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier, export_text, export_graphviz
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score

MOVIES = "https://raw.githubusercontent.com/greatsong/modudata/main/data/kobis_movies.csv"


@st.cache_data
def load_data():
    df = pd.read_csv(MOVIES, dtype={"movieCd": str}).sort_values("movieCd").reset_index(drop=True)
    df["장르"] = df["genre"].str.split("|").str[0]
    df["국가"] = df["nation"].str.split("|").str[0]
    return df


df = load_data()
기준 = st.selectbox("성공 기준 (총 관객)", [500_000, 1_000_000, 3_000_000], index=1)
df["성공"] = (df["total_audi"] >= 기준).astype(int)
st.caption(f"성공 {df['성공'].sum()}편 / {len(df)}편")
st.info("기록된 데이터의 분류 연습입니다. 개봉 전 예측 성능을 뜻하지 않습니다.")

is_test = df.index % 10 < 3
features = df[["first_scrn", "first_show", "peak", "장르", "국가"]]
Xtr = pd.get_dummies(features[~is_test])
Xte = pd.get_dummies(features[is_test]).reindex(columns=Xtr.columns, fill_value=0)
X = pd.concat([Xtr, Xte]).sort_index()
is_test = df.index % 10 < 3                      # 열 편 중 앞 세 편을 시험용으로
st.caption(f"학습용 {(~is_test).sum()}편 · 시험용 {is_test.sum()}편 · 전체 {len(df)}편")
Xtr, Xte = X[~is_test], X[is_test]
ytr, yte = df["성공"][~is_test], df["성공"][is_test]

scaler = StandardScaler().fit(Xtr)
logi = LogisticRegression(max_iter=2000).fit(scaler.transform(Xtr), ytr)
tree = DecisionTreeClassifier(max_depth=3, random_state=0).fit(Xtr, ytr)

c1, c2 = st.columns(2)
prob = logi.predict_proba(scaler.transform(Xte))[:, 1]
c1.metric("로지스틱 회귀 정확도", f"{accuracy_score(yte, (prob >= 0.5).astype(int)):.3f}")
c2.metric("의사결정트리 정확도", f"{accuracy_score(yte, tree.predict(Xte)):.3f}")
확률표 = pd.DataFrame({"영화": df.loc[is_test, "movieNm"].values,
                     "추정 확률": prob,
                     "실제": ["성공" if v else "기준 미달" for v in yte]})
확률표 = 확률표.sort_values("추정 확률", ascending=False)
fig = px.bar(확률표, x="영화", y="추정 확률", color="실제",

"의사결정트리는 규칙을 만족하는지 아닌지에 따라 대상을 분류하는 모델로, 스무고개 놀이에 비유할 수 있다. … 같은 클래스의 데이터로만 구성될수록 그 노드의 불순도가 낮다고 말한다. 즉, 의사결정트리는 불순도를 낮추는 규칙을 찾는 모델이다." (220쪽)

"의사결정트리는 결과를 직관적으로 이해하기 쉽고 규칙이 명확하게 도출된다는 장점을 갖는다. 하지만 과대적합에 빠지기 쉽다는 단점이 있다." (220쪽)

트리는 한 마디에서 "어느 변수를 어느 값에서 자를 때 두 갈래가 가장 덜 섞이는가"를 따져 분기를 고릅니다. 한쪽에 성공만, 다른 쪽에 기준 미달만 모이면 잘 나뉜 것이고, 양쪽에 두 범주가 뒤섞이면 못 나뉜 것입니다. 가장 덜 섞이게 만드는 분기를 고른 다음, 갈라진 각 갈래에서 같은 일을 되풀이합니다.

여러 분기에서 각 변수가 섞임을 줄인 정도를 그 마디에 놓인 데이터 수로 가중해 합산한 값을 feature importance라고 합니다. 어떤 속성이 예측에 얼마나 기여했는지 나타내는 값이며, 5절에서 직접 확인합니다.

feature importance 값은 현재 데이터·모델·설정에 따른 결과입니다. 관련된 변수가 함께 있거나 학습 데이터가 바뀌면 중요도의 분배도 달라질 수 있습니다. 스크린을 많이 확보해서 관객이 늘었는지, 흥행을 기대해서 스크린을 많이 배정했는지는 이 값만으로 구분할 수 없습니다. feature importance는 인과관계의 증거가 아닙니다.

6. 개념 정리 — 질문이 모델을 고른다

회귀와 분류는 모두 정답 값을 이용하는 지도학습입니다. 회귀는 수치를, 분류는 범주를 예측합니다. 오늘은 관객 수에 기준을 적용해 분류용 라벨을 직접 만들었습니다. 라벨의 의미와 만든 기준을 먼저 확인해야 결과를 해석할 수 있습니다.

❓ 이 숫자, 믿어도 되는가
  • 4절 표에 적은 두 정확도를 다시 봅니다. 두 모델 가운데 어느 쪽이 높았고, 차이는 얼마였습니까.
  • 성공 라벨이 붙은 영화가 시험용 데이터에 몇 편 있었습니까. 모든 영화를 기준 미달로만 찍는 모델의 정확도는 얼마가 되겠습니까.
  • 그 값과 내 모델의 정확도를 나란히 놓으면, 내 모델이 실제로 무엇을 더 해낸 것입니까.
    한쪽으로만 찍는 모델도 정확도가 높게 나옵니다. 그 값을 넘어선 만큼이 모델이 실제로 해낸 일입니다.

다음 시간에는 항상 다수 범주로 예측하는 기준 모델과 비교하고, 성공작을 얼마나 찾아냈는지도 계산합니다.

입력 변수의 가중합에 시그모이드를 적용해 양성일 확률을 추정하고, 문턱값으로 범주를 정하기 때문입니다. 이 실습에서는 확률이 0.5 이상이면 성공, 미만이면 기준 미달로 분류합니다. 선형 회귀를 먼저 학습하는 절차는 아닙니다.

문제 4 앞 표에 적은 중요도 1위 변수와 그 값을 가져옵니다. 이 결과에서 끌어낼 수 있는 말로 알맞은 것은?
중요도는 '무엇을 단서로 삼았나'를 보여 줄 뿐 원인의 증거가 아닙니다. 스크린 수가 1위로 나왔다면, 기대작에 스크린을 몰아주는 결정이 먼저였을 수도 있습니다. 중요도는 데이터와 모델 설정에 따라 달라질 수 있습니다.

🎒 오늘의 체크

  • 회귀와 분류는 묻는 말과 답의 형태로 구분할 수 있다.
  • 우리 반이 정한 흥행 성공 기준선과 그 이유를 말할 수 있다.
  • 내 분류기가 산출한 성공 확률과 정확도를 확인했다.
  • 트리 그림에서 모델이 먼저 던진 질문(변수)을 찾아 읽었다.

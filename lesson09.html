7차시의 영화 데이터로 이번에는 관객 수가 정한 기준 이상인지 분류합니다. 관객 수를 숫자로 예측하는 회귀와, 기준 충족 여부를 예측하는 분류의 차이를 살펴봅니다. 먼저 학급에서 관객 수 기준을 정하고, 두 모델의 확률과 판단 규칙을 비교합니다.

🎯 오늘 하는 것
  • 기준 정하기 — "흥행 성공"의 관객 수 기준선을 학급이 함께 정한다 (라벨은 사람이 정한다)
  • 바이브 코딩 — 로지스틱 회귀로 성공 확률을, 의사결정트리로 판단 규칙을 만든다
  • 관찰 — 트리 그림에서 모델이 질문을 던지는 순서를 읽는다

0. 왜 배우나

스팸 메일 필터, 감염병 검사의 양성·음성 판정처럼 세상의 많은 예측은 숫자가 아니라 "인가, 아닌가"를 답합니다. 문제를 받았을 때 회귀 문제인지 분류 문제인지 가려내는 눈을 오늘 기릅니다.

1. 개념 이해 — 회귀에서 분류로

📖 교과서의 정의 『데이터 과학』 135·136쪽

"분류 모델 중 이진 분류는 어떤 특성을 '띤다' 또는 '띠지 않는다' 두 가지 경우의 수 중 하나로 예측하는 것을 말한다." (135쪽)

"로지스틱 회귀는 선형 회귀 모델을 로지스틱 함수와 결합하여 각 범주에 해당할 확률을 바탕으로 분류하는 방법이다." (135쪽)

"… 출력값이 0.5보다 크면 양성, 작으면 음성으로 분류한다." (136쪽)

→ 로지스틱 회귀는 양성일 확률을 추정합니다. 이 실습에서는 0.5 이상이면 양성, 미만이면 음성으로 분류합니다. 관객 수로 정답을 만드는 기준과, 확률로 예측을 정하는 문턱값은 서로 다릅니다.

구분묻는 말답의 형태영화 데이터라면
회귀 (6~8차시)얼마나?연속적인 숫자총 관객 수는 몇 명일까
분류 (오늘)어느 쪽?정해진 범주 중 하나흥행에 성공할까, 못 할까

범주가 두 개면 이진 분류, 세 개 이상이면 다중 분류입니다. 오늘의 “성공/기준 미달”은 이진 분류입니다. 교과서의 책 장르처럼 여러 범주 중 하나를 고르는 문제는 다중 분류입니다.

로지스틱 회귀는 입력 변수의 가중합에 시그모이드 함수를 적용해 양성일 확률을 추정합니다. 선형 회귀를 먼저 학습한 뒤 출력을 바꾸는 방식은 아닙니다. 분류에 맞게 가중치를 학습하고, 추정 확률에 문턱값을 적용해 범주를 정합니다. 의사결정트리도 확률을 추정할 수 있지만, 이 시간에는 조건에 따라 가지가 나뉘는 판단 과정에 주목합니다.

2. 성공의 기준선 — 라벨은 사람이 정한다

📖 교과서의 정의 『데이터 과학』 138쪽

"레이블은 모델이 예측하고자 하는 정답 값을 의미한다." (138쪽)

→ 분류 모델을 만들려면 각 데이터에 정답(레이블)이 먼저 붙어 있어야 한다. 그런데 우리 영화 표에는 "성공/기준 미달" 열이 없다.

영화 표에는 관객 수가 있지만 “흥행 성공”이라는 라벨은 없습니다. 수업에서는 기록된 누적 관객 수가 100만 명 이상이면 성공(1), 미만이면 기준 미달(0)로 정합니다. 이는 분류 연습을 위한 정의입니다. 제작비·수익 자료가 없으므로 실제 흑자와 적자를 뜻하지 않습니다. 다른 기준을 선택하면 라벨과 예측 과제도 달라집니다.

3. 실습 — 영화 흥행 분류기 (바이브 코딩)

4차시의 영화별 표(kobis_movies.csv)로 앱을 만듭니다. 개봉 전 흥행 예측이 목표라면 입력도 개봉 전에 확보한 값이어야 합니다. 그러나 이 표의 first_scrn·first_show는 일별 10위권에 처음 관측된 날의 집계값입니다. 따라서 아래 코드는 기록된 자료를 이용한 분류 연습이며, 개봉 전 예측 성능을 검증한 결과가 아닙니다. total_audi도 수집 자료에 기록된 누적값으로, 모든 영화의 최종 관객 수를 보장하지 않습니다.

  1. ① 샘플 프롬프트 — 그대로 붙여 넣기

시험용 영화 하나를 고르면 로지스틱 회귀의 추정 확률과 예측 범주를 보여 줘.

    본문 표와 같은 자료·분할을 사용합니다. 학습용은 150편, 시험용은 66편입니다. 라이브러리 버전이나 설정을 바꾸면 결과가 달라질 수 있습니다.

    # app.py — 기록된 관객 수의 기준 충족 여부를 분류한다
import streamlit as st
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier, export_text, export_graphviz
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import accuracy_score

MOVIES = "https://raw.githubusercontent.com/greatsong/modudata/bb860932644270ad1199f10d3e7670e30231bce4/data/kobis_movies.csv"


@st.cache_data
def load_data():
    df = pd.read_csv(MOVIES, dtype={"movieCd": str}).sort_values("movieCd").reset_index(drop=True)
    df["장르"] = df["genre"].str.split("|").str[0]
    df["국가"] = df["nation"].str.split("|").str[0]
    return df


df = load_data()
기준 = st.selectbox("성공 기준 (총 관객)", [500_000, 1_000_000, 3_000_000], index=1)
df["성공"] = (df["total_audi"] >= 기준).astype(int)
st.caption(f"성공 {df['성공'].sum()}편 / {len(df)}편")
st.info("기록된 자료의 분류 연습입니다. 개봉 전 예측 성능을 뜻하지 않습니다.")

is_test = df.index % 10 < 3
features = df[["first_scrn", "first_show", "peak", "장르", "국가"]]
Xtr = pd.get_dummies(features[~is_test])
Xte = pd.get_dummies(features[is_test]).reindex(columns=Xtr.columns, fill_value=0)
X = pd.concat([Xtr, Xte]).sort_index()
is_test = df.index % 10 < 3                      # 열 편 중 앞 세 편을 시험용으로
Xtr, Xte = X[~is_test], X[is_test]
ytr, yte = df["성공"][~is_test], df["성공"][is_test]

scaler = StandardScaler().fit(Xtr)
logi = LogisticRegression(max_iter=2000).fit(scaler.transform(Xtr), ytr)
tree = DecisionTreeClassifier(max_depth=3, random_state=0).fit(Xtr, ytr)

c1, c2 = st.columns(2)
prob = logi.predict_proba(scaler.transform(Xte))[:, 1]
c1.metric("로지스틱 회귀 정확도", f"{accuracy_score(yte, (prob >= 0.5).astype(int)):.3f}")
c2.metric("의사결정트리 정확도", f"{accuracy_score(yte, tree.predict(Xte)):.3f}")
choices = df.loc[is_test].copy()
selected = st.selectbox("시험용 영화", list(range(len(choices))),
                        format_func=lambda i: choices.iloc[i]["movieNm"])
p = float(prob[selected])
st.write(f"추정 성공 확률: {p:.1%}")
st.write("예측:", "성공" if p >= 0.5 else "기준 미달")
st.write("실제 라벨:", "성공" if int(yte.iloc[selected]) else "기준 미달")
st.caption("이 확률은 모델의 추정값이며 실제 성공 가능성을 보장하지 않습니다.")

개봉 전에 예측하려면 first_scrn·first_show를 포함해 입력의 수집 시점을 다시 확인해야 합니다. 미래에 알게 되는 값을 빼 달라는 문장만으로 누수를 막을 수는 없습니다. 다음 시간에는 예측 시점에 사용할 수 없는 값을 입력에 넣었을 때의 문제를 살펴봅니다.

4. 두 모델 비교 — 확률로 답하는 모델, 질문으로 답하는 모델

트리는 조건을 따라 데이터를 나누는 과정을 보여 줍니다. 위에서부터 조건과 가지를 읽으며 한 영화가 어느 끝마디에 도착하는지 따라가 봅니다. 첫 번째 분기만으로 변수의 중요도 전체를 판단할 수는 없습니다. 이 코드의 특성 중요도는 각 변수가 여러 분기에서 클래스의 섞임을 얼마나 줄였는지를 데이터 수로 가중해 합산한 값입니다.

모델답하는 방식정확도 (기준 100만, 동일 시험용 66편)
로지스틱 회귀0~1 사이의 성공 확률0.924
의사결정트리질문의 순서(규칙)0.939

두 모델은 같은 학습용 150편과 시험용 66편을 사용했습니다. 시험용 자료는 학습과 표준화의 기준 계산에서 제외합니다. 표의 수치는 이 자료·분할·설정에서 얻은 값입니다. 다른 분할에서도 비슷한 결과가 나오는지는 별도로 확인해야 합니다.

⚠️ 발견 — 기준선을 움직이면 모델이 흔들린다

성공 기준선을 100만에서 300만으로 바꾸어 다시 학습시키면, 성공 라벨이 붙는 영화의 수가 달라지고 정확도도 함께 달라집니다. 모델은 그대로인데 사람이 정한 기준 하나가 결과를 바꾼 것입니다. 라벨 기준도 판단이며, 모델의 성능은 그 판단 위에 있습니다.

이 과정 전체는 교과서 116쪽 탐구활동의 스팸 메일 예측 모델을 만드는 과정과 같은 뼈대입니다. 폼 Ⅲ-01b에서 우리 실습을 그 단계에 맞춰 봅니다. 시간이 남으면 폼 Ⅲ-02e(교과서 142쪽 탐구활동 '데이터로 예측하기')에 내 분류기의 예측 하나를 기록합니다.

특성 중요도는 현재 자료·모델·설정에 따른 값입니다. 관련된 변수가 함께 있거나 학습 자료가 바뀌면 중요도의 분배도 달라질 수 있습니다. 스크린을 많이 확보해서 관객이 늘었는지, 흥행을 기대해서 스크린을 많이 배정했는지는 이 값만으로 구분할 수 없습니다. 특성 중요도는 인과관계의 증거가 아닙니다.

6. 개념 정리 — 질문이 모델을 고른다

회귀와 분류는 모두 정답 값을 이용하는 지도학습입니다. 회귀는 수치, 분류는 범주를 예측합니다. 오늘은 관객 수에 기준을 적용해 분류용 라벨을 만들었습니다. 다른 분류 과제에서는 이미 기록된 범주를 사용할 수도 있습니다. 라벨의 의미와 만드는 기준을 먼저 확인해야 결과를 해석할 수 있습니다.

⚠️ 이 숫자, 믿어도 되나?

같은 시험용 66편에서 로지스틱 회귀의 정확도는 0.924, 의사결정트리는 0.939였습니다. 이 값만으로 충분히 좋은 모델이라고 말할 수 있을까요? 다음 시간에는 항상 다수 범주로 예측하는 기준 모델과 비교하고, 성공작을 얼마나 찾아냈는지도 계산합니다.

7. 확인 문제

문제 1 다음 물음이 회귀 문제인지 분류 문제인지 골라 보세요. 답을 눌러 확인합니다.
(가) 이 영화의 총 관객 수는 몇 명이 될까
연속적인 숫자를 예측한다 — 회귀입니다.
(나) 이 영화의 기록된 관객 수는 100만 명 이상일까
"100만 명 이상/미만" 두 범주 중 하나 — 이진 분류입니다. 같은 영화 데이터라도 묻는 형태가 모델을 정합니다.
(다) 이 메일은 스팸인가
"스팸이다/아니다" 두 범주 — 이진 분류입니다. 다중 분류는 교과서 135쪽의 책 장르처럼 범주가 셋 이상일 때입니다.
문제 2 흥행 성공 기준선을 100만 명에서 300만 명으로 올리면 무엇이 달라지는지 두 가지 이상 쓰시오. 자기 말로 답해 본 뒤 펼쳐 보세요.
예시 답 펼쳐 보기

①성공 라벨이 붙는 영화 수가 줄어든다(정답 자체가 바뀐다). ②모델이 새 라벨로 다시 학습되므로 예측 결과와 정확도가 달라진다. 즉 라벨 기준은 데이터에 원래 있던 사실이 아니라 사람의 판단이며, 그 판단이 모델의 성능 수치까지 바꾼다.

문제 3 로지스틱 회귀는 이름에 "회귀"가 들어 있는데 왜 분류 모델인가? 자기 말로 답해 본 뒤 펼쳐 보세요.
예시 답 펼쳐 보기

입력 변수의 가중합에 시그모이드를 적용해 양성일 확률을 추정하고, 문턱값으로 범주를 정하기 때문입니다. 이 실습에서는 확률이 0.5 이상이면 성공, 미만이면 기준 미달로 분류합니다. 선형 회귀를 먼저 학습하는 절차는 아닙니다.

문제 4 특성 중요도에서 첫 관측일 스크린 수가 0.476으로 1위였습니다. 이 결과에서 끌어낼 수 있는 말로 알맞은 것은?
중요도는 '무엇을 단서로 삼았나'를 보여 줄 뿐 원인의 증거가 아닙니다. 기대작에 스크린을 몰아주는 결정이 먼저였을 수도 있습니다. 중요도는 자료와 모델 설정에 따라 달라질 수 있습니다.

🎒 오늘의 체크

  • 회귀와 분류를 "묻는 말"과 "답의 형태"로 구분해 말할 수 있다.
  • 우리 반이 정한 흥행 성공 기준선과 그 이유를 말할 수 있다.
  • 내 분류기가 내놓은 성공 확률과 정확도를 확인했다.
  • 트리 그림에서 모델이 먼저 던진 질문(변수)을 찾아 읽었다.
